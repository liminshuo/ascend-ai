# 昇腾异构编程基础（速成班）

> 本课程深入解析昇腾 AI 处理器的达芬奇架构，涵盖 AI Core、AI CPU、层次化存储等核心组件；通过 CANN 异构计算架构与 Ascend C 核函数特性讲解，帮助学员掌握 SPMD 编程范式，并用仿真工具完成自定义算子开发与性能评估。

## 课程概要
- 适用对象：算子开发者；希望掌握昇腾 AI 处理器架构与 Ascend C 核函数开发的工程师
- 学习目标：掌握昇腾达芬奇架构、Ascend C 核函数与 SPMD 编程，并能用仿真工具完成自定义算子开发与性能评估
- 能力等级：中级
- 学习时长：100 分钟
- 关联场景：算子编写与调用
- 关联产品：CANN · Ascend C
- 环境要求：CANN 开发环境；仿真分析章节需仿真工具（如 msprof）

## 预备知识

### 必备基础
- C/C++ 基础

### 推荐学习
- [昇腾AI处理器及CANN基础](https://www.hiascend.com/developer/courses/detail/1559096386317148161)

## 知识点
- 昇腾达芬奇架构（AI Core、AI CPU、层次化存储）
- Ascend C 核函数与 SPMD 编程
- 流水线优化与 Cache 利用率
- 仿真工具与 msprof 性能分析
- 自定义算子开发与性能评估

## 课程介绍

### 课程目标
学完本课后，能够：
1. 说明昇腾 AI 处理器的达芬奇架构特性
2. 使用 Ascend C 语言实现核函数开发
3. 按 SPMD 模型完成多核数据切分
4. 通过 msprof 工具分析指令执行时序
5. 说明 L2 缓存对算子性能的影响，并完成基础性能评估

元素拆解

对照上方完整示例按块填写。链接须为 https 绝对地址，并直达具体资源正文；无内容的块整节省略，勿保留空标题。名称以官网正式用语为准，全文保持一致。课程目标与课程目录必须写成文字，勿只依赖截图。

1. 文首 Frontmatter（必填）

  1. 说明：标识本课程，并与人读详情页对齐；区分内容更新与模板结构版本。
  2. 写法：置于文件最上方，以 --- 包裹；键名固定，勿增删。
  3. title：课程名称，与正文一级标题一致。
  4. type：固定为 course。
  5. schema_version：模板结构版本，当前固定 "1.1"；模板字段升级时由规范更新，业务侧勿改。
  6. id：人读页 URL 末段 ID。
  7. url：人读详情页绝对地址。
  8. updated：内容最后更新日期 YYYY-MM-DD（非首次发布日）；暂无则上线时填写。

2. 标题与摘要（必填）

  1. 说明：课程正式名称，以及一两句介绍（学什么、覆盖哪些环节）。
  2. 写法：一级标题 # 课程名；下一行以 > 写摘要，对齐人读页简介。

3. 课程概要（必填）

  1. 说明：面向选课与推荐的基础信息；对应人读页横幅区（Tab 之上），勿写入「课程介绍」。
  2. 写法：二级标题 ## 课程概要；下列 - 字段名：内容，一行一项。
  3. 适用对象：明确人群，可附能力诉求。
  4. 学习目标：完成本课后的综合能力（一句话）。
  5. 能力等级：如 入门、中级、进阶；与人读页难度口径一致。
  6. 学习时长：与人读页口径一致；须明确是否含视频、阅读、实操时间。
  7. 关联场景：如 算子编写与调用。
  8. 关联产品：如 CANN · Ascend C。
  9. 环境要求：开发 / 仿真 / NPU 等条件；无人读页依据则可省略本行。

4. 预备知识（条件必填）

  1. 说明：区分强制门槛与建议预习，降低 Agent 对学习门槛的误判。
  2. 写法：二级标题 ## 预备知识；下设 ### 必备基础、### 推荐学习。一行一项；有链接用 - [名称](https://…)。

5. 知识点（条件必填）

  1. 说明：本课程覆盖的知识主题，便于检索与问答。
  2. 写法：二级标题 ## 知识点；一行一个短主题。可在括号内补充真实专业同义词，勿堆砌无关关键词。

6. 课程介绍（必填）

  1. 说明：写清学完后的可观察目标；摘要已在标题下 > 写过的，此处勿重复粘贴。
  2. 写法：二级标题 ## 课程介绍；下设 ### 课程目标，按人读页抄为编号列表。目标优先写成可观察行动（如「能…」「说明…」）。

7. 课程目录（必填）

  1. 说明：按章交付材料与视频，供 Agent 按章定位，而非只读课程卡片。
  2. 写法：二级标题 ## 课程目录；各章用三级标题 ### 第 N 章 · 名称，章名按人读页抄写，编号须连续。
  3. 学习材料 / 视频：各两行——上一行人读绝对 URL，下一行镜像 .md 绝对 URL；先人读、后 Markdown。
  4. 深链：优先材料 / 视频自身地址。现网暂无独立深链时，示例暂用课程页与 ….md 占位，上线前换成真实 URL。

8. 实操与实验（条件必填）

  1. 说明：与本课程配套的实操 / 实验资源。
  2. 写法：二级标题 ## 实操与实验；每条 - [名称](https://…)：一句用途说明。

9. 学完之后（条件必填）

  1. 说明：学完本课后的推荐去向，帮助回答「下一步学什么」。
  2. 写法：二级标题 ## 学完之后；可写 推荐学习路径 / 推荐认证 等，值为可点链接，认证可附级别与一句能力说明。

发布前核验

  1. 链接：均为 https 绝对地址；可访问；指向预期资源正文（非栏目首页、安全验证页或登录拦截页）。HTTP 200 不等于正文有效。
  2. 目录：章名与人读页一致；学习材料 / 视频的人读与 .md 成对；占位 ….md 不得直接上线。
  3. 一致：人读页与 Markdown 的课程名、目标、章节、资源名称保持一致。
