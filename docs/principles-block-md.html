块级 Markdown

架构图、规格表在 HTML 里排版复杂，机器直接抓取容易退化为截图。由于 Agent 无法读取截图，其中的结构与数值会随之丢失。 因此，需为这类强视觉块提供平行的块级 Markdown，保证关键信息能被直接提取。

Agent 是如何取到块级 Markdown 的

主路径 · 通用发现层

按行业通用惯例，直接探测根目录或文档站子路径下的 llms.txt，从中 Fetch 该块的 Markdown 地址。该块地址需在清单中显式列出，确保路径可追溯。

兜底入口 · 内容层

无需前置条件。当已抓到 HTML 且未通过发现层取得该块稿时，Agent 可直接跟从楼层标题旁（main 内）的「打开块 Markdown」真链，获取对应的块级 .md。

核心原则

  • 主次分明主路径为 llms.txt 显式列出的块级地址（详见发现层部署）；楼层真链仅作兜底。不依赖私有锚点改写规则；整页 Markdown（见页级 Markdown）不能替代块级稿。
  • 打开是真链入口固定于楼层标题旁、main 区域的真实 <a> 标签。锚点、无字图标、页级入口及源码链均不可替代。

执行要点

  • 指向约定路径href 需指向该块平行 .md 的绝对地址，并带上精确锚点（如 …/platform-stack.md#ascend-platform），仅指向整页的 # 锚点不能作为该块的入口。
  • 名称写在链上有文字位时，文案直接写「打开块 Markdown」或「打开 Markdown」。仅用图标时，在 <a> 上添加 aria-label="打开块 Markdown"（可同时设置 title），img 的 alt 留空。避免使用「更多」「MD」「AI」等容易让机器或用户混淆的词。
  • 保持首包真实Agent 无法点击页面视觉元素，可识别的是源码里的真实 href。入口需位于首包 main 区域内已存在的 <a> 标签中；不使用 CSS background-image 绘制图标，也不通过悬停注入 DOM。

价值收益

  • 提供纯净正文入口楼层标题旁增设「打开块 Markdown」，供用户直接获取该层或该表的平行 .md，不必在整页长文里翻找。
  • 兜底抓取路径未读 llms.txt、或清单未列该块时，main 内楼层真链仍能稳定带到同一块 .md，避免跨层、跨表问答中断。
