隐藏的语义（折叠面板） 抓取差

折叠隐藏语义指默认收起区内的正文——用户需点击展开才能看到的硬件确认指引，默认抓取常只入库标题、丢失区内步骤。 以 CANN 软件下载 中的「我不知道硬件信息」折叠面板为分析聚焦。

问题实测

1. 向模型提问

我在看 CANN 软件下载（CANN 9.0.0），不太确定自己的昇腾硬件型号，应该怎么确认并选对的 CANN 安装包？

2. 大模型回答

查看大模型回答内容

3. 问题洞察

大模型的回答指向两点结论：

  • 折叠区未入库：「我不知道硬件信息」面板默认收起，区内硬件确认与选型步骤在 display:none 中——chunk 可能仅有标题七个字。
  • 选型链路断裂：与 Tab 选型叠加时，「不知硬件 → 不知如何选 CANN 包」的指引对 RAG 不可见。

根因分析

折叠隐藏语义丢失的核心原因是：默认收起、管道跳过隐藏 DOM、折叠标题无区内正文。

1. 默认收起

关键步骤收纳在折叠体内，默认 DOM 不可见。

修改建议

折叠区默认展开，或同时提供全量展开版本。

2. 管道跳过隐藏区

默认抓取跳过 display:none，区内步骤不入库。

修改建议

机器层将折叠内容全量展开，以 H3 标注各面板标题。

3. 标题代替正文

chunk 仅含折叠标题，无可执行步骤。

修改建议

折叠标题 + 区内步骤须同时进入机器层 MD。

4. 人机层未双轨

人类保留折叠 UI，RAG 无预展开副本。

修改建议

RAG 优先抓取预展开 MD（见 折叠默认展开）。

    下载页通常有「我不知道硬件信息」等折叠区，展开后会给出确认硬件型号的步骤。

    若折叠区默认收起且未全量展开入库，我可能只读到标题、看不到区内步骤，从而无法完整回答如何确认型号并选对安装包。
