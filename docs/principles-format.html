Markdown 正文可直取概述

Markdown 正文可直取，是指为人读 HTML 中需要知识背书的事实，额外提供一份可直接打开、无需渲染的 Markdown 正文。两份内容使用同一套事实：人读页负责浏览与排版，机器稿负责检索、入库与引用。

能被抓到不等于该被引用。导航壳、营销首页不铺平行正文；仅在官方愿为这段事实做知识背书时提供。人读页可保留视觉设计，但机器侧须打开即可读到结构完整的事实正文，不依赖 JavaScript 渲染或复杂排版抽取。

具体原则

  1. 对需要知识背书的页面提供可访问的平行 Markdown，打开即可读取标题、正文、步骤、表格和链接。
  2. 人读 HTML 与 Markdown 使用同一套事实，随发布同步更新，不为机器另起一套文案。
  3. Markdown 不设登录或浏览器门槛，不依赖人读页 JavaScript 渲染即可获取。
  4. 人读页为首包空壳或复杂排版难以抽取时，必须提供机器可读正文。
  5. 在 llms.txt 中列出对应 .md 地址，或在人读页声明 rel="alternate" / 页内入口，使 Agent 能够发现该正文。

标题与标语 开篇 章节

元素拆解

页顶索引

  1. 页顶索引用引用块指向分册或根 llms.txt，告诉 Agent 先扫站点地图再读本页。该部分可选；人读页没有对应区块。

标题与导语

  1. 标题用 # 写与人读页同一标题，是必填项。
  2. 导语紧跟开篇段落或 > 引用块，与人读页同一事实。必填，写成完整句子。

章节

  1. 章节名每个章节一行 ## 标题，与人读页层级一致。
  2. 要点写成完整句子，不依赖截图或交互才能读到。

链接

  1. 链接格式一条一行，写作 - [标题](地址)。标题用页面名，不用 URL。
  2. 链接指向相关主题指向对应 .md 或可直取正文；说明宜短，可选。

- [环境准备]标题 (https://www.hiascend.com/document/…/atlas_ascendc_map_10_0003.html)地址

机器如何发现 Markdown

方式一：试约定路径

  1. AI Agent 把当前人读页的 .html 换成同路径 .md，作为页级平行稿。
  2. 块级稿在同一 .md 上加楼层锚点，或打开清单里写明的独立块文件。
  3. 改后缀只有写进 llms.txt 或页内声明后才高置信；未声明时不要盲试。

方式二：读 llms.txt

  1. 先打开网站根或分册 llms.txt，再跟清单里列出的 .md 地址。
  2. 页级一条一行；块级可带锚点，或写成独立块文件。发现清单本身见机器如何发现 llms.txt。

方式三：读 HTML 源码

  1. 在 <head> 用 <link rel="alternate" type="text/markdown"> 声明本页平行稿。
  2. 可用 rel="describedby" 同时指向覆盖本页的 llms.txt。非 HTML 可改写在 HTTP Link: 头。

方式四：跟页内入口

  1. 页级：H1 同一行放「打开 Markdown」真链，指向整页平行 .md。
  2. 块级：楼层标题同一行放「打开块 Markdown」真链，指向该块 .md 或带锚点地址。整页稿不能替代块级稿。
  3. 「复制 Markdown」给人读；Agent 跟的是源码里已存在的 <a href>，不要用 CSS 图标或悬停注入。

预期效果

  1. 提高不同 AI Agent 获取知识正文的兼容性与稳定性。
  2. 减少因页面渲染失败、排版噪声或交互未触发造成的事实遗漏，使引用可回查。

注意事项

  1. 提供 Markdown 不能替代人读页 HTML 可读；两边应对同一套事实，并随发布同步更新。
  2. 允许抓取不等于一定会被引用；导航壳、营销楼层不要铺平行正文。
  3. 在 llms.txt 列出对应地址，或在人读页声明 rel="alternate" / 页内入口，避免 Agent 只能猜测后缀。
