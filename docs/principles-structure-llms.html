机器发现层部署

在站点层部署机器发现层（llms.txt、llms-full.txt、sitemap.xml、robots.txt），声明机器应从哪条 URL 抓取、主推哪一版文档。同时在人类浏览页提供可见的「机器可读版本」入口，避免 Agent 与合规爬虫只能沿渲染页路径抓取。 找的到 · 序号 1 · 对应 实测问题 · 机器发现层缺失 · 完整条目见 全量亲和原则 #1。

部署对象

对象 描述
robots.txt 站点爬取规则：声明哪些路径允许抓、哪些禁止抓，并指向 Sitemap。
sitemap.xml 站点 URL 清单：列出应被索引的页面及更新时间。
llms.txt 面向大模型的站点索引：按产品线/版本列出推荐抓取的文档入口。
llms-full.txt 面向大模型的全文包：将索引文档的 Markdown 正文聚合为单文件。

部署 robots.txt

前端调整·建议

  • 按业务站点列出 Sitemap：用多条 Sitemap: 声明各产品线 / 文档子系统的 sitemap 或 index，而不是只挂一个笼统入口。
  • 授权智能爬虫通行：对 AI/LLM UA 显式 Allow 机器可读路径（*.md、llms.txt、*.llms.txt），并默认开放站点主体，避免「有 sitemap 却被 robots 封死」。
  • 声明可被 AI 使用：在默认策略中给出 Content-Signal（如允许检索 / 作为 AI 输入），降低合规爬虫对抓取意图的歧义。
  • 搜索引擎与 AI 分组：传统搜索 UA（Googlebot / Bingbot）与智能爬虫分块声明，便于后续差异化放行或限流。
  • 屏蔽噪声参数：Disallow 追踪与高亮类 query（utm、ncid、nvid、highlight 等），避免重复 URL 稀释索引。

前端调整·示例

Before · 封锁机器源

robots.txt

User-agent: *
Disallow: /doc_center/
Disallow: /assets/

Sitemap: https://www.hiascend.com/sitemap.xml

sitemap 声明有文档，robots 却封死 /doc_center/，爬虫拿到链接后直接被拦截。

After · 放行机器路径

robots.txt

User-agent: *
Allow: /doc_center/source/
Disallow: /assets/
Disallow: /api/

Sitemap: https://www.hiascend.com/sitemap.xml

机器源与 llms 入口可抓；噪声路径与追踪参数屏蔽。

部署 sitemap.xml

前端调整·建议

  • 优先收录 source 路径：/doc_center/source/ 下的机器源路径 priority 高于渲染页，lastmod 从文档 dateModified 自动同步。

前端调整·示例

Before · 只收录渲染页

sitemap.xml 片段

<url>
  <loc>https://…/document/detail/…/operator_dev.html</loc>
  <priority>0.5</priority>
</url>

收录 ~224 KB 渲染壳层，导航栏等噪声稀释正文语义。

After · 优先 source 路径

sitemap.xml 片段

<url>
  <loc>https://…/doc_center/source/…/operator_dev.md</loc>
  <lastmod>2026-06-01</lastmod>
  <priority>0.9</priority>
</url>

机器源优先索引；lastmod 与文档 dateModified 自动同步。

部署 llms.txt

设计UI调整·建议

  • 页脚标出站级机器入口：在页脚次要区用小字链标出 llms.txt，文案可读、可跟链；禁止只靠隐式约定或图标。
  • 不抢主路径：入口视觉权重与页脚其他次要链接一致，不突出也不隐藏；文档中心等已有同等清晰站级入口时可免重复挂链。

设计UI调整·示例

页脚标出站级机器入口

反面

正文与主路径区域（略）

  • 法律声明
  • 隐私政策

© 昇腾社区

  • 常见疏漏：页脚未标出 llms.txt，机器与审计无法从版面跟到站级清单。

设计专项完整示例见 机器可读入口可发现。

前端调整·建议

  • 部署 /llms.txt：按产品线-版本分组，构建管道从 CMS 文档元数据自动生成，文档发布时自动更新，不依赖人工维护。
  • <head> 中注入机器发现标签：每个页面自动输出 <link rel="llms" href="/llms.txt"> 和 <link rel="alternate" type="text/markdown" href="对应 source 路径">，由页面模板统一生成。

前端调整·示例

<head> 机器发现标签

Before

HTML 源码

<head>
  <title>Ascend C 算子开发</title>
  <link rel="canonical" href="/document/detail/.../operator_dev.html">
</head>

无 llms / alternate 声明，Agent 只能沿用人类渲染页 URL。

After

HTML 源码

<head>
  <title>Ascend C 算子开发</title>
  <link rel="llms" href="/llms.txt" type="text/markdown">
  <link rel="alternate" type="text/markdown"
        href="/doc_center/source/…/operator_dev.md">
  <link rel="canonical" href="/doc_center/source/.../operator_dev.md">
</head>

页面级声明站点索引与本文机器源，模板统一输出。

部署 llms-full.txt

前端调整·建议

  • 部署 /llms-full.txt：构建管道从 /doc_center/source/ 自动聚合所有索引文档的 Markdown 全文为单文件，随文档发布自动重新生成。
