视觉层

图标文本化

含义图标须写成名称；数字可用单位表意。

原则概述

原则：图标不独自表意

  • 图标用于辅助识别，其承载的字段、类型或量纲信息须有对应文字交付。图标本身可保留，但不得作为信息传递的唯一载体。图标旁出现数字时，须附单位标明量纲；若已有名称，可仅补充单位。上下文已明确表达同一含义，或图标纯属装饰时，可不重复加注。（状态图标详见 状态文本化）

对 AI 的好处

  • 字段名、量纲单位落在可抓取文字上，AI 无需从图标猜测含义；数字配套单位后可直接入库，避免只读到图形或裸数。

核心原则：类型图标须写成名称；日期须写明是何种时间。

公告 社区版 昇腾CANN 9.1.0版本发布 2026/07/31 发布
