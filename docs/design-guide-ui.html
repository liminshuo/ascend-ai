UI 规范

正文排版

说明性正文、场景描述、原则条目，统一用下列字号与行高；标题与原则页 fn-h* 同源 token，避免页与页之间忽大忽小。

层级Token值用途
H1 --text-h1 / --text-h1-lh clamp(28–40px) / 48 页标题（.page-header h1）
H2 --text-h2 / --text-h2-lh 24 / 36 · 底线 pad --space-h2-rule: 16px 区块标题（.section h2）
H3 --text-h3 / --text-h3-lh 18 / 28 · 上下 pad --space-h3-pad-y: 24px .section h3 与 h3.fn-h3 同源
H4 --text-h4 / --text-h4-lh 14 / 22 · 底 pad --space-h4-pad-b: 16px .section h4 与 h4.fn-h4 同源
正文 --text-body / --text-body-lh 14 / 22 正文默认字号
辅助 --text-auxiliary 12 / 20 辅助说明

这是正文示例：适用场景、要求、原因，以及亲和原则条目，均按 14 / 22 排版。
