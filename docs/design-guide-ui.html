UI 规范

设计指导页共用的基础视觉与排版约定，先定正文，再叠层级。

正文排版

说明性正文、场景描述、原则条目，统一用下列字号与行高，避免页与页之间忽大忽小。

Token值用途
--body-size 14px 正文默认字号
--body-lh 22px 正文默认行高

这是正文示例：适用场景、要求、原因，以及亲和原则条目，均按 14 / 22 排版。

font-size: 14px · line-height: 22px

  • 统一：设计指导各页正文默认 14px / 22px，用 CSS 变量 --body-size、--body-lh 引用。
  • 例外：H1 / H2 / 标签 / 标注圆点等层级元素可另定尺寸，不占用正文规格。
