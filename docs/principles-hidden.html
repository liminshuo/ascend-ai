交互不藏关键正文

解决什么问题

Agent 拿不到被交互藏起来的步骤与结论（如：非激活 Tab、默认收起的折叠、只在悬停里的定义、被蒙版挡住的安装命令）。

核心原则

交互不藏关键正文

关键步骤、定义与命令须在默认态、首包 HTML 中可读。Tab / 折叠 / 悬停 / 蒙版只控制显隐，不能当唯一出处；禁止用 display:none、默认收起、悬停注入或模糊遮罩把正文从可读流拿掉。

典型示例

Tab · 各面板写入 Markdown 与源码

界面可以用 Tab 切换；Markdown 与首包 HTML 仍须写出全部栏目与卡片标题。
