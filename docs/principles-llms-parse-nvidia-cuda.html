CUDA 产品分册

解析什么

对照 CUDA 产品册 https://docs.nvidia.com/cuda/llms.txt。从文档站总册的 CUDA Toolkit 跟过来。这一本按任务分节，叶子是各页平行稿，不再套 llms.txt。

它在解决什么

CUDA 文档覆盖安装、编程模型、架构调优、API、工具。文档站总册不能为每一个产品摊这么多页。产品册只服务这一条产品线。

这本分册怎么摊开

  • 按任务分节安装、编程指南、架构、API、工具分开，不是把站点树原样搬家。
  • 叶子是页多数链 index.html.md 平行稿；个别仍是 HTML 或站外文档。
  • 没有第 4 层条目不再指向另一本 llms.txt。

分册交付示例

对照 CUDA 产品册的结构。全文按任务分很多节，这里只摘页顶、安装、编程指南。其余节同一写法：标题 + 各页地址。

产品线 llms.txt 交付件拆解

对照 docs.nvidia.com/cuda/llms.txt：一条产品线的页目录。下一跳是页，不是再一本 llms。

页顶

标题即产品范围。下面一段说明覆盖安装到工具，告诉 Agent 这本册子装的是整条 CUDA 文档面。

按任务分节

节名是任务（安装 / 编程），链接文案也是何时读这一页。Agent 按任务选页，而不是先解析站点路径。

叶子地址

主路径是 index.html.md 平行稿。现网仍有只给 HTML、或链到站外文档的条目，那些页没有 Markdown 孪生稿。

价值收益

  • 产品线读得完只摊 CUDA，不混入 NIM / NeMo。
  • 能落到页安装、编程、API 各有地址。
  • 嵌套到此为止NVIDIA 文档路径最深三层 llms，这一层不再套。
