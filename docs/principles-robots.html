配置 robots.txt 许可声明

robots.txt 概述

robots.txt 是网站根目录下的一个纯文本文件，用于告诉爬虫（crawler / bot）哪些页面可以抓取，哪些页面不要抓取。

基于 RFC 9309（Robots Exclusion Protocol）的约定，robots.txt 入口固定为网站根路径 https://{域名}/robots.txt。遵循协议的 Agent 会主动读取该文件，并依据其中规则决定抓取范围；未遵循协议的 Agent 不受其约束。

具体原则

  1. 在网站根目录提供可访问的 robots.txt 文件，确保抓取规则可被爬虫识别。
  2. 根据内容开放范围配置 Allow 与 Disallow 规则，放行公开知识内容，限制非公开资源，避免误将需发现内容设置为禁止抓取。
  3. 在 robots.txt 中声明站点地图（Sitemap）地址，为搜索引擎爬虫提供公开 URL 发现入口。
  4. 在 robots.txt 中声明机器可读的 llms 访问路径，为 AI Agent 提供知识内容发现与获取入口。

预期效果

  1. 帮助 AI 爬虫发现公开内容，并识别允许抓取的范围。
  2. 减少因入口缺失、链接失效或规则误设导致的内容遗漏，为后续检索和引用提供基础。

注意事项

  1. robots.txt 用于声明抓取规则，不能代替身份验证和访问权限控制，也不能保证所有爬虫遵守。
  2. 允许抓取不等于一定会被索引或引用；站点地图也不保证内容被收录。
  3. 开放范围应与内容权限保持一致，避免为了提升可发现性而开放敏感或非公开内容。
