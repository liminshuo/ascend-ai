NVIDIA（md）分析 · 可引用性·内容（md）分析

引用后是否有价值：正文是否结论前置、事实原子化，以及是否值得维护平行 Markdown。 缺口归内容生产，与管道配置分开排期；营销口径默认不当知识源。

实施建议

  • 准入 MD 的标准（事实与结构层）：产品能力说明、行业用例与方案结构、平台可调用入口（如 Inference Endpoints / Skills）等可核对内容可进 MD。行业总览宜收敛为行业目录与报告入口；知识叶子应能让 Agent 直接取到稳定表述。
  • 排除 MD 的标准（壳、转化与说服层）：站壳导航、筛选控件、视频播放器 UI、客户 Logo 墙与实时活动流、Cookie 浮层等应留人读 HTML。壳页即使技术上能出 MD，也不应把「几乎无可引用事实」的过滤界面当正文背书。
  • 楼层切片逻辑：营销产品页常把叙事、用例、新闻一并推进 MD；点播壳页则往往只切出极薄目录。同一流水线交付，密度可以差一个数量级——分析要以楼层对照，不以「有 md」一刀切。
  • 有目录 ≠ 有 MD：是否进 llms.txt 与是否存在平行 Markdown 是两道闸。例如 NGC Catalog 可出现在开发者目录，却无平行 MD——Agent 发现了入口，仍缺可解析正文（有 llms 收录、无 Markdown 可读）。对照见可达性侧 NVIDIA 分析。
