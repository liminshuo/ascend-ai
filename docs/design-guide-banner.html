组件亲和

Banner

入口与活动 Banner 要有独立文案层；运营口号帧可不做亲和，勿当规格源。

Pattern说明

场景定义

  • 入口与活动 Banner 承载标题、摘要或 CTA，字不得只烧进图时，适用本 Pattern；运营口号帧可例外。

AI 亲和设计原则

信息呈现

  • 分类：按用途分为入口 Banner、活动招揽 Banner、运营口号 Banner；字不得只烧进图。
  • 叠字可抓：标题与摘要须是独立 DOM，允许视觉叠在图上；像素字机器抠不到。
  • 明示：关键说明须默认可见；悬停、当前帧以外的文案不得作为唯一出处。

交互实现

  • 真链：可点击处须为真实链接 a[href]，禁止 button 伪链或只写「了解更多」。
  • 轮播：全量帧进首包；入口帧白名单交付三要素；运营帧标 exclude，不当规格源。

入口 Banner

入口 Banner 把人送进产品、专区或文档。默认要做亲和：标题与摘要须为独立 DOM，可点须为真链。

亲和原则

适用场景：首页或专题上可点击的产品 / 专区入口帧。

原因：机器无法从海报像素推断「是什么、去哪」；字烧进图则无法入库。

解构

  1. 1背景图：辅助氛围；可忽略，不得作为唯一信息出处。
  2. 2标题文案（必要）：写明对象名，须为独立 DOM。
  3. 3描述文案（必要）：一句话可引用摘要，写清品类或去向。
  4. 4按钮文案（可选）：写明动作与对象（如「进入专区」）；勿只写「了解更多」。
  5. 5真链（必要）：标题、按钮或整帧须为真实链接 a[href]。

活动招揽 Banner

活动招揽 Banner 用于训练营、认证、报名。默认要做亲和：活动名须写在卡面 DOM 里，可点须为真链。

亲和原则

适用场景：活动目录、专题页上的招揽帧（点进去看活动或报名）。

原因：活动名、场次烧进海报则目录里列不出有什么活动。

解构

  1. 1背景图 / 海报：辅助氛围；可忽略，不得把活动名只画在图里。
  2. 2标题文案（必要）：写明活动名。
  3. 3描述文案（必要）：一场次或一句话去向（如「学习认证专场」）。
  4. 4按钮文案（可选）：写明动作（如「查看活动」「立即报名」）。
  5. 5真链（必要）：可点击处须为真实链接 a[href]。

修改

  • 补独立文案：活动名与一场次写成 DOM，允许叠在图上。
  • 保持真链：整帧或按钮为真实 a[href]，指向活动页。
  • 积分细则进正文：海报里的权益说明放到活动页，不必全部爬进 Banner。

运营口号 Banner

运营口号 Banner 只做氛围或营销口号。是否做亲和，看它是否当入口或规格源：纯口号则不必做；不要把它当产品事实入库。

不必做亲和

适用场景：首页轮播里的氛围口号、与产品规格混层的运营帧；稿面标 exclude，不当规格源。
