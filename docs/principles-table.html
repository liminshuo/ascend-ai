表格语义可结构化

解决什么问题

Agent 切片后拿不到可查询的表结构，只能看到打散、互不相属的单元格。

核心原则

表骨架可机读

表头由表格组件给出。须写出能点名的表题，并用合法合并表达行列归属；格内列表独立成结构。能力格须写成「支持 / 不支持」，禁止只靠对号或空格。

典型示例

合并与分组可还原

合并后每格仍能还原行名 × 列名；Markdown 无 rowspan 时逐行写全场景名，HTML 用 rowspan + scope 呈现合并。

格内状态写成词

能力矩阵的单元格须写成「支持」「不支持」；对号可保留作辅助，空格不得暗示不支持。

价值收益

  • 行列可切片还原入库后仍能回答「某场景 × 某芯片是否支持」，而不是丢了行头的碎片。
  • 主题可点名描述性 caption 让引用能落到具体规格表，而不是「见上表」。
  • 能力可点名格子里能读出「支持 / 不支持」，而不是对号或空白。
