活动规划如何枚举

月轴与月历都是壳；首包须能枚举活动名、时间或地点，可点则带真链。

原则概述

原则：活动写成可枚举条目

  • 时间轴、月历格子、色点、点选展开都是壳；事实是每一场活动的名称、时间或地点，可点则真链。
  • 默认 / 首包须能枚举活动；格子上的图标不能单独表示「有日程」。点日期才注入详情、默认空态，不可取。

对 AI 的好处

  • 不点日期、不猜色点，也能列出有哪些场；月历壳可保留给人用。

场景说明

活动中心、年度规划、开发者日历常见两种壳：时间轴 / 月份轨道，或月历 + 右侧详情。人可扫疏密、点日期；机器要能枚举每一场。

  • 页型：活动中心、社区日历、开发者日程
  • 对应页面：昇思 MindSpore · 活动中心
  • 订阅、创建会议、授权报名可标可不做亲和

方式选型

三种交法，自上而下按推荐程度。月轴 / 月历都可留着给人用；关键是活动条目默认可抓。

亲和说明

  • 推荐：月轴或月历可留；每场活动名 + 时地 +（可点则）真链，默认 / 首包可枚举。
  • 可接受：按类别列出；或「全部 / 会议 / 活动」筛选，但默认态有结果。
  • 不推荐：只有落点 / 整图日历；或点日期才注入详情、默认空态。
  • 「TBD」可作状态，活动名仍要有。订阅 / 创建会议 / 授权可标可不做亲和。
