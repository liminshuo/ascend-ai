标题层级可识别

原则定义

标题层级用于表达页面主题、层次与从属关系。仅靠字号、粗细或排版区分，或使用「概述」「介绍」等空泛标题，AI Agent 难以准确识别结构与章节意图。

须使用规范的标题标签、连续的层级，以及描述性、面向任务或概念的标题文案，便于定位与引用。

元素拆解

级别标题

层级由标题标签表达；字号仅作视觉呈现。标题文案须具体可描述，反映下方内容意图。

H11Add算子快速入门

Add算子功能介绍

H22算子设计

H33Device 端核函数接口

Host 端运行时接口

视觉规则

  1. 1H1页面主旨标题；文案具体，不使用「概述」等空泛词。
  2. 2H2一级分节；与 H1 从属连续，不跳级。
  3. 3H3章节下的细分主题；标题可独立理解下方内容意图。

前端规则

  1. h1–h6使用真实标题标签；Markdown 用 # 至 ######。不以字号、加粗或普通段落冒充。
  2. 层级连续按内容从属设置级别，避免无依据跳级；标题语义与视觉层级一致。

示例如下：

<h1>Add算子快速入门</h1>
<h2>算子设计</h2>
<h3>Device 端核函数接口</h3>

编号标题

用数字序号写出从属关系（如 1 / 1.1 / 1.2.1）。字号可统一，不靠字号区分层级；与级别标题二选一，不叠加。

一级11 Add算子快速入门

1.1 Add算子功能介绍

二级21.2 算子设计

三级31.2.1 Device 端核函数接口

1.2.2 Host 端运行时接口

视觉规则

  1. 1一级写成「1 标题」；序号进入可读文本，不单靠缩进表达层级。
  2. 2二级写成「1.1 / 1.2」；与一级从属可直接读出。
  3. 3三级写成「1.2.1」；与上级编号连续，不跳号。

前端规则

  1. 序号入文编号写在标题文本节点中（如 1.2 算子设计），不以纯样式伪元素代替。
  2. 二选一编号与级别标题二选一表达从属，不在 H3 下再叠写 1.1。

示例如下：

1 Add算子快速入门
1.2 算子设计
1.2.1 Device 端核函数接口

适用边界

上述规则适用于文档与产品页中，标题大纲需要被 AI 识别、检索或引用的场景。

级别标题与编号标题二选一表达从属，不叠加；层级依据内容结构确定，不为纯视觉排版而设。
