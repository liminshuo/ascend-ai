代码源码可复用

为了帮助 Agent 入库后可直接复用命令与示例，代码块须标注语言与场景、分离行号、还原 HTML 实体，确保抓取文本为干净源码。

适用对象

名称 说明 常见落点
语言标注 代码块须标明语言（如「Bash」「Python」），禁止仅靠高亮推断。 命令块、示例代码
预期输出 成功输出须以独立文字块呈现，禁止截图展示。 命令结果、运行回显
代码行号 非必要不展示行号；若展示，须与可复制命令正文分离。 报错对照、逐行讲解

适用场景

优先级 页面类型 说明
必做 文档站命令块、安装 / 编译 / API 示例 Agent 最常复制与引用的可执行事实。
建议做 官网 SDK / 能力页示例代码 示例进引用池时，须语言可辨、源码干净。
可不做完整改造 纯装饰伪代码、无执行意图的短片段 不承载可运行命令，且正文已覆盖同一事实时，可只作示意。

设计UI调整

调整建议

  • 语言与输出成文 块顶须标明语言；预期输出写成独立文字块，禁止以截图承载结果。
  • 行号不污染正文 非必要不展示行号；确需对照报错或逐行讲解时，行号不得混入可复制、可抓取的命令文本。

调整示例

用文字标明代码语言

反面

npu-smi info ascend-dmi -a

  • 常见疏漏：块顶未标明语言，机器无法识别是 Bash 还是 Python。
正面

Bash

npu-smi info ascend-dmi -a

  • 正确做法：块顶写成「Bash」等语言名。
  • 可免场景：整页已统一声明所用语言时，可省略。

用独立文字块呈现预期输出

反面

Bash

npu-smi info

  • 常见疏漏：仅有命令，未配输出文字块，机器无法识别成功时的设备状态。
正面

Bash

npu-smi info

Output

NPU 状态为 OK，设备列表可见。

  • 正确做法：预期输出写成可选中的独立文字块，说明成功长什么样。
  • 可免场景：命令无输出，或正文已写明成功判据时，可不另附输出块。

行号不混入可复制正文

反面

Bash

1 npu-smi info 2 ascend-dmi -a

  • 常见疏漏：行号混入命令正文，抓取或复制后会污染命令（如「1 npu-smi info」）。
正面

Bash

npu-smi info ascend-dmi -a

  • 正确做法：可复制内容不含行号。
  • 可免场景：需对照报错行或逐行讲解时，可显示行号，但须与命令正文分离。

文档内容调整

调整建议

  • 围栏标明语言与场景 Markdown 围栏写清语言（如 bash、cpp）；必要时在块前或注释中写文件名与场景，便于切片作元数据。
  • 示例尽量可独立运行 关键步骤自包含；执行类示例在块后提供「预期输出」文字，勿只写「见截图」。
  • 源稿不写行号 行号由前端渲染；稿面与平行 MD 禁止手动写入「1 command」式污染文本。

调整示例

语言标注 + 预期输出块

反面 
```
__aicore__ inline void Add(...) {
    Add(z, x, y, TILE_LENGTH);
}
```

← 无语言、无预期输出
  • 常见疏漏：围栏无语言；成功判据缺失，机器难复用。
正面 
```cpp
// kernel_add.cpp · Ascend C · 矢量加法
__aicore__ inline void Add(
    const LocalTensor<float> &z,
    const LocalTensor<float> &x,
    const LocalTensor<float> &y) {
    Add(z, x, y, TILE_LENGTH); // 向量加法
}
```

**预期输出：**

```
[INFO] kernel Add executed successfully.
```
  • 正确做法：围栏语言 + 场景注释 + 可选取的预期输出。

前端调整

调整建议

  • 用 pre / code 语义结构 首包以 <pre><code class="language-xxx"> 输出；禁止用 highlighttable 等表格布局承载源码。
  • 行号仅 CSS 渲染 行号用 CSS counter 等与文本节点分离；复制与切片拿到的须是无行号纯净源码。
  • 实体还原与 chunk 绑定 入模前还原 HTML 实体；语言类名与 code-meta 写入 chunk 元数据；输出块与对应命令同 chunk，不拆散。

调整示例

用 pre / code 替代 highlighttable

反面 
<table class="highlighttable">
  <tr>
    <td class="linenos">1</td>
    <td class="code">…</td>
  </tr>
</table>

← 行号进文本节点，污染切片
  • 常见疏漏：表格布局把行号与源码绑在一起，复制与入库均被污染。
正面 
<pre><code class="language-cpp">
__aicore__ inline void Add(
  const LocalTensor<float> &z,
  const LocalTensor<float> &x,
  const LocalTensor<float> &y) {
    Add(z, x, y, TILE_LENGTH);
}
</code></pre>

← 文本节点仅源码；行号用 CSS
  • 正确做法：language-xxx 可提取；行号不进文本节点。
