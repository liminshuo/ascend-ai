代码块语义化

代码块标注语言与场景、分离行号、还原 HTML 实体，确保入库源码干净可直接复用。 读的懂 · 序号 8 · 对应 实测问题。

设计UI调整

调整建议

  • 代码块顶栏交代语境：稿面预留语言 / 文件名（或场景一句）；复制按钮可有，但元信息须可见。
  • 行号勿进可选中正文：行号只作视觉装饰，设计上不把数字画进可复制文本区。
  • 执行类示例配「预期输出」位：输出块与代码区分开；标题固定「预期输出」，勿散在正文段落。

调整示例

示例1. 裸代码 → 语言栏 + 输出位

✗ 错误示范 · 无元信息

#include <acl/acl.h>
int Init() { … }

无语言栏 · 无复制 · 无预期输出

语言与场景不明；输出散落。

✓ 推荐做法 · 顶栏 + 独立 Output

Shell C++ Python 
#include <acl/acl.h>

int Init() {
  return aclInit(nullptr);
}
Output 
ACL_SUCCESS (0)

要点：顶栏语言 / 源码 / Output 三层分明。

示例2. 预期输出独立成块

✗ 错误示范 · 输出散在正文

run_add.sh · bash
bash run_add.sh
运行后控制台会打印成功信息。

输出混在正文，无法与代码块绑定

Agent 对不上「这段输出属于哪段代码」。

✓ 推荐做法 · 紧随 Output 块

Bash 
bash run_add.sh
Output 
[INFO] kernel Add executed successfully.
elapsed time: 2.3 ms

要点：源码与 Output 成对深色块，不进正文。

文档内容调整

调整建议

  • 围栏标注语言：每个代码块写清语言（如 ```cpp）；关键行加短注释。
  • 源码文本勿选手写行号：行号留给渲染；示例尽量可复制运行。
  • 执行类附预期输出：代码后紧跟「预期输出」块，勿只写「运行后会成功」。

调整示例

示例1. 无语言围栏 → 语言 + 输出

✗ 当前问题 · 无语言、无输出

```
__aicore__ inline void Add(...) {
    Add(z, x, y, TILE_LENGTH);
}
```

✓ 推荐做法 · 语言 + 注释 + 预期输出

```cpp
// kernel_add.cpp · Ascend C · 矢量加法算子示例
__aicore__ inline void Add(
    const LocalTensor<float> &z,
    const LocalTensor<float> &x,
    const LocalTensor<float> &y) {
    Add(z, x, y, TILE_LENGTH); // 执行向量加法
}
```

**预期输出：**

```
[INFO] kernel Add executed successfully.
```

语言元数据与输出可一并切片。

前端调整

调整建议

  • 用 pre > code，弃用 highlighttable：language-xxx 标语言；行号用 CSS，不进文本节点。
  • 入库前还原实体：切片拿到的是可读源码，而非 &lt; 污染串。
  • 切片规则：chunk = 语言 / 文件名（若有）+ 源码 + 紧邻预期输出；输出与源码绑定不拆。

调整示例

示例1. highlighttable → 纯净 pre/code

✗ 当前问题 · 表格塞行号

<table class="highlighttable">
  <tr><td class="linenos">1</td>
      <td class="code">…</td></tr>
</table>

✓ 推荐做法 · 纯净 pre/code

<pre><code class="language-cpp">
__aicore__ inline void Add(
  const LocalTensor<float> &z,
  const LocalTensor<float> &x,
  const LocalTensor<float> &y) {
    Add(z, x, y, TILE_LENGTH);
}
</code></pre>

复制与切片都不带行号杂质。
