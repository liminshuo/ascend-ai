图片图意 · OCarousel

稿面要做什么

  • 信息图：非空 alt 或 figcaption / 正文转写关键结论
  • 装饰图：alt="" 或 aria-hidden，勿冒充内容
  • 正文禁止只写「见上图」——结论须文字复述

常见错误

  • 关键结构 / 数字只在图里
  • 信息图空 alt 或假 alt
  • 用截图代替本可结构化的表格 / 列表
