气泡说明正文 duplicate

字段规格勿只放悬停气泡；正文须 duplicate 或 popover 内容 SSR 进首包。 读的懂 · 社区 UI · 以 社区首页 为例 · 对应 问题实测 · 气泡隐藏说明。

为什么气泡卡片是「视情况」——先分清「字段定义」与「装饰提示」

含字段定义的气泡要做亲和

重要字段 / 规格定义（如「CANN 版本」）若只在悬停气泡，须在正文重复一份，或 popover 内容进首包可抓。

装饰性 tooltip不做亲和

纯提示、装饰性 tooltip 不含唯一知识，入库可忽略；关键在于正文是否另有一份可读定义。

设计UI调整

调整建议

  • 关键定义留成可见旁注：重要字段定义（如「CANN 版本」）别只放悬停气泡，稿面为其预留一处可见旁注 / 正文说明；气泡只作补充。
  • 区分定义气泡与装饰 tooltip：承载字段定义的气泡要在正文另写一份；纯装饰 tooltip 标「纯提示 · 入库排除」。

调整示例

1. 字段说明：只在悬停 → 正文旁注 + 气泡

Before · 定义只在悬停气泡

CANN 版本 ?

字段定义只在悬停「?」时弹出气泡；不悬停 / 禁 JS 时正文没有这份说明，抓取读不到定义。

After · 正文旁注 + 气泡补充

CANN 版本 ?

CANN 版本：昇腾异构计算架构的版本号，决定可用算子与框架适配范围（当前 8.0）。

定义写成可见旁注（正文一份），气泡只作 hover 补充。

文档内容调整

调整建议

  • 字段定义正文 duplicate：悬停气泡里的字段 / 规格定义在正文或文档也写一份可引用文本，气泡不作唯一来源。
  • 装饰 tooltip 可忽略：纯提示 tooltip 不含唯一知识，入库可忽略；关键看正文是否另有定义。

调整示例

1. 字段定义：只在气泡 → 正文旁注

Before · 定义只在 popover

【Before】「CANN 版本」定义只在悬停气泡
正文无等价说明

After · 正文写一份定义

## 字段说明
- CANN 版本：昇腾异构计算架构版本号，决定算子与框架适配范围（当前 8.0）

前端调整

调整建议

  • 含定义的 popover SSR 进首包：承载字段定义的气泡内容在首包 HTML 就存在（可视觉隐藏），别等 hover 才由 JS 挂载。
  • 勿 aria-hidden 删文本：气泡文本保留在 DOM，避免抓取为空。
  • 装饰 tooltip 可 exclude：纯装饰 tooltip 标 <code>data-llm-exclude</code>。

调整示例

1. 气泡：hover 才挂载 → SSR 首包可读

Before · hover 才挂载

<span class="o-popover"></span>
<!-- 定义 hover 时才 JS 注入，无 SSR 文本 -->

After · SSR 首包含定义

<span class="o-popover" role="note">
  CANN 版本：异构计算架构版本号（当前 8.0）
</span>
<!-- 首包可读，视觉上悬停展开 -->
