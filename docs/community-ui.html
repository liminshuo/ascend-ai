社区UI组件

收录设计系统 39 个组件，并附文档层「内容载体」6 项（图 / 表 / 代码等，自大模型抓取研究迁入）。 「是否需要做亲和」指官网或文档场景下 HTML 可抓 / Markdown 是否需配套调整。组件说明见 design-system/components.md。

#组件是否需要做亲和亲和分析

2OTab 标签页视情况内容型 Tab 各面板须全量 SSR；纯交互 / 装饰型入库剥离。详见亲和原则查看详情
3OBreadcrumb 面包屑需要祖先页做成可爬 a[href]；当前页可用纯文本；路径文案与 sitemap 对齐查看详情
4OAnchor 锚点需要本篇目录用真实 #id 与 href；正文标题保留对应 id查看详情
5OPagination 分页需要公开列表底部分页须为可抓 URL（如 ?page=2）；后台表格分页入库剥离查看详情
6OStep 步骤条需要公开流程步骤标题与说明写入源码；进行中 / 完成态勿只靠颜色；后台向导剥离查看详情
7ONavigation 导航需要站点入口与展开子链须进首包可跟；搜索 / 换肤 / 语言等纯操作控件剥离查看详情
8底部导航需要页脚多列链接进源码；列名稳定，并与 llms / sitemap 互证查看详情
