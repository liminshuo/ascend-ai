社区UI组件

收录设计系统与增补展示项共 47 个组件。 「是否需要做亲和」指官网或文档场景下 HTML 可抓 / Markdown 是否需配套调整。组件说明见 design-system/components.md。

#组件是否需要做亲和亲和分析

2ONavigation 导航需要站点入口与展开子链须进首包可跟；搜索 / 换肤 / 语言等纯操作控件剥离查看详情
3OTab 标签页视情况内容型 Tab 各面板须全量 SSR；纯交互 / 装饰型入库剥离。详见亲和原则查看详情
