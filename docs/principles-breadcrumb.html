站内可定位

解决什么问题

Agent 经搜索或发现层打开某篇文档后，单页信息缺乏上下文锚点，导致机器无法建立局部与整体的连接。

Agent 是如何完成站内定位的

核心原则

面包屑写出真实层级

路径按父级到子级完整写出（如：文档中心 › 产品线 › 手册 › 当前篇），当前篇不可点击，各级名称与对应页标题一致。

节级锚点可引用

段落标题旁露出「#」，每个锚点对应稳定 URL，并与右侧目录指向同一小节。点击可复制含 hash 的完整地址。

邻篇导航齐全

页底默认可见上一篇 / 下一篇，篇名与目标页标题一致，并附带真实可跟链接。

典型示例

面包屑 · 写出真实层级

顶栏按父级到子级写出「文档中心 › CANN 8.0 › 安装指南」；当前篇不可点击，各级名称与对应页标题一致。

示例 1 · 文档路径

反面

安装指南

  • 常见疏漏：
  • 1. 只有篇名，看不出手册、版本等上级层
正面

文档中心 › CANN 8.0 › 安装指南

  • 正确做法：
  • 1. 每一级（含手册与版本）写进路径，末级为当前篇

Markdown 书写

  • 1. 正文前按父级到子级写出路径；父级做成链接，当前篇不要做成链接
  • 2. 当前篇名与标题一致

正面

前端源码调整

  • 1. 首包即输出全量祖先可跟链，当前篇用纯文本
  • 2. href 指向手册祖先页，不要链到 sitemap

邻篇 · 邻篇导航齐全

页底默认可见「上一篇 安装驱动」「下一篇 配置环境变量」，篇名与目标页标题一致，并附带真实可跟链接。

价值收益

  • 归属更清楚回答能点明产品线与手册，同名文档不再串篇。
  • 引用更可核回答能落到具体章节或步骤，含 hash 的地址可复制核对。
  • 续读更连贯回答能沿手册指到下一章，不会看完这篇就断。
