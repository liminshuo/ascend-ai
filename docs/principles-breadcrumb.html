面包屑

当前位置须写成真实层级路径；祖先可点，当前页纯文本；禁止只有篇名，帮助 Agent 判断是否在正确任务页。 可达 · 设计专项见 页面位置与邻篇可识别。

对象

对象 描述
面包屑 当前位置须写成真实层级路径；祖先可点，当前页纯文本；禁止只有篇名。常见落点：文档页头、栏目页。

设计UI调整

调整建议

  • 位置写成路径：面包屑默认可见；真实层级、祖先可点、当前页纯文本；禁止只有篇名。
  • 手册与版本外显：所属产品线 / 手册名 / 版本出现在固定位置，不藏进图标。

文档内容调整

调整建议

  • 手册名一致：版本与手册名与正文适用条件一致，并与面包屑路径用语对齐。

前端调整

调整建议

  • 真实可跟链：面包屑祖先均为真实 a[href]；当前页可为纯文本。
  • 首包即含导航：禁只靠路由状态、无 URL 的「当前位置」点。
  • 结构化可选：结构化数据可含 BreadcrumbList / isPartOf。
