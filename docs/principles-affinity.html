轮播帧语义隔离

首页/运营轮播多帧虽已写进网页源码，但运营/活动/招募口号与产品规格混层，须默认 exclude 出 llms 与知识库；人读发现归轮播，规格事实归文档。白名单产品入口帧须输出「标题 + 可引用摘要 + a[href]」，并完成图意转写；跳转型 CTA 禁 button 伪链。 读的懂 · 社区 UI · 以 社区首页 为例 · 对应 问题实测 · 轮播帧语义噪声。

设计UI调整

调整建议

  • 角色标注：设计交付中明确轮播为人读发现层（活动 / 认证 / 招募），默认标注「不入库」；产品能力说明不得只存在于 Banner 图与口号。
  • 信息帧版式：若帧含产品 / 文档入口，稿面预留三块可见文案位——标题、一句话事实摘要、CTA 锚文本（禁仅图标按钮）。
  • 图意转写位：信息型 Banner 在帧内或帧下预留短说明 / figcaption 区域；纯装饰背景图在标注中写明，研发侧按装饰图处理。
  • 帧清单备用：在轮播旁或页脚附近提供「本页推广入口」文本清单（标题 → 落地页），不依赖滑动才能看见全部入口。

调整示例

1. 口号 Banner → 可引用帧卡

Before · 仅视觉口号

算子开发者认证 · 立即前往 ›

整帧就是一张 Banner 图，文字烧进图里：无 alt、无摘要、无落地说明——图意抓不到，还易被当成「官方能力规格」入库。

After · 图意转写 + 摘要 + 入口清单

算子开发者认证（入门级）

面向 Ascend C 入门场景的官方认证入口，非 CANN API 规格说明。

本页推广入口
  • 算子开发者认证 → 认证报名页
  • CANN 安装与开发 → 文档中心对应章节

要点：

  • Banner 图配 alt / figcaption 做图意转写，关键图意用正文复述；纯装饰背景图 alt=""。
  • 信息帧配「标题 + 一句话事实摘要」，讲清「是什么 / 不是什么」——认证入口，而非 CANN API 规格。
  • 「本页推广入口」把全部帧的入口平铺成静态文本清单（标题 → 落地页），不滑动、禁 JS 也能被发现。
  • CTA 锚文本写清去向并落到稳定文档 URL；运营 / 活动帧默认 data-llm-exclude，不当产品规格入库。

文档内容调整

调整建议

  • 默认不入库：首页 / 运营轮播不写入 llms.txt、知识库白名单；重要能力说明落到可引用文档页，轮播只做人读引流。
  • 可引用摘要：信息帧必须具备一句话事实摘要（说明「是什么 / 不是什么」），禁止只有营销口号。
  • 描述性 CTA：锚文本写清目标（如「前往算子开发者认证」），禁止「立即查看 / 了解更多」且无稳定落地文档 URL。
  • 图意转写：信息型帧图补有区分度的 alt；关键图意用正文复述，禁止「见 Banner」式指代。
  • 噪声隔离：活动招募、赛事、实习生等帧不得被写成产品规格段落；若需被 Agent 引用，另开文档页承载。

前端调整

调整建议

  • HTML 结构实现：每帧以独立节点输出（如 article.o-carousel-item），内含标题、摘要段落、真实 a[href]；信息图用 figure + 非空 alt，装饰图 alt="" / aria-hidden。
  • 全量帧 SSR：首屏 HTML 输出全部帧文本，禁止只渲染当前帧；视觉层叠可用位移 / 透明度，禁止用 display:none 删除非当前帧正文。
  • 策展标记：运营轮播根节点加 data-llm-exclude="true"（或等价约定），构建管道默认跳过；仅白名单帧可加 data-llm-cite="true"。
  • Chunk 切片管道：默认跳过 [data-llm-exclude] / .o-carousel；若强制收录，按帧拆 chunk，字段为「标题 + 摘要 + 锚文本 → URL」，活动帧仍丢弃。
