折叠正文默认可抓取

为了帮助 Agent 在无需点击展开的情况下抓取步骤与链接，折叠块须默认展开（如 details open）；关键步骤、警示、验证禁止默认收起。Tab 见 Tab 面板可全量抓取。

适用对象

名称 说明 常见落点
正文折叠块 步骤、警示、验证等折叠区默认展开；标题须有可读语义文本。 安装步骤、FAQ、警示说明
侧栏折叠 侧栏目录若折叠，须提供「全部展开」；子项收起只是视觉，首包须已有链接文案。 文档侧栏、目录树

适用场景

优先级 页面类型 说明
必做 文档站步骤 / 警示折叠、手册侧栏 Agent 最常引用的操作与导航事实。
建议做 官网 FAQ、能力说明折叠区 说明进引用池时，默认态须可读全文。
可不做完整改造 纯补充 FAQ，且正文已覆盖同一事实 不承载唯一步骤时，可保留收起，但首包仍宜有摘要。

设计UI调整

调整建议

  • 关键内容默认可视 折叠只控制显隐，禁止把步骤、定义放到点击之后才注入；关键步骤、警示、验证禁止默认收起。
  • 隐藏须可直达 必须折叠时提供「全部展开」；列表用分页代替无限滚；蒙版不得遮挡关键命令。

文档内容调整

调整建议

  • 关键步骤勿只放折叠内 必须用折叠时默认展开；关键步骤与说明优先放在折叠外正文，折叠仅收纳补充材料。
  • 折叠标题须可读 summary / 折叠标题须含语义文本（如「离线安装步骤」），禁止只放图标或空节点。

前端调整

调整建议

  • details 默认带 open SSR 输出默认带 open；用户可手动收起，但初始 HTML 正文完整。
  • summary 含语义文本 标题须能独立描述折叠区主题；侧栏子链接文案须在首包 DOM 中，勿点击后才注入。

调整示例

首包须带 details open

反面 
<details>
  <summary>离线安装步骤</summary>
  ./toolkit.run --offline
</details>

← 默认收起，管道易跳过区内正文
  • 常见疏漏：无 open，静态抓取可能拿不到区内命令。

<details open>
  <summary>离线安装步骤</summary>
  ./toolkit.run --offline

← 首包即含完整步骤
