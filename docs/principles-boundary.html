明确边界

写清支持 / 不支持、能做 / 不能做、适用 / 不适用，降低 Agent 幻觉与越界建议。 可理解 · 对应全量表 相关条目。

设计 UI 调整

  • 支持 vs 不支持适合用对比表或双栏清单，与普通表格有区分。
  • 废弃、删除、权限限制用可见状态词，不靠暗示。

文档内容调整

  • 边界句写全：对象、场景、版本条件；避免「等」「相关」收束。
  • 不支持项与支持项成对出现，便于机器抽取。

前端调整

  • 边界容器可加 data-pattern="boundary"；支持/不支持分属性标注。
  • JSON-LD 可用 audience / contraindication 等字段映射边界。
