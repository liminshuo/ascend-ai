Mintlify（html）分析 · 可引用性·内容（html）分析

聚焦一件事：大模型去抓网页 HTML 时，关键信息能不能读到、链接跟不跟得上、图和提示有没有字。 下列规则从 Mintlify 五类页面（首页 / 定价 / 文档编辑器 / 博客 / Score）组件实测归纳。

分析总结

  • 关键信息要落在静态文本里：标题、正文、价格、分数、步骤写进源码节点，不点按钮也能读到，才算抓得到。Mintlify 五类页的主文案大体如此；滚轮动效数字、只画在 canvas/图里的细节则抓不全。
  • 入口要看得见也跟得上：卡片和列表不仅要有标题，还要有真实 href。博客做到了；文档 Explore 卡只有样子能点，模型会跟丢。
  • 抓不全不等于都要改：关键可核对信息缺失、入口断链 → 有必要解决；封面/Logo/示意层缺字、但旁白已复述 → 可不解决。本模块只判源码能不能抓全该组件。
