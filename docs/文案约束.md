# 文案约束

## 1. 不用「门禁」「导读」

这两个词是比喻，不准确。

「门禁」会误导：`robots.txt` 没有强制准入力。实测 GPTBot、ChatGPT-User 根本不请求它。

改用更贴事实的说法：

| 不要写 | 改写为 | 对应文件 / 对象 |
|--------|--------|----------------|
| 门禁、准入授权 | **许可声明** | `robots.txt` |
| 导读、必经导读 | **索引目录** | `llms.txt` |
| （比喻式的「打开导读正文」） | **响应体** | 实际打开的 `.html` / `.md` |

页面上「打开正文」可以保留；不要把正文说成导读，也不要把 `robots.txt` 说成挡得住所有 Agent 的门禁。
