图片图意可转译

解决什么问题

Agent 无法仅凭像素读出图中的结构与结论（如：活动名烧进海报，架构关系只画在图里，训练指标只出现在截图中）。

核心原则

图意不独自存在于像素

信息型图片须转写为可检索正文（独立文案层、alt、figcaption、内容转写或平行 Markdown）。src 与 Markdown 图链须写成可抓取的绝对地址，便于多模态 Agent 取图；但不能用「能读图」代替正文转写。装饰图不承载事实，可用空 alt，无需硬写转写，地址仍宜可抓。

图 Kernel 调度示意图

图注：Host 进程运行在 CPU，负责发起计算任务。任务下发到 NPU 后，先进入任务调度器，再由调度器分配到 AI Core 0、AI Core 1 … AI Core N-1；各核承接子任务并并行执行，核数可按 N 扩展。

Markdown 书写

  • 1. 正文复述结论，禁止只写「如图所示」
  • 2. alt + 图注完整转写图意

价值收益

  • 图中事实可被检索Agent 能点名活动名、品牌、层名与调度结论，而不必依赖 OCR 或「见图」。绝对 src 只是给多模态的加成，不是转写的替代。
  • 引用可核对指标与结构写入图注或平行 Markdown 后，回答可带回可复核的文字证据（如参数量 7.62B、Host→NPU 调度关系）。
