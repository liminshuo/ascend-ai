关键内容默认可读

为了帮助 Agent 在无需悬停或聚焦的情况下取得任务必需信息，定义与状态说明须写在默认可读稿面；悬停气泡只可作补充。

适用对象

名称 说明 常见落点
悬停定义 定义、说明不得只写在悬停 tip；首包须有等价文字（正文、旁注或链到定义页）。 术语词条、安装说明
悬停状态 状态或关键说明不得仅存于悬停；稿面须有默认可读文字。 状态图标 tip、控件说明

适用场景

优先级 页面类型 说明
必做 文档站术语、安装说明、状态说明 任务必需定义与状态，Agent 须默认可抓。
建议做 官网产品 / 能力页 tip 规格与能力说明进引用池时，勿只藏在悬停。
可不做完整改造 纯操作提示，且正文已写同一含义 气泡仅补充交互提示时，可保留悬停。

设计UI调整

调整建议

  • 悬停不独自表意 关键信息不得只存在于悬停气泡；首包 DOM 须有等价文字。交互只控制显隐，勿悬停后才注入定义。
  • Hover 可作补充 稿面已有同一含义时，气泡只作补充，不必每个词条下复读。本页若不解释该词，就不要把定义只藏进 Hover。

调整示例

悬停提示须有正文等价说明

反面

安装说明

请先完成 CANN昇腾异构计算架构，提供驱动、编译与运行时。 再继续。

  • 常见疏漏：定义只在悬停后出现，机器未悬停则抓不到 CANN 含义。
正面

安装说明

请先完成 CANN 再继续。

CANN：昇腾异构计算架构，提供驱动、编译与运行时。气泡可再补充，正文须先有这一句。

  • 正确做法：定义写在词条下方或旁注；Hover 只作补充。
  • 可免场景：正文或旁注已写出同一份定义时，悬停气泡可只作补充。

文档内容调整

调整建议

  • 关键说明写入正文或旁注 定义、状态与任务必需说明写在默认可读稿面；与气泡文案保持一份真相。
  • 禁止悬停作为唯一入口 勿写「悬停查看详情」作为唯一出处；可链到定义页，但页内须有可抓摘要。

调整示例

定义写在稿面，勿只靠悬停

反面 
请先完成 CANN 再继续。
（悬停查看详情）

← 稿面无定义句
  • 常见疏漏：唯一含义只在悬停，平行 MD 也抓不到。
正面 
请先完成 CANN 再继续。

CANN：昇腾异构计算架构，
提供驱动、编译与运行时。

← 定义写在默认可读处
  • 正确做法：正文或旁注写出定义；气泡可再补充。

前端调整

调整建议

  • 禁 JS 后关键句仍在 HTML 任务必需定义与状态须随首包输出；气泡内容若重要须双写到可见正文节点。
  • 勿靠 hover 才插入文本 禁止纯 CSS :hover / JS 悬停后才把定义注入 DOM；交互只切换显隐。

调整示例

定义须在首包文本节点

反面 
<span data-tip="CANN">CANN</span>
<script>
  // hover 后才 fetch 并插入定义
</script>

← 静态抓取无定义句
  • 常见疏漏：定义异步注入，禁 JS 时只有词条名。
正面 
<p>请先完成 CANN 再继续。</p>
<p class="term-def">
  CANN：昇腾异构计算架构，
  提供驱动、编译与运行时。
</p>
<!-- tip 可另有，但正文已双写 -->
  • 正确做法：首包即含可见定义节点；tip 只切换显隐。
