音视频内容可转译

概述

音视频承载着丰富的知识信息，包括讲解内容、操作步骤、技术参数、演示过程和结论等。由于这些信息主要通过声音和动态画面传递，AI Agent 未必能直接、完整地获取其中的内容及其上下文关系。

音视频内容可转译原则旨在将音视频中具有知识价值的信息，以准确、可读取的文本形式表达出来，使 AI Agent 能够获取和理解核心内容，并支持信息检索、知识引用与后续使用。

具体原则

  1. 将音视频中的关键文案、技术参数、操作步骤和重要结论转化为可直接读取的 HTML 文本，避免关键信息仅存在于音轨或画面中。
  2. 通过摘要、章节说明或操作步骤呈现音视频的核心内容；对于画面中的关键操作、状态变化和演示结果，补充必要的文字说明。
  3. 对于较长或包含多个主题的音视频，提供章节标题、时间戳或片段索引，帮助 AI Agent 定位关键内容及对应片段。
  4. 保持字幕、转写文本、摘要和配套说明与音视频内容一致；内容更新时同步更新相关文本，避免信息遗漏、描述错误或时间戳错位。

典型示例

旁侧写出要点

概括关键步骤、参数与结论即可，不必逐字转写口播；要点默认可见，勿藏进需点击才展开的唯一入口。

预期效果

  1. 帮助 AI Agent 通过 HTML 文本、旁侧要点、字幕或平行 Markdown 获取音视频中的关键步骤、参数、案例结论和操作结果。
  2. 减少仅依赖语音识别、画面 OCR 或多模态识别带来的不确定性，使回答能够回查到可检索、可引用的文字证据。

注意事项

  1. 装饰性背景音、氛围视频不承载事实时，不需要硬写转写或摘要，避免引入无意义信息。
  2. 旁侧要点用于概括关键事实，不宜制造与口播或画面不一致的新结论。
  3. 字幕和完整转写可以作为补充，但不能替代页面中默认可见的标题、要点和关键结论。
  4. 媒体文件使用可抓取地址有助于多模态 Agent 获取原始材料，但不能替代关键内容的文本转写。
