音视频内容可转写

概述

音视频承载着丰富的知识信息，包括讲解内容、操作步骤、技术参数、演示过程和结论等。由于这些信息主要通过声音和动态画面传递，AI Agent 未必能直接、完整地获取其中的内容及上下文关系。

音视频内容可转译原则旨在将音视频中的核心知识及必要上下文以可读取的文本形式呈现，并通过章节、时间戳等信息建立文本与媒体内容的对应关系，帮助 AI Agent 准确获取、理解和定位关键信息。

具体原则

  1. 将音视频中的关键讲解、技术参数、操作步骤和重要结论转化为可直接读取的 HTML 文本，避免关键信息仅存在于音轨或画面中。
  2. 通过摘要、主要观点和操作步骤呈现音视频的核心内容；对于画面中的关键操作、状态变化和演示结果，补充必要的文字说明，避免脱离上下文后难以理解。
  3. 对于较长或包含多个主题的音视频，提供章节标题、时间戳或片段索引，帮助 AI Agent 定位关键知识及其对应的音视频片段。相关链接和时间信息应指向正确的内容。
  4. 确保摘要、字幕、转写文本和配套说明与音视频内容一致；音视频更新时同步检查相关文本、章节索引和时间戳，避免信息遗漏、描述错误或定位偏差。

旁侧写出要点

预期效果

  1. 帮助 AI Agent 通过文本获取音视频中的核心讲解、技术参数、操作步骤和重要结论，减少对音视频识别的依赖。
  2. 通过摘要、主要观点和关键画面说明补充必要的上下文信息，提升内容的可理解性、可检索性和可引用性。
  3. 通过章节标题、时间戳或片段索引，帮助 AI Agent 快速定位关键内容及对应片段，提高信息获取和使用效率。

注意事项

  1. 无信息价值的装饰性画面和背景音无需逐一转写，避免引入冗余内容。
  2. 配套文本应忠实反映音视频内容，不得遗漏关键条件、歪曲原意或引入缺乏依据的新结论。
  3. 字幕和完整转写文本可以作为补充，但不能替代页面中默认可见的标题、要点和关键结论。
  4. 应提供可访问的媒体资源地址，便于支持多模态处理的 AI Agent 获取原始材料，但媒体地址不能替代关键内容的文本转写。
  5. 音视频更新后，应同步检查摘要、字幕、章节索引、时间戳和相关链接，确保内容准确且指向正确。
