标题层级可识别

概述

标题层级用于表达页面内容的主题、层次与从属关系。仅依靠字号、粗细或视觉排版区分标题，可能导致 AI Agent 无法准确识别内容结构。

标题层级可识别原则旨在通过规范的标题语义和层级关系，帮助 AI Agent 准确识别页面主题、理解内容组织方式，并定位和引用相关信息。

具体原则

  1. 使用规范的标题标签表达层级。 HTML 使用 <h1> 至 <h6>，Markdown 使用 # 至 ######，避免仅通过字号、加粗或普通段落模拟标题。
  2. 标题层级应连续且符合内容结构。 根据主题的从属关系设置标题，避免无合理依据地跳级，或仅为调整视觉样式而选择标题级别。
  3. 标题应准确概括对应内容。 标题应清晰表达所在章节的主题，避免使用含义模糊或脱离上下文的标题；同级标题应保持合理的并列关系。
  4. 标题语义应与视觉呈现保持一致。 确保标题标签、实际内容层级和页面展示相匹配；对于仅用于视觉强调的文本，不应误用标题标签。

预期效果

  1. 帮助 AI Agent 准确识别页面主题、章节层级和内容从属关系，提升页面结构的可理解性。
  2. 帮助 AI Agent 根据标题定位和检索相关内容，提高信息提取、摘要生成与知识引用的准确性。
  3. 减少因标题语义缺失、层级混乱或标题含义模糊造成的内容误判。

注意事项

  1. 标题层级应依据内容结构确定，不应仅为满足视觉排版需求而设置。
  2. 页面主标题、章节标题和子章节标题应形成清晰的层级关系；不必机械要求每个页面只能出现一个 <h1>，但应确保主旨明确。
  3. 标题应简洁、具体，并与其下方内容保持一致，避免标题与正文表达不同主题。
  4. 对于标签页、折叠面板等交互区域，应确保标题及其关联内容能够被正常读取；不应将普通文本或装饰性文字误标为标题。
