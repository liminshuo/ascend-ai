标题层级可识别

解决什么问题

Agent 无法仅凭字号、缩进或分割线理解章节的从属与并列关系。

核心原则

标题层级反映结构

从属与并列关系体现在标题级别（如 H2 / H3）或编号（1 / 1.1）上，不依赖视觉排版。两种方式选其一，避免叠用。

典型示例

用标题级别或编号标明从属

标题级别与编号二选一，不叠加使用（如不在 H3 下同时写 1.1）。

示例 1 · 标题级别

结构由 H1–H5 源码定义（Markdown 用 #，HTML 用 H1–H5），字号仅作视觉呈现，不承担结构语义；标题级别应连续，不宜跳级（如：不在 H1 下直接挂 H4）。

价值收益

  • 从属关系可被理解Agent 能识别「准备环境」属于「安装」，不必靠字号或缩进猜测章节树。
  • 并列关系可被理解Agent 能把「训练开发」「推理部署」当同级主题，引用时不会交叉串节。
