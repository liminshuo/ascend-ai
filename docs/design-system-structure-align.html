全站规范一致性

原则定义

即便单篇已按模式块书写，若同类任务页各写各的——章节名不统一、顺序不一致、内部格式各异——AI Agent 仍难以跨页对齐同一任务类型，检索与复述时易把「准备工作」与「前提条件」当成不同结构。

全站规范一致性要求：全站范围内，核心概念、术语、格式规范、结构模式与交互样式保持一致；跨文档的相同内容使用完全相同的表达、格式和结构。单篇如何切块见「页内结构模式化」。

视觉规则

  1. 1同名跨页章节标题字面一致（如一律「前提条件」），不用近义词或内部代号。
  2. 2同序章节先后顺序一致；勿在个别页调换「步骤 / 验证」。

前端规则

  1. h2 同构同类型页的 h2 文案与 DOM 顺序保持一致，由统一模板生成更稳妥。

示例如下（页 A / 页 B 同构）：

<h2>前提条件</h2>
<h2>步骤</h2>
<h2>验证</h2>
<h2>示例</h2>

适用边界

上述规则适用于安装、配置、API、排障等同类型任务页需要被 AI 跨页识别、对比或聚合的场景。

先约定任务类型模板，再约束各页落地；有助于 Agent 跨页对齐固定模板，降低「同义不同名」造成的结构错配。本原则管跨页是否同名同序同格式；单篇是否切成模式块见「页内结构模式化」。

不同任务类型可各自选用不同章节集，但同一类型内须保持稳定；局部业务差异不应成为各写各的的借口。
