HTML 转化成 Markdown

Skill ID：html-to-md · 依据：Markdown 正文可直取 · 推荐内容后置

核心命题

原始 HTML（尤其营销站）对 Agent 噪声高。本 Skill 把给定页面压成可扫读的 Markdown：去壳去重、保留 CTA；文首索引模块只声明根 llms 与对应 HTML 的 URL；报告只下载 .md。与 md-discoverability 成对：本 Skill 生成 MD，后者核验人读页能否发现平行稿。

下载 Skill 查看示例报告

转换范围

主输入为页面 URL；也可本地 HTML 或粘贴片段。输出精简 .md 与轻量对照报告。不编造正文；不把全站导航写进 MD。

项要求
页面 URL优先：GET 后抽正文；记最终 URL
本地 / 片段需登录、反爬或 JS 不全时改用
去壳去掉 nav/header/footer、登录购物车、语言切换、备案热线
去重轮播等造成的连续重复标题/段落只留一份
语义标题层级、列表、绝对链接、代码块、表格；图片用 alt
按钮 / CTA有有效 href 的按钮文案必须写入 MD 为 [文案](URL)；空链可保留文案并注明
交付Part1 转换说明 + Part2 MD 预览；可下载 .md、导出 PDF

工作流

  1. 输入：页面 URL（优先）或本地 HTML / 片段；可选正文选择器。
  2. 获取：GET 或读文件；去掉 script/style 噪声。
  3. 定位正文：选择器 → main/article → 最大文本块；丢弃壳层。
  4. 转 MD：文首索引（根 llms + 对应 HTML）→ 正文；来源/清洗写报告 Part1；报告只下载 MD。
  5. 质检：是否仍含登录/备案等；过短则标 JS 可能不全。
  6. 输出：.md + 对照 HTML；双写 docs/ 与 report-serve/。

报告结构

白底 HTML，无侧栏；顶栏品牌 +「下载 Markdown」+「导出 PDF」，与正文 1000px 栏对齐。

  1. Part1. 转换说明：来源与可达、正文定位与清洗、问题与发现。
  2. Part2. 转换结果：建议稿预览；下载 .md；编写说明。

如何使用

  1. 下载 Skill 包，解压到 Cursor 的 .cursor/skills/html-to-md/（或个人 skills 目录）。
  2. 准备要转换的页面 URL（优先）；若暂不可抓取，改用本地 HTML 或粘贴片段。
  3. 在对话中调用，例如：按 html-to-md 转换 https://agentorchard.huaweicloud.com/agentarts.html（文首声明根 llms 与对应 HTML URL）。
  4. 按报告模板输出 HTML，并将优化后的 .md 放到 exports/ 供下载。可对照示例：智果 AgentArts 对照报告。
