面包屑路径可链回溯

文档页顶栏面包屑须把每一级祖先页写成可点的链接（a[href]），当前页用纯文本即可；首包 HTML 就要输出完整路径，文案与 sitemap / 手册目录保持一致。 对应页面：昇腾产品形态说明

设计UI调整

调整建议

  • 路径文案须自描述：写清真实层级（如「文档中心 › CANN › 安装部署」），避免「首页 / 详情 / 当前页」等泛词。
  • 祖先可点、当前页纯文本：上级每一级为真实 a[href]，末级当前页用纯文本（避免自链）。

调整示例

示例1. 面包屑：泛词 → 真实层级名

✗ 错误示范 · 泛词路径

首页 › 详情 › 当前页

「首页 › 详情 › 当前页」看不出在站点哪一层，也无法据此回溯到祖先页。

✓ 推荐做法 · 真实层级名 + 可跟链

文档中心 › CANN › 安装部署 › CANN 安装指南

要点：每级为真实层级名；祖先可跟链，末级当前页纯文本。

文档内容调整

调整建议

  • 统一命名：面包屑、sitemap、侧栏目录与 MD 路径链使用同一套层级名与 URL，避免同一页因名称差异被识别成多个入口。
  • MD 页头写路径：Markdown 版在 h1 上方用列表或一行路径链写出 ancestors（标题 + 链接）；末级当前页纯文本即可。
  • 过渡补位：页面面包屑未达标前，用 llms.txt 临时写出关键祖先链；达标后以页面为准，去掉重复维护。

调整示例

示例1. 昇腾产品形态说明：路径链平行轨

✗ 当前问题 · 只有 title，无路径链（连续阅读模式开启情况下）

【HTML】<title>昇腾产品形态说明-产品与技术常见问题-昇腾常见问题…</title>
【缺失】MD / llms 均无各级 ancestors 的可跟链

✓ 推荐做法 · MD 页头平铺路径链

## 路径
- [昇腾常见问题](/document/detail/zh/AscendFAQ/…)
- [产品与技术常见问题](…)
- 昇腾产品形态说明（当前页）

# 昇腾产品形态说明
…

✓ 推荐做法 · llms 临时补祖先链

# llms.txt（过渡）
- [昇腾常见问题](/document/detail/zh/AscendFAQ/…)
- [产品与技术常见问题](/document/detail/zh/AscendFAQ/ProduTech/…)
- [昇腾产品形态说明](/document/detail/zh/AscendFAQ/…/hardwaredesc_0001.html)

页面面包屑达标后以 HTML 为准，llms 中重复路径可移除。

前端调整

调整建议

文档页顶栏面包屑须在首包 HTML 输出完整祖先路径；静态抓取（不执行 JS）仍能列出每一级 a[href] 并回溯到祖先页（对标：NVIDIA cuQuantum bd-breadcrumbs）。

具体要求：

  • 全量祖先进首包：输出与可见 UI 一致的全量路径；中间级不得缺失（Ascend FAQ 实测：server-breadcrumb 仅 2 链，缺「昇腾常见问题 / 产品与技术常见问题」）。
  • 祖先为真实 a[href]：每一级祖先须为带真实地址的 a 标签 + 可见文案；当前页用 span 或纯文本，勿做成自链。
  • 禁仅 JSON/脚本补路径：路径节点不得只在 __NUXT_DATA__ 或前端脚本里才出现；静态 HTML 内须已有完整可跟链。

调整示例

示例1. Ascend FAQ o-breadcrumb

✗ 当前问题 · server-breadcrumb 仅 2 链，中间级缺失

<div class="o-breadcrumb server-breadcrumb">
  <a href="/sitemap/sitemapdoc1.xml">文档中心</a>
  <a href="…/hardwaredesc_0001.html">昇腾产品形态说明</a>
</div>
<!-- 浏览器可见三级路径；中间级在 __NUXT_DATA__ -->

首包只有「文档中心 → 当前页」两链；中间祖先只在 __NUXT_DATA__，静态抓取无法逐级回溯。

✓ 推荐做法 · SSR 全量 ancestors 可链

<nav aria-label="Breadcrumb" class="o-breadcrumb">
  <a href="/document/detail/zh/AscendFAQ/…">昇腾常见问题</a>
  <a href="/document/detail/zh/AscendFAQ/ProduTech/…">产品与技术常见问题</a>
  <span aria-current="page">昇腾产品形态说明</span>
</nav>

祖先级均为真实 a[href]；末级当前页纯文本。静态抓取即可列出完整路径并跟链。
