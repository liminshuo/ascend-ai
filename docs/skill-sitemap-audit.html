Sitemap 轻量诊断

Skill ID：sitemap-audit · 依据：配置 Sitemap 路径清单

核心命题

sitemap.xml 是给爬虫的 URL 发现清单。本 Skill 做轻量核对：可达、规模与结构信号、与 robots 声明 / 可选抓取表是否对得上。不灌全量 URL，不把 Sitemap 写成 llms.txt；与 robots Skill 分工（robots 管声明，本 Skill 管本体信号）。

下载 Skill 查看示例报告

输入

主输入为 Sitemap URL；建议同时给站点根。有抓取表时可做覆盖缺口对照。

字段必填说明
Sitemap URL 是（主） 如 https://www.huaweicloud.com/sitemap.xml；可为 urlset 或 sitemap index
站点根 URL 建议 如 https://www.huaweicloud.com/；对照 robots 是否声明、推断根路径
抓取表 CSV 可选 有则做覆盖缺口轻量对照（类型级）；无则只做 Sitemap 自身信号
收录范围 可选 只要某 host / 路径前缀时写明

检查范围

项要求
可达GET/HEAD 状态码、类型、体积
类型与规模urlset / index；loc 粗估；index 有限层下钻
结构信号host、http/https、路径簇 Top（类型级）
时效信号lastmod 是否异常陈旧
robots 对照是否以绝对 URL 声明本 Sitemap
覆盖缺口仅当有 CSV：类型级对照，不枚举全量差集

工作流

  1. 输入：Sitemap URL（必填）+ 建议站点根 + 可选 CSV / 收录范围。
  2. 拉取：判定 urlset / index；index 有限展开。
  3. 统计：条数、host/scheme、路径簇、lastmod 信号。
  4. 对照：robots 声明；有表则覆盖缺口。
  5. 旧问题举证：协议、时效、收录失衡、robots 未声明等（证据+影响）。
  6. 优化稿：旧→新对照 + 可下载 XML 基线；完整全量由构建管道后续生成。
  7. 输出 HTML：Part1 + Part2；双写 docs/ 与 report-serve/；可导出 PDF。

报告结构

白底 HTML，无侧栏；顶栏品牌 +「导出 PDF」，与正文 1000px 栏对齐。

  1. Part1. 当前 Sitemap 分析：可达、结构与规模、robots 对照、可选抓取表对照、问题与发现。
  2. Part2. 新 Sitemap 怎么改：旧→新对照、可下载优化稿（index/核心册）、修改说明、待确认。

如何使用

  1. 下载 Skill 包，解压到 Cursor 的 .cursor/skills/sitemap-audit/（或个人 skills 目录）。
  2. 准备 Sitemap URL；建议同时给出站点根 URL；可选附上抓取 CSV。
  3. 在对话中调用，例如：按 sitemap-audit 诊断 https://www.huaweicloud.com/sitemap.xml，站点根 https://www.huaweicloud.com/。
  4. 按报告模板输出 HTML；在 GEO 仓库中同步到 docs/ 与 report-serve/。可对照示例：华为云 Sitemap 轻量诊断。
