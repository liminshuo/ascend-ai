控件名称与值可读

原则定义

进度、滑块和评分等控件，若当前值或状态只靠图形填充、滑块位置或星标表达，AI Agent 难以准确识别。

用途、数值、单位与统计口径须写成可读文本或语义属性；图形控件只作视觉辅助。

元素拆解

进度

进度由可读数值文案与进度条构成。百分比、步骤数等口径须写成可见文字；进度条只作辅助。

数值文案1训练进度 60% · 已完成 3/5 步

2进度条

视觉规则

  1. 1数值文案写出当前进度及必要单位或总量（如百分比、已完成步数）。
  2. 2进度条仅辅助展示比例，不单独承载可读数值。

前端规则

  1. 可见文本进度句写入 DOM 文本节点，随状态同步更新。
  2. progressbar可用 role="progressbar" 与 aria-valuenow / aria-valuetext 补充语义。

示例如下：

<p>训练进度 60% · 已完成 3/5 步</p>
<div role="progressbar" aria-valuenow="60" aria-valuetext="60%"></div>

滑块

滑块由当前值文案与滑轨构成。须写出参数名与数值；滑块图形只作辅助。

当前值1批大小：8

2滑轨

视觉规则

  1. 1当前值写成「参数名：数值」，必要时标注单位或可调范围，并随拖动同步更新。
  2. 2滑轨仅辅助表达位置，不单独承载可读数值。

前端规则

  1. 可见文本当前值写入 DOM 文本节点，与滑块状态同步。
  2. rangeinput[type=range] 配合 aria-valuetext 补充语义。

示例如下：

<p>批大小：8</p>
<input type="range" value="8" aria-valuetext="8">

评分

评分由分值文案与星形装饰构成。须写出分数及人数等统计口径；星标只作视觉辅助。

星标1★★★★☆

分值文案24.6 分 · 128 人评价

视觉规则

  1. 1星标仅作视觉辅助，不单独承载可读分值。
  2. 2分值文案写成可读分数与统计口径（如人数、评价次数）。

前端规则

  1. 装饰星标星形可用 aria-hidden，不承载独立语义。
  2. 分值节点分数与统计口径写入文本节点。

示例如下：

<span aria-hidden="true">★★★★☆</span>
<span>4.6 分 · 128 人评价</span>

适用边界

上述规则适用于进度、滑块、评分等控件的当前值或状态需要被 AI 识别、核对或引用的场景。

数值变化须同步更新可见文本或语义属性；纯装饰图形若不承载独立信息，无需额外语义说明。
