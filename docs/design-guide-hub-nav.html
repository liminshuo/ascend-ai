枢纽如何导流

一页只主攻一种任务——导流或承载；壳页别当说明书。

场景说明

首页、分区壳、资源中心大门这类枢纽页，任务是把人（和机器）指到对的去向：训练开发、推理部署、文档叶子页。常见三种画法：入口卡墙（标题 + 短述 + 真链）、链接列表 / 写清去向的轮播默认帧、或空图封面 +「了解更多」/ 口号轮播。

对人来说，大图和口号也能点进去；对机器来说，稿面要能读出去向名。规格表、安装步骤放叶子页，别堆在壳页卡里。轮播若当入口，默认帧也要有标题、短述和链接；纯运营口号别当事实源。

  • 任务：首页 / 分区壳指路
  • 页型：入口墙、专题枢纽、资源中心大门

方式选型

同一任务下三种拼法，按推荐程度自上而下。

枢纽优先入口卡墙：去向名写在标题上。链接列表或「写清去向的默认轮播帧」也可。空封面只写「了解更多」、口号帧当说明书，机器最难看清去哪。

亲和说明

亲和选型

  • 方案 A（推荐）：入口卡墙；标题写去向名，短述 + 真链都在稿面
  • 方案 B（可接受）：链接列表写清去向；或轮播默认帧含标题 + 短述 + 链
  • 方案 C（不推荐）：空封面只写「了解更多」；口号轮播当事实源；壳页卡塞规格 / 步骤
  • 枢纽只主攻指路；说明书进知识叶子页
  • 「更多」若存在，必须指向真列表页（并遵守列表翻页）
