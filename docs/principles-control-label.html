控件名称与值可读

概述

输入框、滑块、进度条和评分等控件用于表达操作用途、当前值和状态，但这些信息可能仅通过占位符、图形或视觉位置呈现，导致 AI Agent 难以准确识别。

控件标签与数值可读取原则旨在确保控件的用途、当前值、单位和状态能够通过明确的文本或语义化属性获取，帮助 AI Agent 准确理解控件含义及其当前状态。

具体原则

  1. 控件应有明确的名称和用途说明。输入框等应通过关联的 label 或 aria-label 标明用途，不能仅依赖占位符或图标；名称应准确表达用途，不要求额外重复添加与用途无关的标题。
  2. 动态数值应以可读取的文本或语义化属性呈现。进度、评分、滑块等控件应提供当前值，必要时标注单位、总量或统计口径。
  3. 控件状态应明确表达。对于禁用、加载、选中等状态，应提供可识别的语义信息，避免仅通过颜色、位置或图形区分。
  4. 控件的可见信息与实际状态应保持一致。用户操作导致数值或状态变化时，应同步更新对应文本和语义属性，避免读取到过期信息。

预期效果

  1. 帮助 AI Agent 准确识别控件用途、当前数值及状态，减少对占位符、图形和视觉位置的依赖。
  2. 提高进度、参数和评分等信息的可读取性与可理解性，减少因单位缺失或统计口径不明造成的歧义。
  3. 确保控件状态和数值变化能够被及时获取，提升交互信息的准确性与可用性。

注意事项

  1. label 应与对应控件正确关联；aria-label 可用于没有可见标签的场景，但不能无必要地重复已有标签。
  2. 占位符用于提示输入格式或示例，不应替代控件名称。
  3. 进度、滑块和评分等动态信息应同步更新文本或语义属性，避免数值与实际状态不一致。
  4. 数值应根据场景标注必要的单位、总量或统计口径，避免孤立数字产生歧义。
  5. 装饰性图标不承载独立信息时，无需额外添加语义说明。
