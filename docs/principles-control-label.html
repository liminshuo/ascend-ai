控件标签可独立识别

为了帮助 Agent 判断控件用途再操作，按钮、输入、选项须有独立可见标签；占位符不能代替标签。

适用对象

名称 说明 常见落点
独立标签 每个输入须有可见 label；placeholder 只示范格式，不能当唯一说明。 搜索框、表单输入
拼接输入 一个字段拆成多框时，每框须有自己的标签，不能只靠总标签或占位拼接。 版本拆分、日期拆分

适用场景

优先级 页面类型 说明
必做 文档站搜索、筛选、安装 / 配置表单 Agent 需识别字段用途后再填写或检索。
建议做 官网注册 / 试用、资源申请表 进引用池或自动化填写时，标签须可判读。
可不做完整改造 纯装饰搜索条，且旁侧已有同义说明 不承载唯一任务入口时，可保留弱标签，但仍忌只靠占位。

设计UI调整

调整建议

  • 标签不靠占位 每个输入须配可见 label；placeholder 不一定能被抓到，也不能作唯一字段说明。
  • 拆框各有标签 字段拆成多框时，每框须有自己的标签；总标签不能替代各框标签。

文档内容调整

调整建议

  • 说明与标签一致 表单说明、必填与格式约束写在标签或旁注，与稿面 label 用语一致。
  • 禁止只写占位 关键约束不得只出现在 placeholder；文档示例与截图也须展示独立标签。

前端调整

调整建议

  • label 完备 每个输入有 label[for] 或等价可见关联；aria-label 可补不可替可见标签。
  • 首包可见 标签与控件同在首包 DOM；禁用态须有文字原因，勿只变灰。
