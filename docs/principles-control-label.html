控件须配独立标签

按钮、输入、选项须有独立可见标签，使 Agent 能判断用途再操作；占位符不能代替标签。 可读 · 设计专项见 控件须配独立标签。

对象

类型 说明 常见落点
独立标签 每个输入须有可见 label；placeholder 只示范格式，不能当唯一说明。 搜索框、表单输入
拼接输入 一个字段拆成多框时，每框须有自己的标签，不能只靠总标签或占位拼接。 版本拆分、日期拆分

设计UI调整

调整建议

  • 标签不靠占位：每个输入须配可见 label；placeholder 不一定能被抓到，也不能作唯一字段说明。
  • 拆框各有标签：字段拆成多框时，每框须有自己的标签；总标签不能替代各框标签。

文档内容调整

调整建议

  • 说明与标签一致：表单说明、必填与格式约束写在标签或旁注，与稿面 label 用语一致。
  • 禁止只写占位：关键约束不得只出现在 placeholder；文档示例也须展示独立标签。

前端调整

调整建议

  • label 完备：每个输入有 label[for] 或等价可见关联；aria-label 可补不可替可见标签。
  • 首包可见：标签与控件同在首包 DOM；禁用态须有文字原因，勿只变灰。

调整示例

拆框各绑 label

Before

<fieldset>
  <legend>软件版本</legend>
  <input placeholder="例如 CANN" />
  <input placeholder="例如 8.0.0" />
</fieldset>

仅有总标签；各框靠占位说明。

After

<fieldset>
  <legend>软件版本</legend>
  <label for="pkg">软件包</label>
  <input id="pkg" placeholder="例如 CANN" />
  <label for="ver">版本号</label>
  <input id="ver" placeholder="例如 8.0.0" />
</fieldset>

每框有可见 label；占位只示范格式。
