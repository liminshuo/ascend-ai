章节可访问

每一节须有可引用的独立 URL；目录指向该节，标题旁可辨识锚点，使 Agent 能定位到任务相关小节，而不是整页含糊引用或仅靠页内滚动。 可达 · 设计专项见 章节锚点可引用。

对象

对象 描述
节级锚点 每一节须有可引用的独立 URL；目录须指向该节，禁止只有页内滚动、没有节级地址。常见落点：文档正文、本篇目录。
锚点标识 标题旁可标「#」，稿面须看得出该段对应哪条 URL。常见落点：章节标题旁。

设计UI调整

调整建议

  • 锚点层级范围：正文 H2–H3 必须可设节级锚点；H4 及以下按需（长文细分步骤时开启）。篇名 H1 用页面 URL，不另做页内锚点。
  • 锚点须可辨识：可锚点标题旁须标出「#」或等价标识，便于识别对应 URL；锚点不得仅存于悬停或需猜测的位置。
  • 点击可复制锚点：点击「#」或复制控件，须一键复制完整含 hash 的 URL，并给出成功反馈（如 toast「已复制链接」）。
  • 目录须可点：目录须覆盖所有可锚点标题（至少 H2–H3），条目须为可跟链文字，不得做成纯文本列表。

2. 点击「#」可复制锚点

反面

安装步骤#

「#」仅装饰 / 仅悬停出现，点击无响应。

  • 常见疏漏：看得见锚点标识，却无法一键拿到 URL。
正面

安装步骤#已复制链接

点击「#」复制：…/install.html#install-steps

  • 正确做法：一键复制含 hash 的完整 URL，并给出成功反馈。

文档内容调整

调整建议

  • 标题可独立理解：避免「如下」「续」「说明」等无主题标题。
  • 目录文案与标题一致：目录项字面等于对应节标题。
  • 跨页写清节名：引用写「篇名 · 章节名」，禁止「见上文」「点击这里」。

调整示例

节标题与跨页引用

Before · 无主题标题

Markdown / 正文

## 如下
准备驱动与依赖…

## 续
按顺序执行安装命令…

参见上文。

标题不可独立理解；跨页引用无法落到具体节。

After · 可引用节名

Markdown / 正文

## 安装前提
准备驱动与依赖…

## 安装步骤
按顺序执行安装命令…

详见《安装指南》· 安装步骤。

节名可作锚点文案；跨页引用带篇名 · 章节名。

前端调整

调整建议

  • 稳定 id 与目录一致：标题带稳定 id；目录用 a[href="#id"] 指向该节。
  • 首包即含锚点：禁依赖 JS 才注入 id / 目录链。
  • slug 规则固定：id 按统一规则生成或 CMS 指定，不随渲染顺序漂移。
  • 复制锚点可得：标题旁「#」或复制链接输出含 hash 的完整 URL。

调整示例

标题 id 与目录 href

Before · 无节级地址

HTML 源码

<h2>安装前提</h2>
<nav class="toc">
  <span>安装前提</span>
  <span>安装步骤</span>
</nav>

无 id、目录不可跟链；只能页内滚动。

After · 节级可引用

HTML 源码

<h2 id="install-prereq">安装前提</h2>
<nav class="toc">
  <a href="#install-prereq">安装前提</a>
  <a href="#install-steps">安装步骤</a>
</nav>

首包即含稳定 id；目录与正文 hash 一致。
