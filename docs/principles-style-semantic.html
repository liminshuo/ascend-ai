颜色含义可读

概述

颜色是网页表达状态、风险等级和信息分类的常见方式，但颜色本身承载的含义不一定能被 AI Agent 直接识别和准确理解。

颜色语义可转写原则旨在将颜色所表达的关键信息通过文本明确呈现，减少因缺少文字说明或上下文而产生的语义歧义，帮助 AI Agent 准确获取和使用相关信息。

具体原则

  1. 对于颜色所代表的风险等级、运行状态和提示信息，应通过可直接读取的文本明确表达，避免仅依赖颜色传递关键信息。
  2. 对于通过颜色区分的数据类别、图表系列或功能模块，应提供文字标签、图例或其他可读取的标识，帮助 AI Agent 理解不同颜色对应的含义。
  3. 确保颜色所表达的状态、等级和类别与对应文本一致；当状态或数据发生变化时，同步更新颜色和文本，避免信息不一致。
  4. 对于不承载独立信息的背景色、装饰色等，无需额外补充语义说明，避免引入冗余信息。

颜色含义写成可读文字

颜色可以继续承担视觉强调，但风险级别、状态和图例分类必须有可见文字，不能只让 Agent 猜色彩含义。

预期效果

  1. 帮助 AI Agent 通过文本准确获取颜色所表达的状态、风险等级和信息分类，减少对颜色视觉识别的依赖。
  2. 明确颜色与数据类别、状态及提示信息之间的对应关系，提升页面内容的可理解性、可检索性和可引用性。
  3. 减少因颜色含义不明确、缺少文字标识或颜色与文本不一致造成的信息误判。

注意事项

  1. 不应将颜色作为传递关键状态、风险或分类信息的唯一方式，应提供明确的文字标签或说明。
  2. 对于图表、状态指示器和多类别信息，应明确标注颜色对应的含义，避免仅凭颜色推断信息。
  3. 文字说明应表达颜色实际代表的业务含义，而非仅描述颜色本身，例如使用「运行异常」而非「红色状态」。
  4. 当业务状态、数据类别或图表内容发生变化时，应同步更新颜色、文本标签和图例。
