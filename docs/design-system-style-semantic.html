原则定义

颜色常用来表达风险等级、运行状态或信息分类，但颜色本身的含义不一定能被 AI Agent 直接识别。需要用可读取文本标明颜色所代表的级别、状态或类别。

背景色、装饰色若不承载独立信息，不必额外补语义；颜色与文本须保持一致，并随状态同步更新。

元素拆解

警示级别

警示条可用颜色强调，但必须用「警告」「注意」「提示」等可见文字写出级别；不要只靠色块传递风险等级。

警告：请勿在生产环境使用未验证驱动。

警示级别词1

注意：更换驱动前请备份配置。

提示：安装完成后请重启设备。

视觉规则

  1. 1警示级别词用「警告」「注意」「提示」等写出颜色意义；色条仅作辅助强调。

前端规则

  1. 可见前缀警示级别词写入正文文本节点，勿只改背景色或左边框。

示例如下：

<p><strong>警告：</strong>请勿在生产环境使用未验证驱动。</p>

状态词

禁用、运行等状态须写成「已禁用」「运行中」「已停止」；灰色或色点只作辅助，不得作为唯一含义来源。

视觉规则

  1. 1状态词用「运行中」「已停止」「已禁用」等写出业务含义；色点仅作辅助。

前端规则

  1. 色点辅助色点可保留并设 aria-hidden；状态词必须是可见文本。

示例如下：

<span class="dot" aria-hidden="true"></span>
<span>设备管理服务</span>
<span>运行中</span>

适用边界

适用于警示条、禁用态、运行态、图表图例等需要被 Agent 识别级别、状态或分类的场景。

不承载独立信息的背景色、装饰色无需补充语义说明。

文字应表达业务含义（如「运行异常」），而非仅描述颜色本身（如「红色状态」）；状态变化时同步更新颜色与文本。
