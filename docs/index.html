共用标尺 · AI亲和 Level

背书闸门

愿不愿意让 AI 把这页当官方事实原样引用？

不愿意 → 停在基线，业务价值再高也不升档。典型：定价页价值高，却因报价会变而故意不进机器目录。

三档 Level

未就绪

缺索引，或正文不可读

Sitemap / llms 都找不到，或主信息靠 JS 才出现且无平行 MD。

走出：公开页须保证 HTML 可读（主信息不靠 JS 才出现）。

基线亲和

Sitemap · HTML 可读

进内容面 Sitemap，禁 JS 也能读到完整主信息。服务 SEO / 人读；默认不进 llms、不强制 MD。

达到：用户会问「怎么做 / 是什么」→ 进 Sitemap。

深度亲和

llms · Markdown 可读

写入机器目录，并提供与 HTML 同源的平行 Markdown。只给官方愿背书的事实叶子页。

升档：长期稳定、愿背书 → 补 llms 与平行 MD。能搜到 ≠ 该被引用。

分面落点

非知识面默认

基线亲和封顶

营销、生态、博客、定价、活动等：可进 Sitemap；不进 llms，不强制 MD。

知识面目标

做到深度亲和

文档 / API / 教程 / 支持库：先 Sitemap + HTML，再补 llms 与平行 MD。

明确不做

  • 会频繁变且过期有害定价、活动日程、报价
  • 说服性而非事实性营销卖点、客户证言、博客观点
  • 与产品使用无关招聘、法务、公司新闻、登录账户
  • 壳页与弱背书转化入口、纯导航目录根、社区 / Wiki / UGC
