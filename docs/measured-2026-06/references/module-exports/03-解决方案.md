# 模块 03 · 解决方案

> 对应 HTML：[solutions.html](../../solutions.html)  
> 关联 Claude 对话：03-知识库与大模型集成方案

## 双轨交付架构

```
HTML 源 → 人类阅读层（document/detail）
       → 模型消费层（MD / JSON / llms.txt）→ RAG / Agent
```

## 格式优先级

| 场景 | 格式 |
|------|------|
| RAG 入库 | MD + YAML Front Matter |
| Agent 调用 | JSON API |
| 人类阅读 | HTML 站点 |
| 发现索引 | llms.txt |

## 轻量 IA

每页提供：breadcrumb、prev/next、version、keywords、applicable_devices  
不需要：全站 282 项导航菜单

## 知识库集成

1. 源提取 → doc_center/source HTML
2. 转换 → MD + Front Matter
3. 切片 → 按 H2/H3 边界
4. 入库 → 向量库 + JSON API
5. 检索 → 语义搜索 + 元数据过滤

## 落地路线

- **Phase 1**：alt、热区冗余、LINK 修复、llms.txt、代码行号分离
- **Phase 2**：HTML→MD 管道、JSON-LD breadcrumb、admonition 标签
- **Phase 3**：CI/CD 双轨发布、RAG 切片、抓取回归测试
