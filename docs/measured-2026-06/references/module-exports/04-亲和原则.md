> 关联 Claude 对话：05-AscendC语言学习指南、06-静态Tensor编程内容解读

## 总原则

| 原则 | 说明 |
|------|------|
| 语义先行 | 信息须有文本表达 |
| 扁平交付 | 隐藏/Tab 内容全部展开 |
| 双通道一致 | 人类 ≈ 模型，信息不丢 |
| 元数据外显 | 类型、设备结构化 |
| 源页瘦身 | 剥离导航壳 |

## 组件规则速查

| 组件 | 核心规则 |
|------|----------|
| 标题 H-01~04 | 一个 H1，层级连续，有锚点 |
| 链接 L-01~05 | 描述性文本，热区文本冗余 |
| 图片 IMG-01~05 | alt + 转写，热区变链接列表 |
| 表格 TBL-01~04 | 有 caption，不嵌代码 |
| 代码 CODE-01~06 | 标注语言，行号分离 |
| 注意 NOTE-01~04 | 类型文本化，MD 引用块 |
| Tab TAB-01~04 | 源层全展开，标签作 H3 |
| 折叠 COLL-01~05 | 机器层默认展开 |

## 复杂内容：静态 Tensor

- 概念密度高 → H2/H3 严格分层
- 代码与概念交织 → 概念→代码→说明 三段式
- 前置依赖多 → prerequisites 元数据
- 模板代码难解析 → 标注 language + 逐行注释
