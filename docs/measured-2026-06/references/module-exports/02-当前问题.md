## 问题维度框架

### 页面形式
HTML 渲染页噪声、MD 未作为正式出口、JS 依赖、双端点未声明

### 内容获取
- 图片 — 无 alt、热区丢失
- 链接 — LINK 占位符、导航污染
- 表格 — 标杆较好，caption 缺失
- 代码块 — 行号污染、语言未标注
- 注意提示 — 类型不可识别
- 卡片 — Tab/折叠隐藏、设备卡片未结构化

### 结构感知
- 跨文档 — breadcrumb 消歧、版本混淆、热区导航丢失
- 单文档 — chunk 边界、嵌套语义、Tab 扁平化失败

## 大模型回答侧问题

| 问题 | 表现 |
|------|------|
| 官方内容占比少 | 大模型回答中，来自昇腾社区官方的内容少 |
| 版本不是最新 | 回答的信息不是最新版本的（如 8.5 vs 9.0 混淆） |

**关联改造**：机器友好源、llms.txt、version 元数据、引用溯源

## 格式与噪声

| 维度 | 现状 | 影响 |
|------|------|------|
| 页面体积 | ~224 KB | Token 消耗 20–50 倍 |
| 导航链接 | 282 个/页 | 稀释正文语义 |
| JS 渲染 | 161 处 v-if | 静态爬虫不完整 |
| 隐藏层 | 34 处 display:none | Tab/折叠被跳过 |

## 能抓取 ✅

标题、正文、列表、表格、代码主体、注意提示正文、站外链接、Topic 锚点

## 不能抓取 ❌

- 图片热区（28 个链接全丢）
- 无 alt 示意图
- Tab 隐藏面板
- 行号污染代码
- 「LINK」占位符
- 折叠未展开内容
