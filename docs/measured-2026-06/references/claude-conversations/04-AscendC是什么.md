## 已提炼要点（来自研究报告）

- Ascend C 是 CANN 针对算子开发推出的编程语言，原生支持 C/C++
- 五层 API：语言扩展层 C API → 基础 API → 高阶 API → 算子模板库 → Python 前端（PyAsc）
- 支持 Atlas A2/A3、Atlas 350 等多系列 AI 处理器
