# Ascend C 算子开发介绍（基于官方资料）

## 一、什么是 Ascend C？

Ascend C 是华为 CANN（Compute Architecture for Neural Networks）针对昇腾 AI 处理器算子开发场景推出的编程语言。它原生支持 C 和 C++ 标准规范，兼具开发效率和运行性能[^1]。2023 年 5 月 6 日，在昇腾 AI 开发者峰会上正式发布[^2]。

基于 Ascend C 编写的算子程序，通过编译器编译和运行时调度，运行在昇腾 AI 处理器（NPU）上。使用 Ascend C，开发者可以基于昇腾 AI 硬件，高效地实现自定义的创新算法[^1]。

Ascend C 是 TBE TIK 的官方替代方案[^3]。

## 二、核心特点

| 特点 | 说明 |
|------|------|
| **C/C++ 原生编程** | 原生支持 C 和 C++ 标准规范，最大化匹配用户开发习惯，学习曲线低 |
| **屏蔽硬件差异** | 编程模型屏蔽了底层硬件差异，提高了代码的通用性 |
| **多层 API 封装** | 类库 API 封装，既保证易用性，又兼顾高效性 |
| **孪生调试** | 支持在 CPU 侧模拟 NPU 侧的行为（Asc-Tools），便于调试 |
| **自动并行计算** | 编译器自动优化，性能接近手写汇编 |

[^1][^4]

## 三、编程模型

Ascend C 采用 Host-Device 异构协同架构，一个完整的算子实现主要包含两个部分[^5]：

### 3.1 Host 侧 —— Tiling 实现（CPU 端）

由于 NPU 中 AI Core 内部存储（Local Memory）无法完全容纳算子输入输出的所有数据，需要每次搬运一部分输入数据进行计算然后搬出，再搬运下一部分，这个过程称为 Tiling（切分）。

Tiling 函数根据算子的 shape 等信息来确定数据切分算法的相关参数（如每次搬运的块大小、总循环次数等）[^5]。

Host 侧充当「指挥者」角色，负责计算调度策略[^6]。

### 3.2 Device 侧 —— Kernel 实现（NPU 端）

Kernel 实现即算子核函数，使用 `__global__` 修饰，运行在 AI Core 上。在 Kernel 函数内部[^3][^5]：

- 解析 Host 侧传入的 Tiling 结构体获取 Tiling 信息
- 根据 Tiling 信息控制数据搬入搬出 Local Memory 的流程
- 调用计算、数据搬运、内存管理、任务同步 API，实现算子逻辑

## 四、核心编程概念

### 4.1 内存层次模型

昇腾 AI 处理器的内存分为多个层级：

- **Global Memory（全局内存）**：外部存储，容量大但访问慢
- **Local Memory（本地内存）**：AI Core 内部的高速缓存，容量有限但访问极快
- 算子开发的核心之一就是在 Global Memory 和 Local Memory 之间高效地搬运数据[^7]

### 4.2 并行执行模型（SPMD）

Ascend C 采用 SPMD（Single Program Multiple Data）编程模型，实现多核并行计算[^8]：

- 将数据切分为多个分片，分配给不同的计算核心（block）并行处理
- 多个 AI Core 共享相同的指令代码
- 每个核通过唯一的 block_idx 来识别自身身份，处理不同的数据分片

### 4.3 流水线编程范式

Ascend C 的编程范式是一种流水线式编程范式（Pipelining），核心要素包括[^9]：

- **流水任务设计**：将核内处理程序分成多个并行任务（Stage），如 CopyIn、Compute、CopyOut
- **任务间通信和同步**：通过队列（Queue）完成任务间通信和同步（DeQue/EnQue）
- **内存管理**：通过统一的 Pipe 模块管理任务间通信内存

每个并行任务 Stage 的标准编程范式为[^9]：

1. AllocTensor 申请内存 / DeQue 从上游队列获取数据
2. 完成计算或数据搬运
3. EnQue 将处理好的数据入队
4. FreeTensor 释放不再需要的内存

## 五、多层级 API

Ascend C 提供多层级 API，满足多维场景算子开发诉求[^1]：

开发者可根据需求选择不同层级的 API，从快速原型开发到极致性能调优均可覆盖[^10]。

## 六、算子开发流程

基于官方文档，Ascend C 算子的标准开发流程如下[^11]：

1. 环境准备 → 安装 CANN 开发套件包
2. 算子分析 → 明确算子数学逻辑、输入输出 Tensor 及需调用的 API
3. 核函数开发 → 编写运行在 NPU 上的核心计算代码
4. CPU 侧验证 → 使用 ICPU_RUN_KF 宏在 CPU 侧模拟验证（孪生调试）
5. NPU 侧验证 → 使用 `>>>` 内核调用符在 NPU 上运行验证
6. 性能调优 → 使用性能分析工具进行优化

工程目录结构示例[^12]：

```
MatmulCustom/
├── build.sh
├── CMakeLists.txt
├── op_host/
│   ├── matmul_custom.cpp
│   └── matmul_custom_tiling.h
└── op_kernel/
    └── matmul_custom.cpp
```

## 七、支持的产品型号

Ascend C 支持以下昇腾产品系列[^1]：

- Atlas A3 训练系列产品 / 推理系列产品
- Atlas A2 训练系列产品 / 推理系列产品

## 八、开发前提与学习路径

根据官方最佳实践文档，开发者在使用 Ascend C 前需要具备[^13]：

- 熟练使用 C++ 编程语言
- 了解计算机架构
- 理解昇腾 AI 处理器硬件架构

官方提供的学习资源包括：快速入门、成长地图、概念原理、API 参考、最佳实践。（无独立脚注）
