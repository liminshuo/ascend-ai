昇腾社区 GEO 指标字典

与基线报告同源：按三个测试维度组织——Sitemap 结构质量 → llms.txt 目录与 Markdown 资源可用性 → AI 回答中的品牌可见度与引用质量。后一维不可从前两维推算；测不出的不占定稿值。

下载《昇腾社区 GEO 指标字典.xlsx》 下载《GEO 22 指标精简可追溯记录表》
01

维度 1 · Sitemap 结构质量

评估目的：Sitemap 是搜索引擎爬虫与 AI Agent 发现站点 URL 的入口。重复 URL、非预期 Host 及查询参数膨胀可能增加 URL 处理开销，影响内容发现与下游处理效率。本维仅评估 Sitemap 的静态结构与条目质量，不代表页面已被收录或能够正常访问。

指标名称定义计算公式 / 口径
重复 URL 率
优先级·高
Sitemap 中精确重复 URL 条目数占原始 URL 条目总数的比例，用于衡量去重质量。精确重复不代表页面内容重复。(原始条目数 − 精确去重数) ÷ 原始条目数 × 100%
非预期 Host 占比
优先级·高
Host 不在预期白名单内的 URL 占比，用于核查域名配置一致性。已纳入白名单的 CDN/业务子域不计为异常。非白名单 Host 条目数 ÷ 原始条目数 × 100%
查询参数 URL 占比
优先级·中
含查询参数的 URL 占比，用于识别筛选/追踪等参数可能造成的 URL 扩张；不直接判定为异常。含查询参数条目数 ÷ 原始条目数 × 100%
lastmod 缺失率
优先级·中
未提供 lastmod 字段的 URL 占比；仅检查字段是否存在，不代表已提供时间真实准确。缺少 lastmod 条目数 ÷ 原始条目数 × 100%
特殊编码 URL 占比
优先级·辅助
含百分号编码的 URL 占比，用于描述编码情况；合法编码不代表异常，不纳入核心评分。匹配编码模式条目数 ÷ 原始条目数 × 100%
02

维度 2 · llms.txt 目录与 Markdown 资源可用性

评估目的：llms.txt 为 AI Agent 提供精选内容目录。需验证目录入口是否可访问、人读页与 Markdown 路径是否配对，以及声明的 Markdown 链接能否获取有效正文。目录配对 ≠ 链接可访问 ≠ 正文有效。单纯 HTTP 200 不作为 Markdown 可访问的判定依据。

指标名称定义计算公式 / 口径
llms.txt 线上可访问性
优先级·高
站点根路径 /llms.txt 是否可通过 HTTP 获取，并返回可读取的目录文本，而非空响应或拦截页。可访问 / 不可访问（定性）
页面—MD 配对率
优先级·高
同时包含人读页 URL 与对应 llms-content/*.md 路径的目录记录占比；衡量目录层链接配对完整性。具备配对链接的目录记录数 ÷ 目录记录总数 × 100%
Markdown 链接线上可访问性
优先级·高
目录中的 llms-content/*.md 链接目标能否在线获取并返回预期 Markdown 资源，而非 WAF/登录页。可访问 / 不可访问（定性）；单纯 HTTP 200 不作可访问依据
Markdown 正文有效性
优先级·中
在成功获取目标资源的前提下，检查正文是否非空、可读取且符合预期 Markdown 格式。尚无足够正文证据时记「无法判定」，而非「不可访问」。有效 / 无效 / 无法判定
03

维度 3 · AI 回答中的品牌可见度与引用质量

评估目的：基于 24 道测试题在三个 AI 平台上的回答，评估昇腾品牌提及、官方来源引用、引用内容对回答主张的支持程度及事实准确性。该维度直接衡量 AI 回答层面的实际表现，无法通过 Sitemap 或 llms.txt 的静态结构指标推算。

指标指标定义计算公式
昇腾相关问题品牌提及率
优先级·高
在本轮均为昇腾相关问题的有效回答中，明确提及「昇腾」「Ascend」或「昇腾社区」的占比。不等同于全问题域品牌曝光率，也不等同于来源引用率。提及目标品牌的有效回答数 ÷ 有效回答总数 × 100%
官方来源引用率
优先级·高
有效回答中明确引用或链接昇腾社区官方页面的占比；不等同于搜索引擎收录率。含官方页引用/链接的有效回答数 ÷ 可判定有效回答数 × 100%
引用支持率
优先级·高
引用来源能否支持回答中对应主张。主指标仅计「支持」；「部分支持」「不支持」另列。判定为「支持」的主张数 ÷ 已完成支持性判定的主张数 × 100%
事实准确率
优先级·高
经核验判定为正确的事实项占可判定事实项总数的比例；无法判定项另报，不进分母。正确事实项数 ÷ 可判定事实项总数 × 100%
关键问题覆盖率
优先级·中
已覆盖关键要点数 ÷ 全部预设关键要点数；不以回答长度代替完整度。已覆盖要点数 ÷ 预设要点总数 × 100%
