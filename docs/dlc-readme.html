三种学习方式：

  1. 社区路径 / 课程 / 认证 — 按下方主线进入昇腾 DLC 人读页

当你（或智能助手）听到「我想学 XXX」时，按主题 key 一键出图：

# 在本目录下
python3 scripts/generate.py --topic inference --out ./out/推理学习旅程.html \
  --role 开发人员 --goal 大模型推理入门 --level 入门
参数说明
--topic上表 11 个 key 之一
--role / --goal / --level可选画像；缺省见 scripts/topics.py
--out输出 HTML 路径

资讯 / 案例意图（「有什么新技术」「实践案例」）走博客墙：

python3 scripts/build_blog_wall.py --out ./out/技术博客墙.html
