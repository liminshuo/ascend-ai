下拉子链首包缺失 子项须进源码

查看测试页面

下拉子链首包缺失指下拉菜单内导航项须在首包 HTML 可读；勿悬停/点击/JSON 注入才挂载子链，否则发现层断裂。 以 集群产品页 为例：集群页标题旁「更多产品」下拉切换同品类机型。

问题实测

1. 向模型提问

根因分析

下拉子链首包缺失的核心原因：下拉面板子项依赖点击/悬停或外部 JSON 才挂载，静态抓取只能看到触发器（「更多产品 / Products / Resources」），看不到各子项 a[href]。

1. dropdown-panel 空壳

问题：昇腾侧：集群页浏览器可见「更多产品」及 Atlas 900 A2 PoD / SuperCluster AI 集群等项，静态 HTML 无 panel 内 a[href] 列表。

友商侧：Mintlify pricing 顶栏 Products/Solutions/Resources 触发器在首包，mega menu 子项（Platform / Editor / Authentication / Automations / Agent 等）须悬停/点击才挂载 panel。

修改建议

SSR 输出完整 dropdown 子项：每项可读 label + href；视觉可折叠但 DOM 须保留 a 节点。

2. 菜单 JSON 外部注入

问题：NVIDIA developer.nvidia.com：Resources 下拉含 Developer Program / Community Hub / Discord / GTC / On-Demand 等，静态 HTML 仅 div#header 空壳，子链在 header-secondary.json 须 fetch + NVDeveloperHeader 客户端挂载。

修改建议

关键子链 SSR 进首包 HTML；外部 JSON 菜单仅作增强，不可作唯一发现层。

3. portal / 延迟挂载

问题：下拉项在点击后才注入 DOM 或挂到 body portal，首包无 li/a；与 Mintlify navigation-menu data-state=closed 同类。

修改建议

子项写在页面静态 nav/ul 区，勿仅 portal 延迟挂。

4. 触发器当唯一信息

问题：入库 chunk 只有「更多产品 / Products / Resources」等触发器文案，Agent 无法证伪各子项 URL。

修改建议

子项文案与落地页 title 一致，并带 canonical href。
