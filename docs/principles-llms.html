llms.txt

llms.txt 概述

根 llms.txt 是站点入口给机器的知识面清单，既可包含分册 llms.txt，也可包含单页 .md，仅收主推知识面。它的目标是以极少 token 决定下一步打开谁；读完应能选定内容面、站点或产品分册，首份清单需足够小以完成该判断。

解决什么问题

缺少入口清单时，Agent 只能猜测 URL 或检索人读页，容易落入营销页或空壳，无法稳定判定下一步打开谁。

核心原则

  • 约定路径可达文件放在站点根目录或对应子路径下，打开即可读取，不设跳转或登录门槛。一份 llms.txt 覆盖其路径下的所有页面。路径分册的地址，由更上层的清单显式写出。
  • 可发现性声明页面用 rel="alternate" type="text/markdown" 指向 Markdown 平行稿，用 rel="describedby" 指向覆盖该页的 llms.txt。可写在 HTML <link> 或 HTTP Link: 头（后者也适用于非 HTML）。
  • 结构固定可预期按标准 Markdown 顺序书写：# 站点或项目名（唯一必填），可选 > 简述，随后是零个或多个 ## 章节，每个章节挂一组链接列表。根清单按内容域或站点分节；页数多、仍需二次选择的面，写成子路径分册；一页可读完的，直接写 .md。分册内部同样按模块组织，只列目录，不写正文。
  • 链接指向可跟内容条目写成 - [名称](地址)，名称使用页面或分册的标题，而非 URL；其后可加冒号和一句说明，写清页面实际包含什么。地址优先指向 Markdown，便于 Agent 先扫描清单再跟链。次要条目可归入 ## Optional 章节。
  • 控制 token 消耗首份清单需足够小，读完即可判定下一步打开谁。根文件只精选主推内容面，不堆砌全站链接。分册可以比根文件大，但仍需整份能扫完节名和条目；页数多到无法扫完时，用页名清单 .md 外包，不再为同一域套一层 llms.txt。全文拼接交由 llms-full.txt 承载，不替代精选索引。

根 llms 交付示例

这是 Mintlify 的站根目录：只挂入口，不写文章。现网约 5.6KB、75 行、8 个 ##、三十余条链接（2026-09-10 实测 mintlify.com/llms.txt）。Agent 可以整份读完，也可先扫节名再跟分册。文档、博客、资料库、客户案例链分册 llms.txt；首页、定价、法务等一页读完的链 .md。文档站每一页不在这里，见分册llms。

根 llms.txt 交付件拆解

站点名与描述

  • 站点名用 # 写站点或项目名，提案里唯一必填。
  • 描述紧跟 > 引用块：这份清单是什么、怎么取平行稿。可省略；有则 Agent 先读完再往下选模块。

模块名与描述

  • 模块名每个模块一行 ## 标题。Agent 先扫这些名字，再决定进哪一节。
  • 怎么分按要找什么切块（文档、官网、博客等），不是把站点导航原样搬家。
  • 模块描述## 和链接之间可以有一段纯文字。可省略：Mintlify 的 Docs、Pages 就直接挂链接。

链接

  • 怎么写挂在对应 ## 下面，一条一行。格式是 - [标题](地址)，后面可以加 : 一句说明。标题用页面或分册名，不用 URL。
  • 写什么地址是下一步要打开的分册 llms.txt 或单页 Markdown。说明写清实际包含什么，宜短；可省略，如法务那条。

机器如何找到 llms 根目录

方式一：试约定路径

Agent 尚未落到单页、手里也没有清单地址时，会按行业惯例直接打开站点根 /llms.txt。v2 规定：文件也可放在子路径（如 /docs/llms.txt），覆盖该路径下的页面；多份并存时以最具体的为准。这一步不依赖 robots.txt 或 HTML 里先写过地址。

方式二：读 robots.txt

Agent 进站常先读 /robots.txt。可在末尾仿 Sitemap: 加一行 LLMs.txt:，把根清单地址写死。该字段不是官方规范，只作路径不确定时的补充。Mintlify 本站未写这一行，根文件仍靠方式一找到。

前四行是 Mintlify 实文件。注释里的 LLMs.txt: 是建议补上的声明，不是该站现网内容。

方式三：读 HTML 源码

Agent 也会读人读页的 HTML 或响应头。v2 用标准链接关系声明：Markdown 平行稿与覆盖该页的 llms.txt，不必只靠猜 /llms.txt。

rel="alternate" type="text/markdown" 指向本页 Markdown；rel="describedby" 指向覆盖本页的清单（文档页应指向 /docs/llms.txt，而非一律写站根）。也可在 HTTP Link: 头声明，适用于非 HTML。这不能替代页内真链。

方式四：跟页内入口

HTML 正文中提供指向根 llms.txt 的真链，作为内容层兜底。细则见站级导读。Mintlify 文档页隐藏导读指向的是分册 /docs/llms.txt，根文件仍应在官网或文档入口另备一条。

价值收益

  • 先看该看的主推知识面写在前面，不必从全站 URL 里筛。
  • 能跟到正文Agent 先读或检索清单，再跟随指向 Markdown 的链接。
  • 读得完、套得住根只挂入口；列页不再套 llms.txt。全文拼接留给 llms-full.txt。
