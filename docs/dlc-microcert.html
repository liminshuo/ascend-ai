# 多机多卡并行推理

> 本认证主要考核如何使用 MindIE 进行大模型推理部署的流程与优化方法，旨在帮助开发者高效完成大模型多机多卡并行推理部署。

## 认证概要
- 适用对象：对大模型推理部署感兴趣的企业、伙伴、高校开发者
- 认证级别：中级
- 能力范围：围绕昇腾平台上的大模型推理部署，覆盖模型迁移适配、并行策略选择、量化及性能优化等内容
- 学习时长：约 1.1 小时
- 通过条件：考试总分达到 70 分及以上（以官方公布的计分规则为准）
- 证书有效期：自颁布之日起 2 年
- 认证成果：以 DeepSeek 模型为例，学习使用 MindIE 进行大模型多机多卡推理部署的流程与优化方法
- 对应正式认证：未明确

## 认证内容

### 1. 大模型推理在昇腾上的部署（学习时长：6 分钟）
- 学习目标：了解大模型推理在昇腾上的部署方法

### 2. DeepSeek 模型迁移适配（学习时长：10 分钟）
- 学习目标：了解 DeepSeek 模型迁移适配方法

### 3. DeepSeek 模型并行策略选择及模型性能调优（学习时长：25 分钟）
- 学习目标：了解 DeepSeek 模型并行策略选择及模型性能调优方法

### 4. DeepSeek 量化精度及性能调优（学习时长：10 分钟）
- 学习目标：掌握 DeepSeek 量化精度及性能调优方法

### 5. MTP 优化（学习时长：12 分钟）
- 学习目标：了解 MTP 优化方法

### 6. 常见问题（学习时长：1 分钟）
- 学习目标：了解常见问题及解决方案

## 环境准备
本认证需完成大模型推理环境的搭建，可通过以下方式完成：
1. 使用昇腾硬件搭建 MindIE 推理环境
2. 使用华为云平台搭建 MindIE 推理环境

具体操作请进入认证界面，严格按照认证考试要求进行环境准备。

## 认证事项

### 考试规则
1. 考试仅支持电脑端操作
2. 通过考试后，需在 10 天内完成实名认证；逾期未完成实名认证将无法发放证书

### 证书获取与查询
1. 考试及实名认证均通过后 24 小时，可前往[个人中心-我的微认证](https://www.hiascend.com/profile/study?tab=micro-certification)查看证书编号或下载电子证书
2. 证书自颁布之日起 2 年内有效
3. 微认证证书支持在社区公开查询，可前往[微认证证书查询](https://www.hiascend.com/edu/certification/query)使用证书编号进行查询

1. 文首 Frontmatter（必填）

  1. 说明：标识微认证类型、唯一身份和人读页地址。
  2. 写法：置于文件最上方，以 --- 包裹；键名固定，勿增删。字符串值统一加双引号。
  3. title：微认证名称，与正文一级标题完全一致。
  4. type：固定为 "micro-certification"。
  5. schema_version：当前固定 "1.1"；由规范维护者更新，业务侧勿改。
  6. id：人读页 URL 末段 ID，须与人读页一致。
  7. url：人读页 HTTPS 绝对地址；路径为 /edu/certification/detail/…，不得误填正式开发者认证 /edu/developer-certification/detail/…。
  8. updated：内容最后更新日期 "YYYY-MM-DD"（非首次发布日）。

2. 标题与摘要（必填）

  1. 说明：微认证正式名称，以及一两句介绍（考什么、能力边界）。
  2. 写法：一级标题 # 微认证名，须与 Frontmatter title 完全一致；下一行以 > 写摘要，对齐人读页简介。

3. 认证概要（必填）

  1. 说明：说明对象、能力范围、学习投入和认证结果；能力范围是与正式开发者认证区分的核心，不能只依赖名称和级别。
  2. 写法：二级标题 ## 认证概要；下列 - 字段名：内容，一行一项。官方未公布的字段可省略，不得将未知推断为无要求。
  3. 适用对象：适合参加认证的人群及其背景。
  4. 认证级别：与人读页官方标注一致，如 入门级、中级、高级。
  5. 能力范围：必填。明确覆盖的技术主题、知识领域或实践任务；须与认证内容章节一致，不得写入未覆盖的能力。
  6. 学习时长：完成认证课程 / 学习内容所需时间（如 约 1.1 小时）；不等于考试时长。可按章节学习时长汇总核对；有四舍五入差异时以官方展示为准。
  7. 通过条件：官方公布的通过分数及计分要求（如 考试总分达到 70 分及以上（以官方公布的计分规则为准））。计分规则不明确时不得自行推断百分制或其他口径。
  8. 证书有效期：自颁布之日起的有效期限；可与认证事项中的操作说明并存。
  9. 认证成果：完成认证后能够掌握或验证的知识与技能；不得超出能力范围与认证内容。
  10. 对应正式认证：有明确关联时填 [名称](https://…)；经业务确认无关联时填 无；仅页面未展示、尚未确认时填 未明确。「无」与「未明确」不可互换，不得因页面未展示就推断为无。

4. 认证内容（必填）

  1. 说明：描述微认证实际覆盖的章节、学习目标与内容范围，供 Agent 判断能力边界。章节是学习内容单元，不是考试题目或考试权重；勿擅自赋予考试占比、题目数量等页面未提供的信息。
  2. 写法：二级标题 ## 认证内容；各章三级标题统一为 ### N. 章节名称（学习时长：N 分钟）；下挂 - 学习目标：…。按人读页表格逐项整理，保持顺序。
  3. 学习目标：忠实于人读页；不扩大能力范围，不将「了解」改写成「熟练掌握」。
  4. 时长：按官方数据填写，未提供则不自行估算；章节学习时长之和应与概要总学习时长基本一致。

5. 环境准备（条件必填）

  1. 说明：考前环境搭建要求，供 Agent 回答「要备什么环境」；放在认证内容之后、认证学习之前。
  2. 写法：独立二级标题 ## 环境准备；按人读页官方原文整理可选方式、硬性要求与操作入口说明。
  3. 缺省：人读页无该块时整节省略，不得自行编造；勿与「认证事项」下的考试规则混写。

6. 预备知识（可选）

  1. 说明：仅记录官方明确的前置要求；不是默认模块。
  2. 写法：有官方前置要求时用 ## 预备知识，每条单独列出。若仅为推荐背景，须标注「推荐」，勿写成强制准入。人读页无相关信息时整节省略，不自行推测。

7. 认证学习（条件必填）

  1. 说明：关联官方推荐的学习资源，回答「如何学习这项认证内容」。认证内容描述考查 / 覆盖范围，认证学习描述学习资源；二者可关联，但课程章节不等于考题。
  2. 写法：二级标题 ## 认证学习；按类型设三级标题，如 ### 推荐课程、### 推荐教程、### 推荐案例、### 实验与实践。
  3. 资源说明：每项资源一句介绍学习内容或实践目标。
  4. 学习成果：人读页有「通过本课程将掌握」等列表时，整理为编号列表保留。
  5. 关联认证内容：可选；将资源映射到「认证内容」章节名，须依据资源正文核验，不得仅凭标题推测。
  6. 缺省：仅收录人读页展示或业务明确认可的资源；无推荐资源时整节省略；无对应类型时不保留空标题。

8. 认证事项（必填）

  1. 说明：说明考试参与规则、证书发放条件与查询方式。
  2. 写法：二级标题 ## 认证事项；下设 ### 考试规则、### 证书获取与查询。
  3. 考试规则：设备 / 作答要求 / 禁止事项；以及考试后须完成的实名认证等条件与截止时间。
  4. 证书获取与查询：发放前置条件与预计时间、电子证书入口、有效期与公开查询。「考试通过」与「证书发放」是不同状态，先后关系须写清。「个人中心」「证书查询」保留 HTTPS 绝对链接。
  5. 缺省：无对应信息时省略子标题；勿写领券 / 购前运营话术与客套收尾。

发布前核验

  1. 能力边界：能力范围、认证成果与认证内容一致；「对应正式认证」口径正确（无 / 未明确 / 链接），勿与正式开发者认证混淆。
  2. 内容与时长：章节、学习目标与人读页一致；章节学习时长合计与概要学习时长相符，勿当作考试时长。
  3. 通过与出证：通过条件、实名时限、证书领取与有效期准确；环境准备有则写、无则省。
  4. 链接：HTTPS 绝对地址，直达正文（HTTP 200 ≠ 正文有效）。
  5. 一致与时效：与人读页名称、级别、内容一致；变更时更新 updated。
