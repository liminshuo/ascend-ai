正文首包可得

为了帮助 Agent 在禁用 JavaScript 时仍读到完整正文，页面须以静态 HTML 或服务端渲染（SSR）输出标题、段落、步骤、表格与代码；禁止无限滚动、虚拟滚动与关键文字懒加载。

适用对象

名称 说明
文档正文 标题、段落、步骤、警示、代码块，以及可入库的列表项与表格行，必须随首包 HTML 完整输出；深页内容须分页。严禁依赖客户端 JS 注入，或使用无限滚动 / 虚拟列表仅渲染视口行。

适用场景

优先级 页面类型 说明
必做 文档站正文页、手册 / 教程页 Agent 核心事实源，须保证首包完整可抓。
建议做 文档列表、官网规格 / 能力详情页 存在可引用正文/规格表时，须保证首包语义化输出。
可不做完整改造 纯交互工具台、无入库正文页 须在收录策略（如 robots.txt）中明确划界，严禁越界收录。

设计UI调整

调整建议

  • 首包可枚举 所有需入库的枚举内容（含列表、步骤、条目等）必须随首包默认可见，列表仅为常见形态之一；深页采用分页或一次性完整展示，严禁靠「向下滚动加载更多」等交互延迟注入关键项。

调整示例

首包可枚举，深页用分页

反面
MindSpore Transformers
大模型套件
CANN
异构计算架构
ATC 模型转换
工具

向下滚动加载更多

  • 常见疏漏：关键条目只在滚到底后才注入，机器无法在首包枚举结果。
正面
MindSpore Transformers
大模型套件
CANN
异构计算架构
ATC 模型转换
工具
123
  • 正确做法：首包默认可见若干条目；深页用分页，不靠无限滚注入。

文档内容调整

调整建议

本原则无独立文档内容改造。

前端调整

调整建议

  • SSR 完整输出主体 标题、正文、代码块、表格必须服务端渲染至首包 HTML；严禁依赖客户端 JS 注入主体（如空壳 #app 配 bundle）。
  • 严禁文字懒加载与虚拟滚动 正文、步骤、警示等文字严禁懒加载；长列表 / 长表严禁仅渲染视口行。图片可保留 loading="lazy"。
  • 无 JS 抓取校验 CI/CD 须以禁用 JS 的方式抓取页面，校验 H1、正文、代码块等关键节点完整存在，缺失即阻断发布。

调整示例

首包须含完整正文

反面 
<body>
  <div id="app"></div>
  <script src="/bundle.js"></script>
</body>
  • 常见疏漏：正文由 JS 注入，静态爬虫拿到空壳页。
正面 
<body>
  <h1>Ascend C 算子开发</h1>
  <p>本文介绍算子开发基本流程…</p>
  <pre><code>…</code></pre>
</body>
  • 正确做法：标题、正文、代码块均在首包 HTML，无需执行 JS。

关键文字禁止懒加载

反面 
<section data-lazy-load="steps"></section>
<script>fetchSteps().then(render)</script>
  • 常见疏漏：步骤、警示由 JS 异步注入，静态抓取为空。
正面 
<ol>
  <li>下载 CANN 安装包</li>
  <li>执行安装脚本</li>
</ol>
<div class="note">注意：需 root 权限</div>
  • 正确做法：步骤与警示随 HTML 直出；图片可保留懒加载。

长表禁止虚拟滚动

反面 
可见行：第 1–15 行
（共 200 行，其余未挂载 DOM）
  • 常见疏漏：虚拟滚动仅渲染视口行，爬虫拿不到完整表。
正面 
<table>
  <tr><th>name</th><th>shape</th>…</tr>
  <!-- 全部 200 行完整输出 -->
</table>
  • 正确做法：所有行节点存在于首包 HTML，行列关系可完整提取。
