页面 HTML 可读

解决什么问题

Agent 拿到 HTML，不等于读到正文：页面打不开、字靠 JS 后出现、事实在图或 iframe 里、页面太大被截断。任一处失败，就只能退回搜索摘要。平行 Markdown 见 双轨交付。

核心原则

打得开

匿名打开返回正文，不因浏览器标识或登录跳走。

首包就有字

关掉 JavaScript 仍能读到标题、正文、步骤、表格和代码。

字在主文档里

事实写在页面文字里，不藏在 iframe、画布或纯图片中。

字符集清楚、篇幅可控

写明字符集和语言；长文拆篇，避免中途截断。

示例 1 · 空壳 vs 首包正文

反面 
<body>
  <div id="app"></div>
  <script src="/bundle.js"></script>
</body>
  • 常见疏漏：正文由 JS 注入，静态抓取拿到空壳。
正面 
<body>
  <h1>Ascend C 算子开发</h1>
  <p>本文介绍算子开发基本流程…</p>
  <pre><code>…</code></pre>
</body>
  • 正确做法：标题、正文、代码块均在首包，无需执行 JS。

示例 2 · 深页用分页

反面

大模型套件

异构计算架构

向下滚动加载更多

  • 常见疏漏：后面条目要滚到底才注入，或只挂视口里那几行，首包枚举不全。
正面
MindSpore Transformers
大模型套件
CANN
异构计算架构
ATC 模型转换
工具
123
  • 正确做法：首包给出一批完整条目；更深的用可抓分页，不靠滚动才挂节点。

价值收益

  • 正文可被完整入库禁用 JS 也能读到标题、步骤与表格全部行，抽取结果与页面一致。
  • 抓取一次到位不必等渲染、滚动或点开，单次请求即可取全，漏抓与超时风险下降。
