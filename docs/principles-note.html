安全警示语义化

Note / 警告 / 危险等提示正文完整展开、用文字前缀标明类型，不靠折叠或图标承载语义。 读的懂 · 序号 10 · 对应 实测问题。

设计UI调整

调整建议

  • 警示正文默认展开：Note / 注意 / 警告须直接出现在稿面，禁仅靠折叠、tooltip、模态才能看到。
  • 类型用可见文字前缀：写「注意：」「警告：」「危险：」；图标只能辅助，不能当唯一标识。
  • 级别颜色统一：不同级别容器色全站一致；步骤内警示嵌在所属步骤旁，勿甩到列表外。

警告：…

两块同灰，级别看不出

文档内容调整

调整建议

  • 警示全文写进正文：禁「点开才看见」；关键注意点用引用块或加粗前缀直接写出。
  • 类型前缀固定用词：统一「注意 / 警告 / 危险」，禁只丢一个图标或「Tip」而无中文类型。
  • 步骤内警示写在该步下：归属清晰；勿把全章警告堆到文末。

前端调整

调整建议

  • 类型文字写入 DOM：「注意：」「警告：」须是真实文本节点，禁仅靠 ::before / 图标图。
  • 保持步骤嵌套：ol > li 内嵌警示，渲染勿扁平化到列表外。
  • 切片规则：警示 chunk = 类型前缀 + 正文（+ 所属步骤标题）；勿因折叠默认收起而跳过。

调整示例

示例1. 仅图标 → 文本前缀 + 语义容器

✗ 当前问题 · 无文字类型

<div class="note">
  ⚠ 升级前请备份…
</div>

✓ 推荐做法 · 可读前缀进 DOM

<div class="admonition admonition-warning">
  <span class="admonition-label">警告：</span>
  升级前请备份 /usr/local/Ascend。
</div>

类名可辅助；切片读「警告：」+ 正文即可。
