GEO BASELINE TEST REPORT · V1.1 · 2026-10-27

昇腾社区 GEO 基线测试报告

只汇报当前证据能定稿的指标：Sitemap 目录 · llms.txt 目录结构 · 三平台 × 24 题 AI 记录。测不出的不占表、不填猜测值。

01

维度 1 · Sitemap 结构质量

评估目的：Sitemap 是搜索引擎爬虫与 AI Agent 发现站点 URL 的入口。重复 URL、非预期 Host 及查询参数膨胀可能增加 URL 处理开销，影响内容发现与下游处理效率。本维仅评估 Sitemap 的静态结构与条目质量，不代表页面已被收录或能够正常访问。

77,430原始 URL 条目
76,753精确去重后 URL 数
677重复冗余条目
指标定义基线值描述
重复 URL 率
优先级·高
Sitemap 中精确重复 URL 条目数占原始 URL 条目总数（77,430）的比例，用于衡量 URL 条目的去重质量。重复率偏高可能增加下游处理开销；若下游已去重，实际影响有限。精确重复不代表页面内容重复。0.87%共检出 677 条重复冗余条目
非预期 Host 占比
优先级·高
Sitemap 中 Host 不在预期白名单内的 URL 数占原始 URL 条目总数的比例，用于核查域名配置的一致性。CDN、业务子域及跨站 Sitemap 等若已纳入白名单，不计为异常。占比偏高时，应优先核查白名单配置、域名迁移遗留及错误域名。1.00%共检出 776 条指向 15 个非预期 Host 的 URL
查询参数 URL 占比
优先级·中
Sitemap 中包含查询参数的 URL 数占原始 URL 条目总数的比例，用于识别筛选、追踪等参数可能造成的 URL 扩张。占比偏高时，应抽样核查参数用途，不直接判定为异常。2.83%共检出 2,190 条包含查询参数的 URL
lastmod 缺失率
优先级·中
Sitemap 中未提供 lastmod 字段的 URL 数占原始 URL 条目总数的比例，用于衡量更新时间元数据的完整性。该指标仅检查字段是否存在，不代表已提供的更新时间真实或准确。0.11%共检出 85 条缺少 lastmod 字段的 URL
特殊编码 URL 占比
优先级·辅助
Sitemap 中包含百分号编码（如 %20、%E4%B8%AD）的 URL 数占原始 URL 条目总数的比例，用于描述 URL 编码情况。合法编码不代表异常，本指标不纳入核心评分。1.48%共检出 1,145 条包含特殊编码的 URL，包括 %26 等编码形式
02

维度 2 · llms.txt 目录与 Markdown 资源可用性

评估目的：llms.txt 为 AI Agent 提供精选内容目录。需验证目录入口是否可访问、人读页与 Markdown 路径是否配对，以及声明的 Markdown 链接能否获取有效正文。目录配对 ≠ 链接可访问 ≠ 正文有效。

指标定义基线值描述
llms.txt 线上可访问性
优先级·高
检查站点根路径 /llms.txt 是否可通过 HTTP 获取，并返回可读取的目录文本，而非空响应或拦截页面。可访问GET 返回 HTTP 200，响应类型为 text/plain，文件约 12.1 MB，目录约 26,157 行
页面—MD 配对率
优先级·高
统计同时包含人读页 URL 与对应 llms-content/*.md 路径的目录记录占比，衡量目录层面的链接配对完整性。99.96%26,147 条具备配对链接，10 条仅含人读页 URL。不代表目标资源可访问或页面与 Markdown 正文内容一致
Markdown 链接线上可访问性
优先级·高
检查目录中的 llms-content/*.md 链接目标能否在线获取，并返回预期的 Markdown 资源，而非 WAF 拦截页或登录页。不可访问脚本请求未能获取可用的 Markdown 资源响应，返回内容多为 WAF/Cookie 页面。单纯 HTTP 200 不作为可访问的判定依据
Markdown 正文有效性
优先级·中
在成功获取目标资源的前提下，检查正文是否非空、可读取且符合预期的 Markdown 格式；本阶段不评估主题匹配等内容质量。与「Markdown 链接线上可访问性」区分：后者描述资源能否获取；本指标在尚无足够正文证据时记为「无法判定」，而非「不可访问」。无法判定当前未能获取真实 .md 正文，无法完成非空性、可读性及格式有效性检查。目录可读取 ≠ 链接可访问 ≠ 正文有效
03

维度 3 · AI 回答中的品牌可见度与引用质量

评估目的：基于 24 道测试题在三个 AI 平台上的回答，评估昇腾品牌提及、官方来源引用、引用内容对回答主张的支持程度及事实准确性。该维度直接衡量 AI 回答层面的实际表现，无法通过 Sitemap 或 llms.txt 的静态结构指标推算。

指标定义基线值描述
昇腾相关问题品牌提及率
优先级·高
在本轮 24 题 × 三平台（均为昇腾相关问题）的有效回答中，统计明确提及「昇腾」「Ascend」或「昇腾社区」的回答占比。同一回答无论提及多少次，均只计 1 次。该指标不等同于全问题域品牌曝光率，也不等同于来源引用率。100%72 / 72；Claude、DeepSeek、千问均为 100%
官方来源引用率
优先级·高
统计有效回答中明确引用或链接至昇腾社区官方页面的回答占比，用于衡量官方内容在回答中的引用情况，不等同于搜索引擎收录率。95.8%68 / 71（可判定 71 条）；Claude、DeepSeek 约 100%，千问约 87%
引用支持率
优先级·高
统计引用的来源页面能够支持回答中对应主张的比例。分母为完成支持性判定的引用主张数（非回答数/链接数）。主指标仅计入「支持」；「部分支持」「不支持」单独统计，不纳入主指标分子。10.1%7 / 69；部分支持 58 条（84.1%），不支持 4 条。有引用链接不代表引用内容能够支持对应主张
事实准确率
优先级·高
统计回答中经核验且判定为正确的事实项占可判定事实项总数的比例。无法判定的事实项单独记录，不纳入分母。73.8%48 / 65；另有 7 项无法判定，单独统计
关键问题覆盖率
优先级·中
统计已覆盖关键要点数 ÷ 全部预设关键要点数，用于衡量回答对问题核心信息的覆盖程度，不以回答长度代替内容完整度。86.7%约 242 / 279；Numbers 日期字段存在存储格式问题，已按 n/4 还原，建议抽查原始记录后定稿
