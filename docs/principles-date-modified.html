设计UI调整

调整建议

  • 新旧写成日期和版本：条目须标注可读的更新日期与版本号。角标可保留，但不得替代日期与版本文字。
  • 演进关系写成词：取代、兼容、适用版本须写成「已被 v8.0.0 取代」「兼容 8.0」等；版本号不能代替关系句。

  • 可免场景：页头已写明仅展示当前版本时，列表内可不重复日期。

调整建议

  • 正文与稿面文案须与设计示例一致：语义落在可抓取文字上，不依赖色、形或悬停。

前端调整

调整建议

  • 信息以 DOM 文本 / 语义属性交付；装饰图形 aria-hidden。
  • 切片管道抽取旁路文字，不依赖仅视觉编码。
