Part2. robots.txt 的优化建议

在保留现有 Sitemap 清单与搜索页 Disallow 的前提下，补齐显式 Allow，并声明已可访问的 llms.txt；同时将 sitemap 字段名规范为大写 Sitemap。

修改说明

  1. 新增 Allow: /：显式声明放行范围。
  2. 新增 LLMs.txt: 声明：指向已可访问的 https://developer.huawei.com/llms.txt。
  3. 规范 Sitemap 字段名：sitemap: → Sitemap:，URL 列表保持不变。
  4. 保留 Content-Signal：沿用 search / ai-input / ai-train=yes。
