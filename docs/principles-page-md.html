页级 Markdown

当用户在对话窗口里需要本页正文时，从渲染页拿内容容易带上导航和壳层噪声、丢失结构。 Agent 处理这一页时——不管是 Cursor 这类工具的单次调用，还是企业内部 RAG 的批量摄取——解析渲染 HTML 同样容易带噪声、难切块。

Agent 是如何取到页级 Markdown 的

Agent 取页级纯净正文有三条路径，按置信度从高到低排序：

通用发现层（主路径）

按行业通用约定，直接探测根目录或文档站子路径下的 llms.txt，从中 Fetch 该篇地址。这是跨站点通用的社区惯例，优先级最高。

站点私有发现层（需站点声明）

将当前页 URL 的 .html 改为 .md。前提：此规则属于站点私有约定，非通用知识，必须已在 llms.txt 或其他公开规范中明确声明，Agent 才会尝试。

内容层（兜底入口）

这是一个无需前置条件的确定路径。只要已抓到这篇 HTML，且无法通过上述路径获得平行稿，Agent 即可直接从页头「打开 Markdown」的真链跟到平行 .md。落点固定在 H1 同一行，必须写在 main 里。

核心原则

  • 主次分明与置信度遵循「先通用、后私有、再兜底」的阶梯。跨站通用的 llms.txt 拥有绝对优先权（主路径，见发现层部署）。站点私有的「URL 改写」规则，仅在公开声明（如写入 llms.txt）后才具备高置信度；若无声明，必须降级使用。页头「打开 Markdown」是无条件的内容层兜底。这三者不互为替代，而是按明确优先级递进。
  • 打开是真链「打开 Markdown」必须画在 H1 旁，且是 main 里的真实 <a>。rel="alternate" 和仓库源码链都不能单独替代这条链。

执行要点

  • 指向约定路径href 必须指向本页平行 .md 的绝对地址，并与 llms.txt 列出的该篇地址一致。未公开声明时，不要假设把 .html 换成 .md 即可到达。
  • 名称写在链上有文字位就写成「打开 Markdown」。只用图标时，在 <a> 上写 aria-label="打开 Markdown"（可兼 title），img 的 alt 留空。避免「更多」「AI」冒充打开。
  • 保持首包真实机器不点这条链，可跟的是源码里的真 href。必须落在首包 main 已有的 <a> 内，不要用 CSS background-image 画图标，不要悬停才插入 DOM。rel="alternate" 可并存，但不能代替这条可见链。

价值收益

  • 人能打开干净稿页头可见「打开 Markdown」，点开即是无导航噪声的平行 .md。
  • 未走通改写规则也能接住当 Agent 抓到了 HTML，且「URL 改写」规则未被声明，或其尝试无效时，main 里的真链仍能 100% 将其带到同一篇 .md，保证跨页检索不断裂。
