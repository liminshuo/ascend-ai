HTML 页面正文可读

概述

AI Agent 获取网页 HTML 后，需要能够直接从页面源码中读取标题、正文、步骤、表格和代码等核心知识内容。若关键信息依赖 JavaScript 渲染、隐藏在 iframe 或图片中，或页面内容过大导致截断，Agent 可能无法完整获取和理解页面内容。因此，应确保核心知识内容在 HTML 中可直接访问，并保持结构清晰、内容完整。

不是要求页面没有 JavaScript，而是要求 AI Agent 无需执行复杂交互，就能从 HTML 中直接获取核心知识内容。

具体原则

  1. 确保页面 HTML 可直接访问，避免依赖登录、强制跳转或其他前置条件才能获取核心内容。
  2. 在首屏 HTML 中直接提供页面标题、正文、步骤、表格和代码等核心知识内容，避免依赖 JavaScript 执行后才能生成。
  3. 将核心知识内容放在页面主文档中，避免隐藏在 iframe、Canvas 或图片等不可直接解析的载体中。
  4. 使用明确的字符集和合理的页面结构，控制页面内容规模，避免因字符编码错误或内容过长导致信息截断。

预期效果

  1. 帮助 AI Agent 直接从 HTML 中获取页面标题、正文、操作步骤、表格和代码等核心内容，减少因动态渲染或内容缺失造成的获取障碍。
  2. 提高页面内容的可理解性和可引用性，帮助 AI Agent 准确识别内容层级、理解信息关系并使用相关知识。

注意事项

  1. HTML 可读不等于禁止使用 JavaScript，重点是核心知识内容不应依赖 JavaScript 执行才能获取。
  2. 页面可以使用图片、Canvas 或 iframe，但标题、正文、步骤、参数等核心知识内容不应仅存在于这些载体中。
  3. 页面内容较多时应合理分页或拆分，避免单页内容过长导致抓取和解析成本过高。
  4. 对于需要交互才能展开的内容，应提供可直接访问的文本或独立页面入口，避免关键信息仅通过交互操作才能获取。
