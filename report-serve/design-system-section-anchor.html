锚点可引用

原则定义

锚点让页面中的特定段落或内容区块能够被单独定位和引用。用户可以找到锚点入口、复制链接，并在打开链接后准确识别对应内容。

类型

段落锚点 查看示例来源

整段被引用、从页内目录进入某一段落时使用。入口在段落标题右侧。以《编程模型概述》为例，标题旁的链接图标即段落锚点入口。

元素拆解

段落锚点 查看示例来源

顶部地址栏给出 URL 中的段落锚点（# 后的片段），正文标题旁是锚点符，右侧页内导航标出当前段落。四者同名，打开链接后落到这一段。以《编程模型概述》为例。

  1. 1URL 中的段落锚点　地址栏 # 后的「并行执行模型：SIMD与SIMT」，与该段标题同名，打开后落到这一段。
  2. 2段落名　正文标题「并行执行模型：SIMD与SIMT」，须与地址栏 # 后同名。
  3. 3锚点符　标题旁的链接图标，点击后把段落名写入 URL 的 #。
  4. 4页内导航　当前项与段落名同名，打开带 # 的地址后标出停在哪一段。

内容块锚点 查看示例来源

顶部地址栏给出 URL 中的内容块锚点（# 后的片段）；入口在内容块标题旁；不进页内导航。被引用的是图题、图与图注。

  1. 1URL 中的内容块锚点　地址栏 # 后的「图2 SIMD-Reg矢量计算内存层级」，与图题同名，打开后落到这一块。
  2. 2块名　内容块标题「图2 SIMD-Reg矢量计算内存层级」，须与地址栏 # 后同名。
  3. 3锚点符　块标题旁的链接图标，点击后把块名写入 URL 的 #。图与图注随图题一并被引用，不进页内导航。

交互规则

默认

链接图标始终可见，不靠悬停才出现；颜色与正文可区分，但不抢过标题。

悬停 / 聚焦

悬停时入口变为灰色圆角底；旁侧气泡提示「复制链接」。

如何使用

锚点可引用让页面中的特定段落或内容区块能够被单独定位和引用。用户可以找到锚点入口、复制链接，并在打开链接后准确识别对应内容。下面按三种用法说明。

复制段落或内容块链接

用户要分享某一段落或某一张表时，在标题右侧找到始终可见的链接图标。点击后复制含 # 的完整 URL，并用「已复制链接」确认成功。被引用的对象是这一段或这一块，而不是整页。

从目录或外链落到段落

用户从页内导航或他人分享的链接打开带 # 的地址。页面滚到对应段落，标题与地址栏 # 后同名；目标给出短暂落点高亮，页内导航标出当前项。打开链接后能够认出停在哪一段。

从图题或表题落到内容块

图、表、步骤块不进入页内导航。用户要单独转发其中一块时，点内容块标题旁的链接图标，复制带 # 的地址；粘贴打开后页面滚到图题（或表题），图与图注随图题一并露出。页内导航只列段落：点目录项落到对应段落标题，不会落到这张图。图下正文不计入引用范围。入口、复制与 URL 规则与段落锚点相同。
