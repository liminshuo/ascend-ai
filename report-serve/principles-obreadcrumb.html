面包屑路径可链回溯

文档页顶栏面包屑须把每一级祖先页写成可点的链接（a[href]），当前页用纯文本即可；首包 HTML 就要输出完整路径，文案与 sitemap / 手册目录保持一致。 找的到 · 社区 UI · 以 昇腾产品形态说明 为例 · 对应 问题实测 · 路径链断裂。

设计UI调整

调整建议

  • 每级路径用真实层级名：面包屑每一级写清真实层级名（文档中心 › CANN › 安装部署），别用「首页 › … › 当前页」这类泛词；祖先级为 a[href]、当前页纯文本。

调整示例

1. 面包屑：泛词 → 真实层级名

Before · 泛词路径

首页 › 详情 › 当前页

「首页 › 详情 › 当前页」看不出在站点结构的哪个位置，Agent 无法据此定位或回溯到祖先页。

After · 真实层级名 + 可跟链

文档中心 › CANN › 安装部署 › CANN 安装指南

要点：每级为真实层级名 + 可跟链，末级当前页纯文本；据此能回溯到任一祖先页。

文档内容调整

调整建议

  • llms 临时补路径链：面包屑 html 未达标前，llms 或 MD 页头可临时写出「昇腾常见问题 › 产品与技术常见问题 › 当前页」及各级链接；达标后以 SSR o-breadcrumb 为准，避免双轨不一致。
  • MD 页头写清层级：Markdown 版文档在 h1 上方用嵌套列表或一行路径链写出 ancestors，文案与 URL 须与 HTML 面包屑、sitemap 一致。

调整示例

1. 昇腾产品形态说明：title 链 vs MD 路径

Before · 路径只在 title/meta

【HTML】<title>昇腾产品形态说明-产品与技术常见问题-昇腾常见问题…</title>
【缺失】MD 页头无各级 ancestors 的可跟链

After · MD 页头平铺路径链

## 路径
- [昇腾常见问题](/document/detail/zh/AscendFAQ/…)
- [产品与技术常见问题](…)
- 昇腾产品形态说明（当前页）

# 昇腾产品形态说明
…

前端调整

调整建议

  • 首包 SSR 完整 o-breadcrumb：顶栏须输出与可见 UI 一致的全量 breadcrumb（对标友商：NVIDIA cuQuantum bd-breadcrumbs 首包 Home → cuDensityMat → Release Notes）；禁 JS 须仍能列出每一级 ancestors 的 href。
  • 祖先级须为 a[href]：每一级祖先输出带真实地址的 a[href]；当前页用 span 或纯文本。Ascend FAQ 实测：server-breadcrumb 仅 2 链、缺「昇腾常见问题 / 产品与技术常见问题」中间级。
  • 禁仅客户端补路径：路径节点不得只在 __NUXT_DATA__ 或前端脚本里才出现；须与 problems-obreadcrumb 探针判据互斥。
  • 文案与 sitemap 对齐：面包屑显示文案与 href 须与 sitemap、侧栏目录一致，禁 SSR 写「文档中心」而 UI 显示「昇腾常见问题」等错位。

调整示例

1. Ascend FAQ o-breadcrumb

Before · server-breadcrumb 仅 2 链

<div class="o-breadcrumb server-breadcrumb">
  <a href="/sitemap/sitemapdoc1.xml">文档中心</a>
  <a href="…/hardwaredesc_0001.html">昇腾产品形态说明</a>
</div>
<!-- 浏览器可见三级路径；中间级在 __NUXT_DATA__ -->

After · SSR 全量 ancestors 可链

<nav aria-label="Breadcrumb" class="o-breadcrumb">
