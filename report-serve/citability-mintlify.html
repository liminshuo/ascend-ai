Mintlify（md）分析 · 可引用性·内容（md）分析

引用后是否有价值：正文是否结论前置、事实原子化，以及是否值得维护平行 Markdown。 缺口归内容生产，与管道配置分开排期；营销口径默认不当知识源。

实施建议

  • 准入 MD 的标准（事实与结构层）：仅收录官方愿背书、可核对、可解析的稳定事实。包括知识正文（概述、步骤、布局）、课程序列与入口，以及可切分的结构化数据（如榜单行、总分与检查清单）。此类知识叶子页应同步配置页顶索引块，并统一写入 docs/llms.txt。
  • 排除 MD 的标准（壳、转化与说服层）：凡是用于交互、转化或情感打动的内容，应绝对锁定于人读 HTML。包括顶栏、搜索等站壳；试用 Demo 等 CTA 引导；首屏主张、领袖寄语、趋势曲线与实时统计，以及 Cookie 浮窗——这些内容旨在驱动操作或传递情绪，不构成可背书的稳定知识。
  • 楼层切片逻辑：整页内容需按人类阅读与 Agent 提取进行物理剥离。人类视角可铺开五层叙事，但 Agent 通常只取其中唯一可解析的事实楼层。
  • 有 MD ≠ 进目录：是否推入 Agent 目录，最终取决于策展闸门的判定。例如定价页虽可独立生成 pricing.md，但因报价具有强时效性，仍应明确排除在 llms.txt 之外，不可因其技术可产出便默认赋予引用资格。对照见下方案例；可达性侧见 Mintlify 分析。
