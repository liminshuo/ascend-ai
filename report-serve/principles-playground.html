在线尝试入口可继续执行

为了帮助 Agent 不止步于静态代码块，可运行示例旁须提供明确的「在线尝试 / 在 Playground 打开」入口，使控件可选、执行可继续。可照抄静态示例见 示例路径可照抄参照。

适用对象

名称 说明 常见落点
在线尝试入口 代码示例旁固定「在线尝试」「在 Playground 打开」等文案与位置，全站一致。 可运行代码块旁
嵌入式 Playground 嵌入运行区须有尺寸与间距规范，不打断阅读流；无 JS 时降级为静态示例。 教程内嵌运行区
本地复现兜底 无法提供在线环境时，写明本地复现命令与验证方式，仍可继续执行。 示例说明区

适用场景

优先级 页面类型 说明
必做 有官方 Playground / 在线 IDE 的 API、SDK 示例页 Agent 需可选入口继续跑；仅静态块会中断任务。
建议做 快速入门、可运行样例教程 有条件时挂在线尝试；否则写清本地复现。
可不做完整改造 无运行环境的概念说明、纯配置片段 提供可照抄静态示例即可，不必强求 Playground。

设计UI调整

调整建议

  • 入口文案与位置固定 代码示例旁固定「在线尝试」按钮文案与位置，全站一致，便于 Agent 识别控件。
  • 嵌入区不打断阅读流 嵌入式 Playground 须有尺寸与间距规范；静态代码正文始终可见，不被运行区遮挡。

文档内容调整

调整建议

  • 写清输入、动作与预期输出 示例说明与正文步骤一致：输入什么、点哪里、预期看到什么。
  • 无在线环境时写本地复现 无法提供 Playground 时，写明本地复现命令与验证方式，避免任务中断。

  无本地复现说明

**预期输出**：`hello ascend`

无在线环境时：本地执行

  • 正确做法：写清在线入口或本地命令，并给出预期输出。

前端调整

调整建议

  • 代码块可配 Playground URL 组件可配置跳转 URL；尽量预填示例代码，落地即可跑。
  • 嵌入组件 SSR 降级 禁 JS 时降级为静态代码；首包仍保留完整示例正文与入口链接文案。
