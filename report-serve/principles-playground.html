在线尝试入口可继续执行

解决什么问题

抓取型 Agent 吃不到「点 Run」之后的结果，要的是正文里的完整源码，以及能打开当前这段代码的 Playground 链接。可照抄静态示例见 操作可按序照抄。

核心原则

源码可入库，链接带走当前代码

正文须有完整源码。Playground 链接应打开当前这段示例（URL 里带上代码，如 #code=），不要只链到空白运行首页。模板挑选可以是进编辑器的前一步。尽量免登录；若有登录墙，不要让它挡住正文源码。本页点 Run 对抓取型 Agent 意义有限。

典型示例

文档内代码块可运行

源码写在正文里，块上可执行、本页出结果，并提供能打开当前这段代码的 Playground 链接。
