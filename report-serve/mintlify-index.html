Mintlify · 找的到（收录索引）

收录怎么分面、谁进 llms、谁只停在 Sitemap——Mintlify 用「精准克制」给出可对照样本。

分析总结

  • 只认知识面，不认全站。深度亲和锁在 /docs（及学习站）：llms 收录 + Markdown 可读。营销、博客、生态、招聘等导航能点到，也不进 Agent 目录。
  • 叙事与事实分层。基线亲和 = Sitemap 可发现 + HTML 可读，服务 SEO / 转化；只有官方愿背书的规格与操作，才升到深度亲和。
  • 产出跟发布走，策展标准前置。MDX 发布即可同步 llms.txt 与平行 MD——先定「什么配进文档库」，再谈管道，而不是事后全站补亲和。
  • 目标是可溯源，不是页数。相对 NVIDIA「处处可达」，Mintlify 收窄语料边界；缺口（如 changelog 未进 Sitemap / llms）应补收录，不等于放开全站。
