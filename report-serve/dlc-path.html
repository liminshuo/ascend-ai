# Ascend C编程

> Ascend C 是以标准 C/C++ 为基础扩展，开发高性能算子。本路径是 Ascend C 算子开发的系列教程，涵盖 Ascend C 算子开发、算子调用、算子性能分析与优化等全流程。

## 路径概要
- 适用对象：算子开发者；希望掌握 Ascend C 自定义算子开发与调优的 AI 算法 / C++ 工程师
- 学习目标：掌握 Ascend C 自定义算子开发、调用及性能优化的基本方法
- 能力等级：入门至进阶
- 预计总时长：2 小时（120 分钟）
- 关联产品：CANN · Ascend C
- 资源构成：5 门课程 · 2 个实操 · 1 个教程 · 1 个案例 · 1 个微认证
- 环境要求：Atlas A2 / A3 训练或推理系列；CANN 9.0.0 及以上；实操需 NPU 或仿真环境

## 预备知识

### 必备基础
- C/C++ 基础

### 推荐学习
- [Ascend C基本概念](https://www.hiascend.com/document/redirect/CannCommunityAscendCbase)

## 知识点
- Ascend C 算子开发（自定义算子、Kernel 开发）
- 算子调用（自定义算子调用）
- 算子性能分析与优化（算子调优）

## 学习阶段

### 阶段 1 · 昇腾异构编程基础课程（速成班）
- 学习属性：推荐前置
- 学习目标：深入了解昇腾 AI 处理器架构，建立异构编程基础
- 学习产出：能说明 AI Core 与 CANN 的基本分层关系
- 学习资源：
  - 课程：[昇腾异构编程基础（速成班）](https://www.hiascend.com/developer/courses/detail/1925466587412258817)

### 阶段 2 · Ascend C算子开发（入门）
- 学习属性：必修
- 学习目标：掌握 Ascend C 算子开发初级能力，完成课程讲解与样例实操
- 学习产出：能编写并运行入门级 Ascend C 核函数
- 学习资源：
  - 课程：[Ascend C算子开发（入门）](https://www.hiascend.com/developer/courses/detail/1691696509765107713)
  - 实操：[Ascend C 算子开发系列（Kernel 直调版）](https://gitcode.com/cann/cann-learning-hub/blob/master/tutorials/ascendc_operator_development_light/README.md)

### 阶段 3 · Ascend C算子开发（进阶）
- 学习属性：必修
- 学习目标：学会使用 Ascend C 进行自定义算子开发，并掌握自定义算子调用
- 学习产出：能完成自定义算子的开发与框架侧调用
- 学习资源：
  - 课程：[Ascend C算子开发（进阶）](https://www.hiascend.com/developer/courses/detail/1696414606799486977)

### 阶段 4 · Ascend C算子开发（高级）
- 学习属性：必修
- 学习目标：使用 Ascend C 完成复杂算子开发，并掌握性能优化方法
- 学习产出：能使用相关工具开展算子性能分析与基础调优
- 学习资源：
  - 课程：[Ascend C算子开发（高级）](https://www.hiascend.com/developer/courses/detail/1696690858236694530)
  - 实操：[Ascend C 算子开发系列（工程版）](https://gitcode.com/cann/cann-learning-hub/blob/master/tutorials/ascendc_operator_development/README.md)

### 阶段 5 · Ascend C Skills 系列课程
- 学习属性：选修
- 学习目标：理解 Ascend C Skills 工具链设计理念与使用方法，建立从语言特性到全流程实践的工作流
- 学习产出：能使用 Skills 工具链完成 Add 样例工作流
- 学习资源：
  - 课程：[Ascend C Skills 全景概览](https://www.hiascend.com/developer/courses/detail/2056647289996673026)
  - 教程：[Ascend C Skills 系列课程第二弹 - 算子开发](https://www.hiascend.com/developer/blog/details/02192216367561559004)
  - 案例：[Ascend C Skills 系列课程实验手册：Add](https://www.hiascend.com/developer/blog/details/02189216358512201004)
