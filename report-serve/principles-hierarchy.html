标题层级可识别

为了帮助 Agent 识别章节关系与阅读顺序，标题层级须反映信息结构；禁止跳级或纯样式伪标题。

适用对象

名称 说明 常见落点
标题从属 方式一：用 H1–H6 标题级别表达从属关系，字号与缩进不替代层级结构。 安装文档、排障手册
方式二：用 1/1.1 编号表达从属关系，与标题级别二选一，避免叠用。 规范条款、手册章节
标题并列 同级主题须用同级标题表达；分割线、卡片或加大字号不等同于标题结构。 能力模块页、入口专区

适用场景

优先级 页面类型 说明
必做 文档站正文页、手册 / 教程 Agent 最常按标题树切片与引用的事实页。
建议做 官网能力说明、产品详情 多模块并列进引用池时，须有可识别同级结构。
可不做完整改造 纯营销落地页短文 无多级章节树时，可只保证页内 H1 唯一。

设计UI调整

调整建议

  • 层级可辨 机器须能识别文档的层级与从属关系；结构须落在标题级别或编号上，不能只靠排版。
  • 同级用同级标题 并列主题用同级标题表达；分割线、卡片、加大字号不能代替标题结构。

文档内容调整

调整建议

  • 标题可独立成目录项 标题概括本节主题，可独立成目录项；勿用「如下」「继续」等无信息词作唯一标题。
  • 稳定小节名 步骤、注意、验证等用稳定小节名，与侧栏 / 目录用语一致。

前端调整

调整建议

  • 使用真实标题标签 输出真实 h1–h6；Lint 拦截跳级、空标题与用 div / 加粗冒充标题。
  • 目录与 DOM 一致 页内目录根据标题 id 生成，与首包 DOM 层级一致。
