表格结构可读

概述

表格是网页表达规格、能力、场景和对照关系的重要载体，但视觉上清晰的表格不一定能被 AI Agent 准确还原行列关系和单元格含义。

表格语义可结构化原则旨在明确表头、行列归属、单元格内容及合并关系，使表格信息能够被 AI Agent 准确读取、理解、查询和引用。

具体原则

  1. 表格应有明确的标题和表头，清晰表达主题及字段含义。
  2. 表头与数据应有明确的对应关系。HTML 表格应合理使用 th、scope、rowspan 和 colspan 等结构；Markdown 表格应确保列名清晰、行内容完整。
  3. 单元格内容应完整、清晰，避免将多个字段或条件混在一起；复杂内容可通过列表或补充说明呈现。
  4. 状态、适用范围和规格参数应使用明确的文本、数值及必要单位，避免仅依赖符号、颜色或空白表达含义。
  5. 表格与正文及其他格式的同源内容应保持一致，数据或规则更新时同步维护。

典型示例

表格结构可还原

合并单元格可能导致行列归属在内容切片或格式转换后丢失。应使用明确的表头和合并结构表达归属关系，并确保转换后的每行数据仍能识别所属场景、模型和能力项。

参数字段应明确对应

对于输入输出参数，应分别标注参数方向、名称、数据类型、形状和格式等字段，避免将多个属性混在同一列，或因表格转换导致字段与数值错位。

格内状态应写成明确文本

能力矩阵中的支持状态应使用「支持」「不支持」「待支持」等明确文本表达，勾叉等符号可作为辅助。对于因合并单元格产生的空白，应确保其含义明确，避免被误解为不支持、缺失数据或未知状态。

预期效果

  1. 帮助 AI Agent 准确识别表格标题、表头、行列关系和单元格含义，减少因结构还原错误造成的信息错配。
  2. 提高规格参数、能力对照和适用条件等信息的可查询性、可比较性和可引用性。
  3. 降低因合并单元格、状态符号或字段含义不明确造成的理解偏差，提高表格信息的可用性。

注意事项

  1. 表格适用于呈现具有明确行列关系的数据和对照信息，不宜将大段正文直接放入表格。
  2. 对于多级表头、合并单元格或复杂表格，应确保表头与数据的归属关系明确；必要时拆分为多个简单表格，或补充文字说明。
  3. 对于 Markdown 无法清晰表达的复杂行列关系，可使用结构规范的 HTML 表格，或提供完整、易读的文本替代内容。
  4. 不要依赖空白、颜色或单一符号表达关键含义；状态应使用明确文本，数值应补充必要的单位和统计口径。
  5. 表格、正文说明和其他格式的同源内容应保持一致，更新时同步维护，避免数据冲突或信息过时。
