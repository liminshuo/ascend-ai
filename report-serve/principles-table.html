表格语义化

用 caption、th、scope 与合法合并表达标题与行列归属；格内嵌套列表独立成结构。状态词写法见 状态完整标注。 可读 · 对应 问题论证 · 表格的结构语义。

对象

对象 描述
表头与标题 每表有描述性 caption；列/行名用 th + scope。常见落点：规格表、参数表。
合并与多级表头 colspan / rowspan 后每格仍能还原「行名×列名」；禁止只靠底色或框线表达分组。常见落点：分组规格表、兼容矩阵。
嵌套内容 格内接口 / 要点列表用真实列表，不拆成伪数据行。常见落点：I/O 规格、能力说明格。

设计UI调整

调整建议

  • 表格标题文案交付：每表同步提供 caption，格式如「表1 Ascend C Add 算子设计规格」，禁「表格1」「数据表」。
  • 表头作用域标明：交付标注哪些是 th、哪些是 td，以及 scope 方向（col / row）。
  • 合并须可还原归属：合并单元格时标明跨行/跨列范围；分组不得只靠底色。若格内是状态词，写法遵循 状态完整标注。
  • 嵌套列表独立：接口列表区域标为独立列表，不拆成伪数据行。

文档内容调整

调整建议

  • caption 与列名写全：稿面与 Markdown 表均有描述性标题；列名稳定、可当字段名。
  • 合并在文稿可还原：Markdown 无 rowspan 时，优先拆行写全场景名，或注明「以下两行同属预训练」；勿留空首列指望读者脑补。
  • 状态词另遵状态页：格内支持/不支持等词义见 状态完整标注，本页不重复符号替换细则。

前端调整

调整建议

  • 完整语义结构：caption、thead/th+scope、tbody；禁止用样式 td 冒充表头。
  • 合并可切片：rowspan/colspan 后管道须能展开为「列名:值」且带上合并行头；空首列不得入库为独立行。
  • 嵌套列表同 chunk：格内 ul 与所属表绑定，不拆散。

调整示例

合并行头 HTML

Before

<tr><td>预训练</td><td>V3</td>…</tr>
<tr><td></td><td>Janus</td>…</tr>

空单元格，归属靠视觉。

After

<tr>
  <th scope="row" rowspan="2">预训练</th>
  <td>V3</td>…
</tr>
<tr><td>Janus</td>…</tr>

行头合并，切片可还原场景。
