颜色语义转写

颜色只辅助，级别与类别须写成文字（警告 / 注意 / 提示、成功 / 失败等），禁止仅以色块表意。 可读 · 设计专项见 颜色语义转写。

对象

类型 说明 常见落点
警示色 警示级别须写成「警告」「注意」「提示」等词，禁止仅以颜色区分。 文档告警条
禁用色 不可用须写成「已禁用」等词，禁止仅以灰色表达。 禁用操作
图例色 分类须写成文字图例，禁止仅以色块区分。 图表图例

设计UI调整

调整建议

  • 颜色不独自表意：状态、禁用、图例等含义须配文字，颜色可保留但不得作唯一载体。

调整示例

用级别词表达警示色

反面

请勿在生产环境使用未验证驱动。

更换驱动前请备份配置。

安装完成后请重启设备。

  • 常见疏漏：仅以色块区分级别，未配「警告 / 注意 / 提示」等文字。机器无法识别警示等级。
正面

警告：请勿在生产环境使用未验证驱动。

注意：更换驱动前请备份配置。

提示：安装完成后请重启设备。

  • 正确做法：级别写成「警告：」「注意：」「提示：」；颜色只辅助。

文档内容调整

  • 统一「警告：」「注意：」「提示：」等前缀写法。
  • 表格与图例中的含义用词，不用「红/绿」指代。

前端调整

  • 前缀写入 DOM 文本节点；可加 data-admonition-type。
  • 勿用 CSS ::before 单独生成唯一级别词。
