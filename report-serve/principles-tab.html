Tab 全量展开

若使用 Tab，须同时提供全量展开版本或首包输出全部面板，确保非激活面板正文也能被抓取。折叠见 折叠默认展开。 可读 · 对应 问题论证 · 隐藏语义（Tab）。

设计UI调整

调整建议

  • 提供全量入口：须提供「展开全部」或页内各 Tab 垂直排列的备用布局，不能仅依赖点击切换。
  • 优先平铺：安装路径等关键内容优先用标题分节，少用仅交互可见的 Tab。

文档内容调整

调整建议

  • Tab 全量可见：必须用 Tab 时，须提供无需点击即可访问全部面板内容的方法。
  • 可改用标题：多路径安装等可用 H2/H3 平铺，替代仅 Tab 切换。

### 在线安装（x86_64 · CANN 9.0.0）

```bash
wget … ./Ascend-cann-toolkit_9.0.0_linux-x86_64.run
./Ascend-cann-toolkit_9.0.0_linux-x86_64.run --install
```

### 离线安装（x86_64 · CANN 9.0.0）

```bash
./Ascend-cann-toolkit_9.0.0_linux-x86_64.run --install --offline
```

前端调整

调整建议

  • 面板首包全量：所有 Tab 面板在 SSR 首屏 HTML 中完整输出，不依赖 JS 注入非激活面板。
  • 禁止 display:none 藏正文：非激活面板勿用 display:none / visibility:hidden 去掉可读节点。
