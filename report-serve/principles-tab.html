Tab 面板可全量抓取

为了帮助 Agent 抓取非激活面板中的步骤与命令，若使用 Tab，须首包输出全部面板正文，或提供「展开全部」后改为垂直平铺 / 页内平铺备用布局（Tab 无法同时展开全部面板）。折叠见 折叠正文默认可抓取。

适用对象

名称 说明
Tab 面板 承载路径 / 版本 / 系统切换的正文面板；非激活内容必须全量输出至 DOM 或经 SSR 完整呈现。严禁仅渲染激活态，导致漏抓关键信息。

适用场景

优先级 页面类型 说明
必做 文档站安装 / 编译多路径页 路径 / 命令常分 Tab，必须全量输出至 DOM，严禁只渲染激活态。
建议做 官网产品能力多 Tab 说明 规格 / 能力若需进引用池，各面板必须全量可抓取。

设计UI调整

调整建议

  • 关键路径尽量不用 Tab 安装 / 版本等多路径关键内容优先用标题分节平铺；少用 Tab 切换作为唯一呈现方式，避免非当前路径「点开才看见」。

调整示例

关键路径尽量不用 Tab 表达

反面
在线安装 离线安装 Docker

wget … && ./toolkit.run --install

  • 常见疏漏：非激活 Tab 不可见；Agent 只能抓到一个面板。
正面

在线安装

wget … && ./toolkit.run --install

离线安装

./toolkit.run --install --offline

Docker

docker pull … && docker run …

  • 正确做法：「展开全部」后改为垂直平铺，各路径静态可见；勿与横向 Tab 条并存。

文档内容调整

调整建议

  • 稿面须能读到全路径 必须用 Tab 时，平行 MD / 页内须有无需点击即可访问的全部面板文案。
  • 可改用标题平铺 多路径安装等优先用 H2 / H3 分节，替代仅靠 Tab 切换才见步骤。

调整示例

用标题平铺替代仅 Tab

反面 
<!-- 在线安装 Tab（激活） -->
在线安装步骤：wget … ./toolkit.run --install

<!-- 离线安装 Tab（隐藏） -->

← 非激活面板无正文
  • 常见疏漏：稿面只留激活路径，离线 / Docker 步骤丢失。
正面 
### 在线安装（x86_64 · CANN 9.0.0）

```bash
wget … ./Ascend-cann-toolkit_….run
./Ascend-cann-toolkit_….run --install
```

### 离线安装（x86_64 · CANN 9.0.0）

```bash
./Ascend-cann-toolkit_….run --install --offline
```
  • 正确做法：各路径用标题平铺，全文静态可读。

前端调整

调整建议

  • 面板首包全量输出 各路径步骤与命令须随首包 HTML 完整输出，不点 Tab 也能被抓取；严禁依赖 JS 注入非激活面板，或把非当前 Tab 当作「点开才存在」的唯一出处。
  • 禁止用 display:none 藏正文 非激活面板勿用 display:none / visibility:hidden 去掉可读节点；可用视觉层叠且保留 DOM 文本。

调整示例

首包须含全部面板文本

反面 
<div class="tab-panel">在线安装…</div>
<div class="tab-panel hidden">
  离线安装步骤…
</div>

← hidden / display:none 从可读流消失
  • 常见疏漏：非激活面板从抓取流中消失。
正面 
<div class="tab-panel" data-active="true">
  在线安装…
</div>
<div class="tab-panel">离线安装…</div>
<div class="tab-panel">Docker…</div>

← 首包含全部面板文本节点
  • 正确做法：首包输出全部面板；激活态只影响样式，不删节点。
