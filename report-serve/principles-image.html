图片内容可转译

概述

图片是网页传递信息的重要载体，但其承载的信息与网页文本不同，不能始终被 AI Agent 完整、准确地获取和理解。

图片内容可转译原则旨在降低图片信息的理解障碍，使图片所表达的关键内容、语义关系和知识结论能够被 AI Agent 有效获取和使用。

具体原则

  1. 将图片中的关键文案、技术参数、操作步骤和重要数据写成可直接读取的 HTML 文本，避免关键信息只存在于图片中。
  2. 对于流程图、架构图、关系图和数据图表，通过正文、列表或表格说明关键节点、层级关系、数据含义、处理流程及主要结论。
  3. 根据图片的内容和用途提供准确的 alt 文本，描述图片主要内容或功能；纯装饰性图片使用空 alt（alt=""），避免引入无意义信息。
  4. 保持图片、替代文本、图注和正文语义一致。图片内容发生变化时，同步检查并更新相关文字，避免遗漏、不准确或相互矛盾。

预期效果

  1. 帮助 AI Agent 通过 HTML 文本、图注或平行 Markdown 获取图片中的关键文案、技术参数、结构关系和主要结论。
  2. 减少仅依赖 OCR 或多模态识别带来的不确定性，使回答能够回查到可检索、可引用的文字证据。

注意事项

  1. 装饰图、氛围图不承载事实时，不需要硬写图意转写，可使用空 alt（alt=""）。
  2. alt 用于简述图片主要内容或功能，不宜只重复图题；复杂结构和完整结论应写在图注、正文或平行 Markdown 中。
  3. 图片、替代文本、图注、正文和平行 Markdown 应保持语义一致，图片内容变化时同步检查并更新相关文字。
  4. 图片使用可抓取地址有助于多模态 Agent 取图，但不能替代关键内容的文本转写。
