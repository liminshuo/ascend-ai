图片图意可转译

为了帮助 Agent 检索图中的结构与结论，信息型图片须转写为可检索正文（独立文案层、alt、figcaption、内容转写或 Mermaid），禁止图意只存在于像素里。

适用对象

名称 说明 常见落点
官网·展示图 关键文案（标题、入口、角标）须为独立文字层，禁止烧入图片。图仅作背景，信息须有可抓文字。 活动 Banner、首页招揽
官网·架构图 层名与产品关系须以文字链接或旁注徽标（Markdown）交付，禁止仅以图片承载。 平台栈、官网结构图
文档·架构图 流程与调度结论须以图题和图注交付，禁止仅以图片标注承载。 架构示意、调度图
文档·截图 截图中原文与结论须以正文 / 图注交付，截图仅作对照。 训练日志、报错页

适用场景

优先级 页面类型 说明
必做 文档站架构图 / 截图页 图意常承载步骤与结论，须可检索转写。
建议做 官网 Banner、平台栈展示 标题与入口若进引用池，须独立文字层或平行 MD。
可不做完整改造 纯装饰图、氛围底图 不承载信息时可用空 alt / CSS 背景，勿硬写转写。

设计UI调整

调整建议

  • 信息不烧图 标题与入口文案须独立于图片，禁止烧入图中；图可作背景，信息须有可抓文字层。
  • 图意成文 结构、结论与报错须以图注、旁注或正文交付；每张信息图下方预留 figcaption / 转写位。
  • 图表优先可机读格式 流程图、时序图、架构图优先交付 Mermaid 源码；表达不了时提供可提取文本的 SVG。

文档内容调整

调整建议

  • 替代文本非空 每张信息图须提供非空 alt，简洁描述图意与功能；纯装饰图用空 alt="" 或 CSS 背景。
  • 禁止「见上图 / 下图」 正文引用须复述图中关键信息，禁止仅靠视觉位置指代。
  • 复杂图须内容转写 含复杂逻辑的图表，须在图下提供内容转写段落；流程图 / 架构图优先 Mermaid 等可机读格式。

前端调整

调整建议

  • figure + figcaption 语义结构 每张信息图用 <figure> + <figcaption> 包裹；<img> 填非空 alt；每图唯一 id 作锚点。首包即含图注文字。
  • Mermaid / SVG 可提取 支持嵌入 Mermaid 并渲染；SVG 优先内联以便提取文本，避免仅用不可读的 PNG 承载结构。
  • Chunk 拼接图意 切片时将 alt + figcaption + 前后正文拼为连续文本块入库；装饰图（空 alt / aria-hidden）跳过。
