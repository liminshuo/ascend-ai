缺省空态可文案处理

为了帮助 Agent 确认默认配置、理解为何为空并继续处理，缺省项须写成「默认 …」，空结果须说明缺失内容与下一步；禁止仅靠选项值、空白或「-」表意。

适用对象

名称 说明 常见落点
缺省配置 已选推荐项须写成「默认 …」（如「默认 8.0.0」），禁止仅以选项值本身表达推荐。 版本下拉、参数默认项
空状态 空列表与空结果须说明缺失内容与下一步，禁止仅以空白或「-」代替。 筛选无结果、空列表
空态原因区分 区分「无数据」「无权限」「筛选过空」等原因，文案与可执行下一步对应。 结果区、权限拒绝页

适用场景

优先级 页面类型 说明
必做 下载筛选、参数表单、列表检索结果 默认值与空结果最易无文案；Agent 需确认并改条件。
建议做 控制台空列表、文档站筛选页 写清空因与下一步，避免任务停在空白区。
可不做完整改造 加载中占位、短暂骨架屏 加载态可短提示；落定后的空态仍须文案。

设计UI调整

调整建议

  • 缺省可识别 推荐值须标注「默认」，禁止只露选项值；机器须能识别推荐版本并回答默认配置。
  • 空态可行动 空结果须写明缺失内容与可执行下一步，空白与「-」不得单独表意。

设计专项完整说明见 缺省空态文案化。

文档内容调整

调整建议

  • 区分空因并给下一步 区分「无数据」「无权限」「筛选过空」；给出可执行下一步；成功态与空态文案勿混用。
  • 默认值写成字 稿面与表单说明中，推荐配置写成「默认 …」，禁止只写裸版本号暗示推荐。

调整示例

空态说明缺失内容与改法

反面 
筛选结果：-

← 无原因 / 无下一步
  • 常见疏漏：仅「-」或空白，Agent 无法确认空因与如何改。
正面 
筛选结果：暂无匹配的软件包。
请更换芯片型号或版本后再筛选。

默认软件版本：默认 8.0.0

← 空因 + 下一步 + 缺省
  • 正确做法：写清空因与可执行改法；缺省项带「默认」。

前端调整

调整建议

  • 空态节点首包输出 空态文案在首包 / SSR 输出；原因可进 data-empty-reason；勿仅转圈无文案。
  • 默认项写入可见文本 选中推荐项的可见文本含「默认」；可用 data-default="true" 辅助机读。

调整示例

空态与默认值可机读

反面 
<select>
  <option selected>8.0.0</option>
</select>
<div class="spinner"></div>

← 无「默认」/ 无空态文
  • 常见疏漏：默认无字、空态只转圈，切片拿不到可处理信息。
正面 
<option selected data-default="true">
  默认 8.0.0
</option>
<p data-empty-reason="no-match">
  暂无匹配的软件包。请更换
  芯片型号或版本后再筛选。
</p>

← 可确认 / 可继续
  • 正确做法：默认与空态均为可见文本；原因可进 data-*
