AI入口可识别

在渲染页上标出机器可读入口（站级 llms、页级 / 块级 Markdown 等），文案可发现、可命名；禁止只靠无字图标或悬停才出现。

场景定义

类型 说明 常见落点
站级入口 站级机器可读清单（如 llms.txt）须在页脚等次要区用可读文案标出，便于人与审计跟链。 全站页脚
页级MD入口 文档页头须有「复制 / 打开本页 Markdown」等可辨入口；仓库源码链不能单独替代。 文档页头工具区
内容块MD入口 强视觉架构图旁挂 MD 徽标，平行 MD 写清层级与依赖；本页保留视觉与产品真链。 平台栈、结构楼层
首包无完整 HTML 表时，须提供平行 MD「规格项 | 数值」表，标题旁挂 MD 徽标作入口。 产品规格表

设计UI调整

调整建议

  • 入口文案自描述 站级 / 页级 / 内容块入口位置固定；使用「复制 Markdown」「打开机器可读版本」「llms.txt」等可独立理解的短语，禁止仅用泛化图标。
  • 下拉写出动作名 若入口在菜单内，每一项须写出动作名；禁止悬停后才出现关键文案。

文档内容调整

调整建议

  • 与发现路径同名 入口文案须与 llms.txt / source 路径语义一致，避免「更多」「AI」等空泛词。
  • 多模型写清动作 若提供多模型入口，列出具体模型或动作，勿只写「聊天」。

前端调整

调整建议

  • 可抓链接或可见文本控件 入口须为 <a href> 或带可见文本的 button；勿悬停才注入 DOM。
  • 与 alternate 联动 页头可输出 link rel="alternate" type="text/markdown"，与页级入口目标一致。
