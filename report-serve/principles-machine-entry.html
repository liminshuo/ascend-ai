AI入口可识别

机器可读入口（复制 Markdown、打开源文件、与模型对话等）须在稿面可发现、可命名，禁止只靠无字图标或悬停才出现。 可达 · 设计专项见 AI入口可识别。

设计 UI 调整

  • 站级 / 页级 / 内容块入口位置固定，文案自描述（如「复制 Markdown」「打开机器可读版本」）。
  • 禁止仅用泛化图标代替文字；下拉项每项写出动作名。

文档内容调整

  • 入口文案与 llms.txt / source 路径语义一致，避免「更多」「AI」等空泛词。
  • 若提供多模型入口，列出具体模型或动作，勿只写「聊天」。

前端调整

  • 入口须为可抓链接或带可见文本的按钮；勿悬停才注入 DOM。
  • 页头可输出 link rel="alternate" type="text/markdown" 与入口呼应。
