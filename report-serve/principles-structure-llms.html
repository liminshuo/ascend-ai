发现层部署

站点层必须部署机器发现层标准四件套（robots.txt、sitemap.xml、llms.txt、llms-full.txt），放行可索引路径与机器源（source）路径，并显式声明抓取 URL 与主推版本，以确保机器能稳定发现并进入。

部署对象

名称 说明
robots.txt 站点爬取规则：
声明允许 / 禁止路径，并指向 Sitemap。必须放行可索引页与机器源（MD / source）路径；严禁误挡 Agent 与合规爬虫。
sitemap.xml 站点 URL 清单：
列出应索引页面及更新时间。必须覆盖权威文档页，并优先收录机器源路径，便于 Agent 定位。
llms.txt 面向大模型的站级索引：
按产品线 / 版本列出推荐抓取入口。必须声明主推版本，且篇名与目标页 H1 / 侧栏用语保持一致。
llms-full.txt 面向大模型的全文聚合包：
将索引文档的 Markdown 正文聚合为单文件。必须随文档发布自动生成，并与 llms.txt 入口保持同源更新。

适用场景

优先级 站点类型 要部署哪些
必做 知识面：文档站 / 手册 / 知识中心 必须部署全套四件套：robots.txt + sitemap.xml + llms.txt + llms-full.txt。这是 Agent 的「总入口」，缺一不可，严禁漏配。
建议做 产品面：官网产品 / 规格详情 至少部署三件套：robots.txt（放行机器源）+ sitemap.xml（含 MD/source）+ llms.txt。当存在大量可入库正文时，须补齐 llms-full.txt。
可不做完整改造 营销面：落地页 / 临时活动域 不必挂齐四件套，但必须在 robots.txt / 收录策略中明确划界。严禁假挂空的 llms.txt 或空清单误导 Agent。

设计UI调整

调整建议

  • 页脚标出站级机器入口 在页脚次要区提供清晰可读的 llms.txt 文本链，确保可直接跟链。

调整示例

页脚标出站级机器入口

反面

正文与主路径区域（略）

  • 关于我们
  • 法律声明
  • 隐私政策

© 昇腾社区

  • 常见疏漏：页脚未标出 llms.txt，机器与审计无法从版面跟到站级清单。
正面

正文与主路径区域（略）

  • 关于我们
  • 法律声明
  • 隐私政策
  • llms.txt

© 昇腾社区

  • 正确做法：页脚次要区用小字标出 llms.txt，不抢主路径。
  • 可免场景：文档中心等已有同等清晰的站级入口时，页脚可不重复挂链。

文档内容调整

调整建议

  • 清单按产品线 / 版本分组 llms.txt 必须按产品线、版本号结构化分节。
  • 显式写明主推版本 必须声明当前主推版本（如 # 主推版本：CANN 8.0）；多版本并存时，严禁只罗列 URL 而不声明主推。
  • 入口名与正文同名 llms.txt 中的篇名 / 手册名必须与目标页 H1、侧栏用语一致，严禁另起一套叫法导致「看得见但对不上」。

调整示例

llms.txt：分组清晰、主推明确、名称一致

反面 
# Docs
- https://…/a.html
- https://…/b.html
- 昇腾安装指南（旧称）
  • 要点疏漏：① 无产品线 / 版本分节　② 未声明主推版本　③ 篇名与目标页 H1 不一致。
正面 
# CANN 8.0
- [安装指南](https://…/install.md)
- [Ascend C 算子开发](https://…/ascend-c.md)

# 主推版本：CANN 8.0
  • 要点：① 按产品线 / 版本分节　② 显式声明主推版本　③ 篇名与目标页 H1、侧栏同名。

前端调整

调整建议

  • robots 放行机器路径并划界 声明 LLMs.txt 与 Sitemap；放行机器源（/*.md$、/llms.txt）；屏蔽鉴权区、营销 / 活动域。
  • sitemap 优先机器源、排除噪声 loc 优先机器源 / 平行 .md 与主推版本；排除活动页与营销页；lastmod 与文档同步。多张 sitemap 须按业务语义分面命名（参照 NVIDIA），禁止 sitemapdoc1…N 式序号堆砌。
  • 页头声明 llms + alternate 统一输出站级 rel="llms" 与页面 rel="alternate"（指向平行 MD）；构建管道自动更新。

调整示例

robots：声明 LLMs.txt、放行 .md

反面 
User-agent: *
Disallow: /doc_center/
Disallow: /assets/

Sitemap: https://www.hiascend.com/sitemap.xml
  • 要点疏漏：① 未声明 LLMs.txt　② 机器源 / .md 被封死　③ 仅一条总 sitemap。
正面 
Sitemap: https://www.hiascend.com/sitemap.xml
Sitemap: https://www.hiascend.com/doc_center/sitemap.xml
LLMs.txt: https://www.hiascend.com/llms.txt

User-agent: *
Allow: /doc_center/source/
Allow: /*.md$
Allow: /llms.txt
Allow: /llms-full.txt
Disallow: /assets/
Disallow: /*?*utm_
  • 要点：① 声明 LLMs.txt　② 放行 source / .md / llms　③ 多条 Sitemap　④ 屏蔽噪声参数。

sitemap：loc 机器源优先，priority 更高

反面 
<url>
  <loc>https://…/document/detail/…/operator_dev.html</loc>
  <priority>0.5</priority>
</url>
  • 要点疏漏：① 仅渲染壳层　② 无 lastmod　③ priority 未区分机器源。
正面 
<url>
  <loc>https://…/doc_center/source/…/operator_dev.md</loc>
  <lastmod>2026-06-01</lastmod>
  <priority>0.9</priority>
</url>
  • 要点：① loc 指向机器源 / 平行 .md　② lastmod 与文档同步　③ priority 高于渲染页。

sitemap：按业务语义分面命名

反面 
Sitemap: …/sitemap/sitemapdata1.xml
Sitemap: …/sitemap/sitemapdata2.xml
Sitemap: …/sitemap/sitemapdoc1.xml
Sitemap: …/sitemap/sitemapdoc2.xml
Sitemap: …/sitemap/sitemapdoc3.xml
Sitemap: …/sitemap/sitemapdoc4.xml
Sitemap: …/sitemap/sitemapdoc5.xml
Sitemap: …/sitemap/sitemapdoc6.xml
  • 要点疏漏：仅按序号拆分，无业务语义；Agent / 运维无法按产品线定向抓取。
正面 
Sitemap: …/sitemap/doc-center.xml
Sitemap: …/sitemap/cann.xml
Sitemap: …/sitemap/mindie.xml
Sitemap: …/sitemap/developer.xml
Sitemap: …/sitemap/zh-CN.xml
Sitemap: …/sitemap/en-GB.xml
  • 要点：按文档中心 / 产品线 / 语种等业务语义分面命名（对齐 NVIDIA 多 Sitemap 分面），禁止 sitemapdoc1…N。

页头：输出 llms 链、指向 MD 源

反面 
<head>
  <title>Ascend C 算子开发</title>
  <link rel="canonical"
        href="/document/detail/.../operator_dev.html">
</head>
  • 要点疏漏：① 无 rel="llms"　② 无 alternate 指向平行 MD　③ Agent 只能跟渲染页。
正面 
<head>
  <title>Ascend C 算子开发</title>
  <link rel="llms" href="/llms.txt"
        type="text/markdown">
  <link rel="alternate"
        type="text/markdown"
        title="Ascend C 算子开发"
        href="/doc_center/source/…/operator_dev.md">
</head>
  • 要点：① 站级 rel="llms"　② 本页 alternate 指向平行 MD　③ title 与 H1 同名。
