机器可达：AI 亲和的起点

机器可达是 AI 亲和体系的起点。本页聚焦发现层的四个基础配置文件，其分工逻辑为：robots.txt 作为准入前提，llms.txt 作为主要路径，llms-full.txt 作为导读配套，sitemap.xml 作为兜底清单。它们共同回答了「知识在哪里、先看哪篇、如何高效获取」的问题。

Agent 是如何发现内容的

流程验证

核心原则

  • 聚焦知识面本套机制服务于文档与官方事实，营销面内容不占用发现层入口。
  • 门禁作为准入前提robots.txt 的配置定义了发现层的准入规则，是其他入口能够合法生效的前提条件。
  • 导读作为主要路径存在 llms.txt 时，以其作为判断相关性和优先级的主要依据；sitemap.xml 仅在导读缺失时承担回退功能，不承担替代导读的职责。
  • 全文包作为导读配套llms-full.txt 是 llms.txt 的配套组件，其内容与导读同步更新，不脱离导读单独发挥作用。

典型做法

1. robots.txt：准入门禁

进站时优先读取的准入文件，用于明确知识面的合法抓取范围。

约定路径

https://{域名}/robots.txt（协议规定的强制路径，不可更改）

最小合格示例

执行要点

  • 放行知识面文档站、官网知识页、/llms.txt 及 /llms-full.txt 路径应保持可访问（不设 Disallow），避免误挡主流 Agent。
  • 拦截噪声面后台、测试环境、调试接口等非公开路径应明确设置 Disallow，避免占用抓取额度。
  • 声明清单地址应在文件末尾通过 Sitemap: 字段列出 sitemap.xml 的完整地址，为 Agent 提供后续入口。
  • 进阶声明（非标准）部分厂商会在 robots.txt 中额外声明 LLMs.txt: 字段指向导读地址，仿照 Sitemap: 的写法；非官方规范，可作为路径不确定时的补充信号。

2. llms.txt：优先导读

面向 Agent 的精选导读，仅收录主推知识面，而非全站清单；用于明确优先阅读顺序与主推版本。

约定路径

https://{域名}/llms.txt（默认根目录；若文档站部署在子路径下，如 example.com/docs，则为 example.com/docs/llms.txt）

最小合格示例

说明：H1 为站点名；> 写明主推版本；H2 按产品 / 版本分组；链接文案与目标页 H1 同名；安装、API、概念排在组内前部。

执行要点

  • 直接可达根路径 /llms.txt 应直接返回内容，不设置跳转或登录拦截。
  • 内容纯化面向文档与主推版本，活动落地页不收录其中。
  • 结构对应按产品 / 版本分组，篇名与目标页面 H1 保持一致。
  • 版本声明多版本并存时，显式标注主推版本，以防引用过期稿。
  • 优先级排序安装、API、概念等核心入口置于清单前部。

3. llms-full.txt：配套正文包

导读的配套正文包，由导读定向触发，支持一次性提取纯净正文。

约定路径

https://{域名}/llms-full.txt（与 llms.txt 同目录，惯例路径）

最小合格示例

说明：篇题与顺序须与 llms.txt 一致；只留正文，不含导航、页脚、侧栏；随文档发布自动生成，不手工维护、不单独挂空文件。

执行要点

  • 入口限制依赖 llms.txt 中的链接或同目录惯例进入，不脱离导读单独配置。
  • 构建同步随文档发布流程自动生成，避免手工维护导致过期。
  • 结构对齐包内篇目顺序与 llms.txt 保持一致。
  • 正文纯净剔除导航、页脚和侧栏，仅保留可引用正文；不发布空文件。

4. sitemap.xml：无导读兜底

公开知识页的 URL 清单，作为导读缺失时的兜底入口。

约定路径

必须在 robots.txt 中通过 Sitemap: 字段声明完整地址——这一点与前三个文件不同，不能默认按根路径直接访问。

最小合格示例

说明：完整地址须写在 robots.txt 的 Sitemap: 行；有导读时本清单只作回退。

执行要点

  • 收录范围面向应被公开索引的知识面页面，后台或重复 URL 不收录其中。
  • 语义化 URL路径与文件名包含明确的业务语义（如产品名、版本号），避免无意义参数和会话 ID。
  • 地址声明在 robots.txt 中声明绝对地址。
  • 动态维护页面增删或迁移后同步更新。
  • 定性明确在存在导读时，作为回退方案，不承担主入口职责。

价值收益

  • 抓取资源更聚焦由于噪声页被隔离，抓取额度被有效集中，知识库的输入更干净，无效页面占用明显减少。
  • 检索命中更完整主推版本优先被捕获，深层或新增页面作为补充，实现从「高频核心」到「边缘细节」的全面覆盖。
  • 入库链路更高效免去逐页渲染壳层的开销，直接获取纯净正文，显著缩短了从抓取到进入知识库的耗时。
  • 回答出处更权威官方事实被优先沉淀为引用依据，有效规避了过期内容或营销页给用户带来误导，提升了 Agent 回答的整体可信度。
