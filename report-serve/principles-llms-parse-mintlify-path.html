这条路径说明什么

  • 从上往下读，碰到候选先记下Agent 按文件顺序读，不是先把所有 URL 打开再挑。读到像入口的那条（橙行）先记下，不立刻跳走。
  • 候选所在的节要读完，后面几条也看同一节里，候选下面的条目仍会读，用来确认不是它们。根清单 Docs 里，Documentation index 后面的 home / Quickstart 就是这样。不是碰到黄行就走。
  • 其它章只扫标题和一句说明，再进下一层后面的 ## / ### 跳读节名和描述，排除博客、定价、API、CLI 等。相关才进节里看第一条。排除完，再打开下一份。这一问每层跟一条；问句要对照两页时，同一层可以跟两条。
  • 答案在当前文件就停第四份已经是完整快捷键表，Related topics 只扫节名，不再打开。打开几次由「问句还缺什么」决定，不由目录有几层决定。
  • 第三份不是第三本 llmsllms.txt 只在「还要再选一本目录」时出现。根清单选出文档，下一份仍是文档分册 llms.txt。分册已经在列这一面有哪些页，页多就写成页名 .md，不再叫 llms.txt。所以这一问打开四份文件，llms 只有两本。
