实测页级亲和 领队

Skill ID：/page-affinity-probe

这个 Skill 做什么

这是单页领队。给一页文档或产品页，只敲 /page-affinity-probe：先判断有没有可打开的平行 Markdown；没有就从人读页抽正文；最后按原则改成可部署的 Markdown。全站入口（robots / sitemap / llms）请用总检。依据见全量原则 25 项。

  1. 发现：确认本页有没有平行 Markdown，以及文件是否可访问。
  2. 诊断：只看这一页实际出现的图、代码、步骤、说明等内容。
  3. 改稿：基于现网 Markdown 或抽出的正文给建议稿；绿色只标改过的字。
下载 Skill 查看示例报告

它怎么带其它 Skill

把它当作单页入口：对话里只敲 /page-affinity-probe，后面接页面地址。它会把「可发现」和「转 Markdown」两件事接起来，再统一产出一份可部署稿。下载本包即可完成这条流程，不必先装两个分项。

输入怎么接力输出
一页文档或产品 URL 先查平行 Markdown；没有可用文件时抽正文；再按原则补标题、图意、代码语言、验收等 一份页级报告 + 一份可下载 .md。修改说明会写清页面上怎么声明这份 Markdown
站点根（只有域名） 先确认是查全站，还是只改首页这一页 查全站时改走总检；这里不改 robots、sitemap、llms

本包已经内置这些分项说明，会在页级探针里按需接上：

  1. 核验 Markdown 正文可发现 /md-discoverability：看声明和文件能不能打开
  2. 提供 Markdown 正文 /html-to-md：没有可打开的平行稿时，用来抽正文

分项仍保留单独下载入口：只想核验声明，或只想把网页转成 Markdown，可以直接用对应 Skill。

如何触发

  1. 下载本领队包，放到 Agent 可读取的 skills 目录（如 .cursor/skills/page-affinity-probe/）。包内已含「可发现」和「转 Markdown」说明，不必再下两份分项。
  2. 在对话中用 /page-affinity-probe 唤起；斜杠后写页面 URL。不要再敲分项斜杠。没有地址时，Agent 会先追问。
字段必填说明
斜杠命令是用 /page-affinity-probe 明确唤起这个 Skill
页面 URL是如 https://support.huaweicloud.com/qs-codeartsagent/codeartsagent_qs_0002.html
本地 HTML可选抓不全时再给。不交也能跑

用户可以这样输入

  • /page-affinity-probe核验 https://support.huaweicloud.com/qs-codeartsagent/codeartsagent_qs_0002.html
  1. 生成结果是一份独立 HTML（问题判定 + 平行 Markdown 建议稿）和可下载的 .md。可对照 CodeArts VS Code 示例。
