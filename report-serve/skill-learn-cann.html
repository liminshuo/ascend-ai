生成 CANN 学习路径（社区）

Skill ID：/learn-cann

这个 Skill 做什么

当用户想学习 CANN / 昇腾相关主题时，这个 Skill 会把一句学习意图整理成一张可点击的学习路径地图。地图按「公共基础 → 主题阶段 → 练习与认证」组织，帮助用户直接进入适合自己的课程、学习路径或认证资源。

输出是一份本地 HTML 页面：每张卡片都使用昇腾社区学习中心（DLC）的真实资源名称与详情页链接，并标明资源类型，避免只给一段文字大纲。

下载 Skill 打开学习路径样例

如何触发

  1. 下载 Skill 包，放到 Agent 可读取的 skills 目录（如 .cursor/skills/learn-cann/）。
  2. 在对话中用 /learn-cann 唤起；斜杠后写学习主题，也可以补充画像。没有主题时，Agent 会先追问学习方向。
字段必填说明
斜杠命令是用 /learn-cann 明确唤起这个 Skill
学习主题建议例如算子开发、大模型推理、训练、应用开发、CANN 入门等
画像可选说明角色、目标或技术基础，用于调整路径推荐

用户可以这样输入

  • /learn-cann我想学大模型推理
  • /learn-cann我是开发人员，有 C++ 基础，想学 Ascend C 算子开发
  1. 生成结果是一份本地单文件 HTML，包含头图、学习者画像与时间轴卡片；卡片可跳转到社区课程 / 路径 / 认证。可打开学习路径样例查看最终效果。
