章节锚点可定位

章节锚点概述

AI Agent 在获取网页后，可能需要通过章节 URL 直接访问指定内容。如果页面缺少稳定的章节锚点，或目录链接与实际章节位置不对应，AI Agent 就难以准确定位目标章节，影响内容引用与后续访问。

章节锚点可定位原则旨在为重要章节提供稳定、唯一的锚点，并使目录链接与锚点一致，帮助 AI Agent 通过含锚点的 URL 直接落到目标章节。

章节锚点可定位原则

  1. 重要章节应具有稳定、唯一的锚点标识，支持通过包含锚点的 URL 直接定位到对应章节。
  2. 对于 Markdown 文档，不要求必须显式编写锚点，但应确保渲染后的页面能够通过章节 URL 定位到目标章节。
  3. 目录中的章节链接应与实际生成的锚点准确对应，确保访问后能够定位到目标章节。

目录链接与章节锚点一致 查看示例来源

目录链接应与章节锚点保持一致；AI Agent 访问包含锚点的 URL 后，应能够直接定位到对应章节。以 MindIE 文本生成推理快速入门为例，通过带 # 锚点的 URL 可直接跳转至目标章节。

  1. 1页地址告诉 Agent 引用知识来自于哪篇文章。
  2. 2段落锚点#环境要求 与该段标题同名，告诉 Agent 从这一段起读。
  3. 3段落名正文标题「2. 环境要求」，须与地址栏 # 后同名，Agent 才能落到这一段。
  4. 4锚点符标题旁的 #，把段落名写进 URL，机器从这一段起读。

Markdown 书写

  • 1. 按正常 Markdown 写标题即可；工具链会自动生成锚点，无需手写 {#id}。目录与定位以渲染结果为准

前端源码书写

  • 1. 标题带稳定 id；目录用 a[href="#id"] 同名对应，首包即可落到该节

预期效果

  1. 帮助 AI Agent 通过章节 URL 直接定位目标内容，提高章节引用的准确性。
  2. 减少逐层查找和重复读取页面内容的成本。

注意事项

  1. 锚点标识应尽量保持稳定，避免因章节调整导致已有链接失效。
  2. 不同 Markdown 平台的锚点生成规则可能不同，应以渲染后的实际定位结果为准。
  3. 章节能够定位不代表正文一定可被读取，正文的可读性应遵循相应规范。
