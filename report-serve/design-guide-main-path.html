主路径如何展开

安装 / 排障等必读步骤，默认就要看得见；弹窗不作唯一说明书。

场景

  • 任务：引导完成一条主路径
  • 页：安装、配置、排障、认证流程

方案对比

  • A：OStep 默认可见 + 警示 Note
  • B：关键步骤塞进折叠 / ODialog
  • C：步骤态只靠颜色，无文字

亲和选型

  • 主路径优先 A：每步有标题（+短说明）
  • 折叠仅收补充；标题须写清主题
  • Dialog 只做确认 / 次要补充，不放唯一安装说明

涉及组件

  • OStep 步骤条
  • 折叠面板
  • 警示 Note
  • ODialog 对话框

交稿检查

  • 未展开、未点弹窗时，主路径步骤标题仍在稿面
  • 「进行中 / 已完成」有文字或可辨标记，不只靠变色
  • 警告写「注意：」「警告：」，图标色只辅助

细样见 OStep · 折叠面板 · 警示 Note
