关键命令不受蒙版遮挡

为了帮助 Agent 在未勾选协议时仍能抓取安装命令与关键步骤，任务必需文本须首包默认可读；协议勾选可保留，不得用模糊蒙版挡住命令。

适用对象

名称 说明 常见落点
步骤蒙版 安装命令等关键步骤须默认可读；禁止用模糊蒙版藏步骤。 下载页、安装指引
协议门禁 协议勾选可保留；不得把命令可见性绑死在勾选结果上。 软件许可、资源下载

适用场景

优先级 页面类型 说明
必做 文档 / 官网下载页、安装指引 命令与步骤是 Agent 最常复制的事实。
建议做 SDK / 资源获取页 进引用池的安装路径，勿依赖勾选后才露命令。
可不做完整改造 纯法务弹窗，且命令另有公开说明页 本页不承载唯一步骤时，可只做协议确认。

设计UI调整

调整建议

  • 命令默认可视 安装命令、关键步骤须在默认态可读；协议勾选只控制确认，禁止把步骤放到勾选之后才展示。
  • 蒙版不得挡命令 禁止用模糊蒙版、半透明遮罩盖住命令区；法务必须确认时，勾选可保留，命令文本仍须默认可读。

文档内容调整

调整建议

  • 步骤写在默认可读区 安装命令、关键步骤写入页面正文或默认可见代码块，不依赖「勾选后才展示」。
  • 协议与命令分离 许可协议文案可独立；命令区不得只在勾选后才出现。平行 MD 亦须含同套命令。

前端调整

调整建议

  • 首包含命令文本 安装命令节点存在于首包 DOM；禁 JS / 未勾选时仍可抓取。
  • 蒙版不删节点 若保留视觉蒙版，不得从 DOM 移除或清空命令文本；优先不用蒙版挡命令。
