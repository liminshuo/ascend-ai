链接目标可识别

概述

网页中的链接用于连接相关文档、操作指南、产品页面及外部资源。如果链接仅使用“点击这里”“查看详情”等通用文本，或只通过图标表达去向，AI Agent 就难以判断链接目标及其用途。

链接目标可识别原则旨在通过清晰的链接文本和可读取的目标地址，帮助 AI Agent 理解链接指向的内容、用途及站内外去向。

具体原则

  1. 链接文本应明确表达目标内容或用途。优先使用目标页面名称、文档标题或具体操作描述，避免仅使用“点击这里”“了解更多”等缺乏上下文的通用文本。
  2. 链接文本与目标地址应保持对应。确保链接文本准确描述实际目标；在 Markdown、源码或其他可读取内容中，保留链接文本与 URL 的对应关系，避免只提供无法识别目标的链接标记。
  3. 图标链接应提供可读取的目标说明。对于仅使用图标、图片或其他非文本元素的链接，应通过可访问名称或配套文本说明其目标或功能。
  4. 站外链接应在适当场景下明确来源或外部属性。当跳转到外部网站、下载资源或第三方服务会影响用户或 Agent 对目标的判断时，应提供必要的来源、资源类型或站外提示。

预期效果

  1. 帮助 AI Agent 直接理解链接指向的页面、文档或资源，减少根据上下文猜测目标的情况。
  2. 提高链接在 HTML、Markdown 和源码中的可识别性，便于发现、检索和引用相关资源。
  3. 帮助 AI Agent 区分站内页面、外部网站和下载资源，降低链接目标误判的风险。

注意事项

  1. 链接文本应简洁、准确，不必重复整段目标页面介绍。
  2. 链接文本应与实际跳转目标一致；目标变更时，应同步检查链接地址和描述。
  3. 图标链接应提供可访问名称；纯装饰性图标无需额外添加链接语义。
  4. 站外链接提示应根据实际场景提供，不必为每个链接重复添加冗余说明。
