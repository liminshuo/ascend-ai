图标语义锚定

信息型图标旁须有文字锚定含义；装饰图标可剥离，禁止只靠图形表达状态、类别或量纲。 可读 · 设计专项见 图标语义锚定。

对象

类型 说明 常见落点
提示图标 公告等提示图标须配文字名称；日期须标明是发布时间还是更新截止时间。 公告提示
说明等提示图标须配文字名称，禁止仅以图形承载。 说明提示
卡片信息图标 卡片内图标所表示的字段名与类型名须以文字标注，禁止仅以图形承载。 卡片内「作者」「发布时间」等
卡片内数字须附带指标名或单位，禁止单独呈现。 卡片内统计等
品牌 Logo LOGO 品牌须配文字：可在 Logo 旁显示名称，或写入源码 alt，二选一即可。 Logo 墙、生态伙伴

设计UI调整

调整建议

  • 图标不独自表意：图标承载的字段、类型或量纲须配文字，图标可保留但不得作唯一载体；数字须附单位。
  • 提示图标配名称：公告、说明等提示图标旁须有可见文字名称；日期须标明发布时间或更新截止时间。
  • 卡片字段与指标成文：卡片内图标字段名、类型名与统计指标须以文字标注，禁止仅以图形或裸数字承载。
  • 品牌 Logo 可识别：Logo 旁显示名称，或写入源码 alt，二选一；每项可跟链。

文档内容调整

调整建议

  • 文案与图标语义一致：文案含义须与图标一致（如「告警」不要配成功勾）；字段名、类型名写入正文，不依赖读者识图。
  • 列表勿只放图标列：表格或列表中承载语义的列须有文字表头与单元格文案，禁止仅以图标列区分状态或类别。
  • Logo / 品牌可检索：品牌名单须以可见文字或非空 alt 交付；旁白已列同一名单时，Logo 可只作装饰。

调整示例

1. 字段与日期写成文字

Before · 仅靠图标

[人像图标] Shiyue Xu, Fu Zhang, …
[时钟图标] 2025年7月

After · 字段名成文

作者 Shiyue Xu, Fu Zhang, …
发布时间 2025年7月

2. 指标数字附单位 / 名称

Before · 裸数字

[星] 228   [分支] 61   [眼] 0

After · 指标名 + 数字

收藏 228 · 分支 61 · 浏览 0

前端调整

调整建议

  • 信息图标可访问名称：信息型图标提供可见旁路文本或 aria-label；装饰图标用 aria-hidden="true" 或空 alt。
  • 入库抽取旁路文字：切片管道抽取图标旁文案 / aria-label，不依赖 icon font 字形或纯 SVG path。
  • 区分信息与装饰：交付时标记信息图标与装饰图标，装饰项跳过向量化。
