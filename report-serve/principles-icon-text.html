图标语义可锚定

为了帮助 Agent 理解状态、类别与量纲，信息型图标旁须有文字锚定含义；装饰图标可剥离，禁止只靠图形表意。

适用对象

名称 说明 常见落点
提示图标 公告、说明等提示图标须配文字名称；日期须标明是发布时间还是更新截止时间。 公告条、说明提示
卡片信息图标 字段名、类型名与统计指标须以文字标注；数字须附指标名或单位，禁止仅以图形或裸数字承载。 卡片「作者」「发布时间」、统计
品牌 Logo 品牌须配可检索名称：Logo 旁显示文字，或写入非空 alt，二选一即可。 Logo 墙、生态伙伴

适用场景

优先级 页面类型 说明
必做 公告条、文档卡片列表 图标常承载类型与字段，须文字锚定。
建议做 官网 Logo 墙、生态伙伴 品牌名进引用池时，须可见名称或非空 alt。
可不做完整改造 纯装饰图标、氛围点缀 不表意时可 aria-hidden / 空 alt，勿硬写标签。

设计UI调整

调整建议

  • 图标不独自表意 图标承载的字段、类型或量纲须配可见文字；图标可保留但不得作唯一载体；数字须附单位或指标名。
  • 提示图标配名称 公告、说明等提示图标旁须有可见文字名称；日期须标明发布时间或更新截止时间。
  • 品牌 Logo 可识别 Logo 旁显示名称，或写入源码非空 alt，二选一；每项可跟链。旁白已列同一名单时，Logo 可只作装饰。

文档内容调整

调整建议

  • 文案与图标语义一致 文案含义须与图标一致（如「告警」不要配成功勾）；字段名、类型名写入正文，不依赖读者识图。
  • 列表勿只放图标列 表格或列表中承载语义的列须有文字表头与单元格文案，禁止仅以图标列区分状态或类别。
  • 指标数字附名称 统计数字须附指标名或单位（如「收藏 228」），禁止裸数字或仅靠图标暗示量纲。

调整示例

字段与日期写成文字

反面 
[人像图标] Shiyue Xu, Fu Zhang, …
[时钟图标] 2025年7月
  • 常见疏漏：字段名只靠图标，机器不知道是作者还是时间。
正面 
作者 Shiyue Xu, Fu Zhang, …
发布时间 2025年7月
  • 正确做法：字段名与时间语义写成可见文字。

指标数字附单位 / 名称

反面 
[星] 228   [分支] 61   [眼] 0
  • 常见疏漏：裸数字 + 图标，量纲不可检索。
正面 
收藏 228 · 分支 61 · 浏览 0
  • 正确做法：指标名 + 数字，图标仅作辅助。

前端调整

调整建议

  • 信息图标可访问名称 信息型图标提供可见旁路文本或 aria-label；装饰图标用 aria-hidden="true" 或空 alt。
  • 入库抽取旁路文字 切片管道抽取图标旁文案 / aria-label，不依赖 icon font 字形或纯 SVG path；装饰项跳过向量化。
  • Logo 名称可检索 品牌 Logo 须非空 alt 或旁路可见名称；首包即含该文字，禁止仅客户端补全。

调整示例

公告图标须有旁路文本

反面 
<span class="ico" aria-hidden="true">…喇叭 SVG…</span>
<span>昇腾 CANN 9.1.0 版本发布</span>
<time>2026/07/31</time>
  • 常见疏漏：无「公告」文案；日期语义不明。
正面 
<span class="ico">
  <svg aria-hidden="true">…</svg>
  <span class="lab">公告</span>
</span>
<span>昇腾 CANN 9.1.0 版本发布</span>
<time datetime="2026-07-31">2026/07/31 发布</time>
  • 正确做法：可见「公告」+ 时间语义写清。

Logo 须有 alt 或旁路名称

反面

  • 常见疏漏：空 alt，品牌名不可检索。

<a href="…">
  <img src="vllm.png" alt="vLLM">
  <span>vLLM</span>
</a>
  • 正确做法：非空 alt 或旁路可见名称（可二选一）。
