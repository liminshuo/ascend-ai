测试提问

Ascend C 怎么入门？请只从 hiascend 官方文档找，并写下你每一步请求了哪个 URL

模型原始回答

  1. 定位：Ascend C 是 CANN 面向算子开发的编程语言，原生支持 C/C++；写好的算子经编译器和运行时调度，跑在昇腾 AI 处理器上。产品页把初学者路径写成：先完成矢量算子核函数，掌握基础 API 调用。
  2. 准备环境：安装驱动固件和 CANN，装完以 CANN 运行用户执行 source $INSTALL_DIR/set_env.sh（商用包示例 /usr/local/Ascend/cann，社区版示例 /usr/local/Ascend/ascend-toolkit）。教程还要求 CMake ≥ 3.16。没有昇腾硬件时可先在 CPU 仿真里开发。
  3. 跟 Add 样例走一遍：算子分析 → 写核函数（样例多为 add_custom）→ 先 CPU 模式验证，再 NPU 模式验证。矢量侧典型流程是 Global Memory → Local Memory（DataCopy）→ 计算（如 Add）→ 再搬回；任务间用 EnQue / DeQue，内存用 AllocTensor / FreeTensor。
  4. 官方给出的下一步：产品页是代码样例 → 快速入门文档 → 入门课程，再进到工程化开发、编程模型、调试。技术文章指向《Ascend C 编程指南》。

改进建议

模型原始回答

  1. 先建立概念：Ascend C 是 CANN 面向算子开发的编程语言，原生支持 C/C++ 标准规范；提供语言扩展层 C API、基于 Tensor 的基础 API、高阶 API、算子模板库和 Python 前端 PyAsc。
  2. 搞懂硬件抽象：CPU 是 host、NPU 是 device，经 PCIe 协同。核心是 AI Core，内含 Scalar / Vector / Cube 三个计算单元和 DMA 搬运单元；Global Memory 共享，Local Memory 带宽高但只有几百 KB 到 1MB。
  3. 掌握流水编程范式：矢量编程固定为 CopyIn → Compute → CopyOut 三个任务，对应逻辑位置 VECIN / VECCALC / VECOUT，用 EnQue / DeQue 串起来，Pipe 统一管内存。多核走 SPMD，所有核跑同一份代码，靠内置变量 block_idx 偏移切分数据。
  4. 记住四类 API 与核函数写法：计算类、数据搬运类（DataCopy）、内存管理类（AllocTensor / FreeTensor）、任务同步类（EnQue / DeQue）；核函数声明为 extern "C" __global__ __aicore__，用 kernel_name<<<blockDim, l2ctrl, stream>>> 调用，入门先把 blockDim 设为 1。
  5. 动手：按《CANN 软件安装指南》装好环境，执行 source ${install_path}/set_env.sh；取官方 quick-start 样例骨架，写核函数和 host 侧 main.cpp；用孪生调试先在 CPU 侧以 ICPU_RUN_KF 宏配 GDB 单步，再到 NPU 侧验证；最后 bash run.sh add_custom ascend910 AiCore cpu，换 npu 再跑一遍，用 md5sum 比对结果。
  6. 继续深入：CANN 文档聚合页（当前 9.2.0-beta.1，更新于 2026/08/12）「编程语言」栏下是《Ascend C 编程指南》，「API 参考」栏下是《Ascend C API》，「学习与教程」栏下有 CANN-learning-hub 和 CANN-samples。
