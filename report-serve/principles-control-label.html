控件标签与数值可读取

解决什么问题

Agent 无法判断控件用途，也读不出当前值（如：只有占位符、拆框共用总标签、进度只靠条长、评分只靠星星）。

核心原则

控件须有可读标签与数值

每个输入须能点名用途：源码用 label / aria-label，占位符不能当唯一出处。搜索框界面不必另加「关键词」标题，按钮「搜索」即可。拆成多框时每框须有独立可见标签。滑杆、进度、评分的当前值与单位须写成可见文字。图形只作辅助。空列表与「-」见 失败状态可处理。

典型示例

标签 · 用途可点名

搜索框不必在界面上再写「关键词」；源码须有 label 或 aria-label。拆成多框时，每框仍须独立可见标签。
