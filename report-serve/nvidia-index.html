NVIDIA · 找的到（收录索引）

NVIDIA 在工程上将「技术可达」做到了极致，却唯独在「愿不愿意为 AI 的引用负责」这一收口环节上缺少边界判断。

分析总结

一、值得学习：工程上把「找得到」做透

  • 分面管道。www / docs / developer / build / gtc 各自维护 Sitemap 与 llms；根站只做枢纽，不靠一张全站总表定生死。
  • 权威 locale。用 en-us 等固定路径当 AI 引用来源，避免只抓到浏览器语言页而漏掉官方正文。
  • 架构一次到位。靠整体渲染与平行 Markdown，整站 HTML 可读，不必逐页补亲和。
  • 可达做成底座。证明高复杂度门户也能把「机器找得到、读得顺」做成基础设施。

二、需要警惕：管道通了，策展却没跟上

  • 管道通 ≠ 策展完。营销叙事也被推进深度亲和，广告与事实混进同一 Agent 语料。
  • 有目录，无背书。收录量大，但不声明「这一页可为 AI 引用负责」；噪声容易盖过精准答案。
  • 规则与交付错位。进了 llms，平行 Markdown 却可能 404——索引写了，正文没跟上。
  • 壳页充正文。On-Demand 等导航汇总页也被生成 MD，信息密度低，还易与子页打架。
