NVIDIA（html）分析 · 可引用性·内容（html）分析

聚焦一件事：大模型去抓网页 HTML 时，关键信息能不能读到、链接跟不跟得上、图和日历会不会丢、广告会不会和正文搅在一起。 下列观点从 NVIDIA 八类典型页（含「完整」与「部分」）实测提炼，并给出可执行建议。

从友商做法提炼的观点

  • 产品/行业营销页往往「完整」：标题、说明、入口卡多半写进源码，且常带真实 href（如 DGX Cloud、Industries、Automotive、Partners）。抓得到文字，不等于整页适合当规格知识源。
  • 「部分」页要单独对待：build.nvidia.com 首屏分区有 SSR，但目录/检索偏动态；Newsroom 列表可抓、全文在详情且图常缺 alt；Events 人读开 JS 能见日程，静态首包几乎无日期——人看得见 ≠ 源码里有。
  • 链接写在标签里才跟得上：NVIDIA 多处 Learn More / Find a Partner / 行业卡带真地址——这点值得学。
  • 转化与证明要剥壳：Contact Us、购物车、加入计划等和说明同页；入库时只留可核对正文与文档链接。
  • 对昇腾：重要说明页优先完整 SSR；应用壳/日历/资讯列表若要对 AI 可抓，补静态列表或独立文档页，并给图补说明文字。
