侧栏菜单不可达 样本缺失 · 侧栏难抓

查看测试页面

侧栏菜单不可达指设计侧栏/层级菜单（OMenu）上的文档目录与链接；若首包无完整树或无真实 href，RAG 无法按手册结构发现页面。 以 昇腾AI训练营常见问题 为例：FAQ 文档侧栏场景；静态未见 o-menu / 侧栏 a[href] 树，目录节点与 URL 在 __NUXT_DATA__。

根因分析

侧栏菜单不可达的核心原因：人在浏览器里能看到左侧目录，但「查看网页源代码」里几乎没有这些目录链接——章节名和地址藏在页面脚本数据里，要等 JavaScript 跑完才画出来，所以爬虫和 AI 默认读不到。

1. 源码里没有完整的左侧目录

问题：打开昇腾AI训练营常见问题页，用「查看网页源代码」核对：左侧那一整棵章节目录几乎找不到，只有很少几条零散链接。各篇其实都有自己的文档地址，但没有写成侧栏上的可点链接，要等脚本跑完才画出来——爬虫打开源码时跟不到目录链。

证据 · 侧栏链接本来应该长这样

期望写进网页的侧栏链接（示意，当前页没有）

<nav class="doc-sidebar">
  <a href="…/accfaq_000.html">账号与认证</a>
  <a href="…/ascendaitrainingcamp_000.html">昇腾AI训练营常见问题</a>
  <a href="…/developerpartner_011.html">伙伴计划</a>
</nav>

每篇不同地址是对的；缺的是把它们直接写在侧栏 HTML 里。

修改建议

页面一出来就把完整目录写进 HTML：每一项都是「章节名 + 真实地址」的链接，展开收起按钮不能代替链接。

2. 脚本数据里也只有邻篇，没有整棵目录

问题：即便从页面脚本数据（__NUXT_DATA__）里抠「上一篇 / 下一篇」，也只能拿到「账号与认证」「伙伴计划」两个邻居，看不到「社区功能与服务」下其余章节。所以既列不全手册结构，也不能靠这段数据补出完整发现层。

证据 · 脚本里只有邻接节点

页面脚本数据摘录（训练营 FAQ 实测）

{
  "finalNodeName": "昇腾AI训练营常见问题",
  "finalNodeUrl": "zh/AscendFAQ/CommuFunc/AscendAITrainingCamp/ascendaitrainingcamp_000.html",
  "upNodeName": "账号与认证",
  "upNodeUrl": "zh/AscendFAQ/CommuFunc/Account&AuthenticationFAQ/accfaq_000.html",
  "nextNodeName": "伙伴计划",
  "nextNodeUrl": "zh/AscendFAQ/CommuFunc/Developer&partner/developerpartner_011.html"
}

地址有、且每篇不同；但这组字段只有当前页 + 邻篇，不是完整侧栏树。

修改建议

若脚本数据要作备用，须带完整子节点列表（标题 + URL），不能只有当前页和上一篇 / 下一篇。

3. 也没有备用的章节清单

问题：侧栏读不到时，如果网站地图或 llms.txt 里也没有按手册列出各章链接，AI 就只知道当前这一页写了什么，不知道整本手册还有哪些页。

修改建议

在 llms.txt 或 Markdown 手册里再列一份「章节名 + 链接」，和侧栏目录互相补上。
