版本与时效信息可识别

概述

技术文档、产品说明和操作指南可能随版本迭代而更新。若页面未明确标注版本、更新时间或内容状态，AI Agent 就难以判断内容适用的版本及当前有效性，可能引用过时信息。

版本与时效信息可识别原则旨在明确标注内容的版本、更新时间和生命周期状态，帮助 AI Agent 判断内容的适用范围、时效性及可用性。

具体原则

  1. 版本号应明确可见。 在版本列表、文档标题或详情页中展示具体版本号，不能仅以「新版」「旧版」等相对描述代替。
  2. 更新时间应明确标注。 展示具体的更新时间或发布日期，使用统一、清晰的日期格式，避免仅依赖列表排序或相对时间判断内容新旧。
  3. 内容状态应有明确的文本标识。 对维护中、已废弃、即将停止支持等状态使用可直接读取的文字说明，不能仅依赖颜色、图标或缩写表达；必要时提供替代版本或后续使用指引。
  4. 版本信息应保持一致。 确保列表、详情页及机器可读元数据中的版本号、日期和状态相互一致；内容更新或状态变更时，同步更新相关信息。

预期效果

  1. 帮助 AI Agent 识别文档对应的版本、更新时间及当前状态，降低引用过时或不适用内容的风险。
  2. 帮助 AI Agent 区分现行版本与历史版本，提高检索、筛选和引用的准确性。
  3. 确保列表、详情页和机器可读信息保持一致，减少版本信息冲突。

注意事项

  1. 版本号、更新时间和生命周期状态应分别表达，不能相互替代。
  2. 「最新」不等于「仍受支持」；必要时应同时标明版本号和生命周期状态。
  3. 历史版本可以保留，但应明确标注其状态，并在适当情况下提供现行版本链接。
  4. 多版本并列时，每个版本应有独立、准确的版本号、更新时间和状态，避免不同版本共用同一组信息。
