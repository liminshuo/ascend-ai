下拉菜单子链须可抓

下拉菜单子项须在首包 HTML 可读（a[href]+可见文案）；禁仅触发器、portal 延迟挂或外部 JSON 菜单（昇腾「更多产品」/ Mintlify Products / NVIDIA Resources 均须 SSR 链化）。

设计UI调整

调整建议

  • 子项文案须自描述：面板内每项用对象全名（如「Atlas 900 A2 PoD 集群基础单元」），勿只写「产品1 / 更多 / 了解更多」。
  • 面板子链按真实链接出：展开面板内子项均按可点链接呈现；勿只画触发器，或子项用无目标的泛词伪入口。

调整示例

示例1. 下拉：泛词伪链 → 自描述可跟链

✗ 错误示范 · 有面板 · 子项也泛

更多产品 ▾
  • 产品 1
  • 产品 2
  • 了解更多 ›

面板里虽有项，但是「产品 1 / 了解更多」等泛词，且常按悬停态交付、未当可跟链接画出。

✓ 推荐做法 · 触发器 + 自描述子链

更多产品 ▾
  • Atlas 900 A2 PoD 集群基础单元
  • Atlas 900 SuperCluster AI 集群

要点：子项用机型全名，并按真实可点链接交付（实现上须首包输出）。

文档内容调整

调整建议

  • 统一命名：下拉子项文案与落地页 title、llms / sitemap 条目对齐（机型 / 特性 / 资源名全称一致）。
  • 下拉子链平行清单：在 llms.txt 或平行 MD 中平铺面板子项（标题 + URL），如「更多产品」下各集群机型；即使 panel 未抓全，也可枚举同品类入口。
  • 过渡补位：HTML 仍靠交互 / JSON 挂载时，用 llms 临时补子链；SSR dropdown 达标后以页面为准，重复项可移除。

前端调整

调整建议

导航型下拉的面板子项须写入首包 HTML；静态抓取（不执行 JS）仍能列全子项文案与 a[href]（对标要求：Mintlify Products、NVIDIA Resources 亦须 SSR；昇腾「更多产品」同）。

具体要求：

  • 子项须为真实链接：panel 内每项须为 a[href] + 可见文案；勿仅留触发器（更多产品 / Products）而无子链。
  • 子链进首包，勿延迟挂：子项须服务端一次性输出；可用 CSS 隐藏，勿等悬停 / 点击才注入，勿仅挂 body portal。
  • 外部 JSON 不可作唯一菜单：header-secondary.json、application/json 等仅可作增强，不能代替首包 a[href] 列表。

调整示例

示例1. 集群页「更多产品」

✗ 当前问题 · 仅触发器 · 子链未进首包

<span>更多产品</span>
<!-- panel 悬停后才挂 a[href] / 首包为空 -->
<!-- 同类：Mintlify Products 触发器；NVIDIA #header + fetch JSON -->

首包只有触发器文案；静态抓取列不出各机型落地 URL。

✓ 推荐做法 · SSR 面板子链可跟

<div class="o-dropdown-panel">
  <a href="/hardware/cluster?tag=900">Atlas 900 A2 PoD 集群基础单元</a>
  <a href="/hardware/cluster?tag=900ai">Atlas 900 SuperCluster AI 集群</a>
</div>

panel 内子项写成 a[href]；静态抓取即可列全并跟链。
