NVIDIA 集团根 llms.txt

解析什么

对照 NVIDIA 站根 https://www.nvidia.com/llms.txt。这是集团入口：几乎只链各站自己的分册 llms.txt，不在根文件里摊开每一页。写法对照见根llms。

它在解决什么

NVIDIA 有北美官网、文档站、开发者站、GTC、地区博客、中国站。若全写进根文件，会截断。根清单只负责告诉 Agent：下一本分册在哪。

这张根清单怎么分面

  • 按下一步分节北美站、文档站、开发者站、大会各自成节，不是把导航菜单原样搬家。
  • 大面只挂分册条目几乎都是另一份 llms.txt。叶子页不进根文件。分册怎么写，见分册llms。
  • RSS 不是 llms地区博客用 feed / xml，不是 Markdown 目录。放在后面，主路径仍是各站分册。

根 llms 交付示例

对照 NVIDIA 站根 llms.txt 全文。收录的是各知识面入口（几乎全是分册 llms.txt），不收录文档站每一页或每一篇博文。地区博客用 RSS，不是 Markdown 目录。

根 llms.txt 交付件拆解

对照 NVIDIA 站根 llms.txt：只当目录，不写文章正文。分节按 Agent 下一步要打开哪一本分册，不是把全站 URL 平铺。同一文件里，分册 llms.txt 与 RSS 兜底可以并存——先选面，再跟分册。

页顶

# NVIDIA Corporation 是站点名。引用块说明本文件是各站分册 llms.txt 的入口，按地区 / 站点往下跟，不在这里摊开每一页。

北美站

官网与开源站各一本分册。第一条写明是营销 / 公司 / 产品信息。OpenSource 这一行标题和括号之间多了一个空格，Markdown 链会断，现网如此。

文档面

进站主任务之一是找产品文档，所以单独成节。这一面页多，只链分册 docs.nvidia.com/llms.txt，根文件不写满。分册内部怎么写，见分册llms。

开发者面

开发者站和开发者博客都是会持续变长的集合，各挂一本分册：下载 / SDK / 论坛一本，博文一本。和文档面拆开，避免把「读手册」和「读博客」混在同一组。

大会

GTC 是独立知识面（会场、场次、嘉宾），单独一本分册，不并进官网或文档站。

分面入口

地区博客用 RSS / xml，不是 llms.txt，也不是各页 .md。中国官网和中国开发者站仍是分册 llms.txt；现网写成 ###，挂在 RSS 节下面，层级容易被读成「RSS 的子项」，实际是另一组站点入口。

价值收益

  • 根文件读得完多站点只保留分册入口，避免截断。
  • 先选面再跟文档、开发者、大会、地区站分开，Agent 按任务打开下一本 llms.txt。
  • 叶子不进根清单各页正文留在分册里摊开，见分册llms。
