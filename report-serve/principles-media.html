音视频要点可伴随

为了帮助 Agent 在不必「听完 / 看完」的情况下答题，音视频不独自表意：关键步骤、结论与参数须有可读取的旁侧文字要点。

适用对象

名称 说明 常见落点
视频 讲解、步骤与结论须以播放器旁标题与要点 / 正文交付，禁止仅存于播放器或画面烧字。 案例视频、教程片
音频 讲解与结论须以音频条旁标题与要点 / 正文交付，禁止仅以波形或口播承载。 答疑音频、播客片段

适用场景

优先级 页面类型 说明
必做 教程片、安装 / 答疑音视频 步骤与结论常靠口播，须旁侧文字可抓。
建议做 官网案例视频、产品演示 案例要点进引用池时，须配标题与摘要。
可不做完整改造 装饰性背景音 / 氛围视频 不承载步骤结论，且旁侧正文已覆盖同一内容时，可只作装饰。

设计UI调整

调整建议

  • 媒体不独自表意 讲解、步骤与结论不得仅存于音视频；须配旁侧可抓取标题与要点。画面烧字与口播均不视为文本替代。
  • 要点概括即可 旁侧文字概括关键步骤、参数与结论即可，无需逐字转写口播；布局上要点默认可见，勿藏进需点击才展开的唯一入口。

CANN 安装答疑

驱动版本须与 CANN 配套；配置 PATH 后用版本查询确认匹配。

  • 正确做法：音频条旁写标题与要点正文；波形只辅助。

设计专项完整说明见 音视频要点伴随。

文档内容调整

调整建议

  • 要点与口播一致 用条目概括操作步骤、命令与预期结果；旁侧要点须与口播关键事实一致，勿另写一套营销摘要。
  • 页内须有足够摘要 可链完整讲义 / Markdown，但页内须有足够步骤与结论摘要，禁止「详见视频」作为唯一出处。

前端调整

调整建议

  • 要点在首包 HTML 旁侧标题与要点须随首包输出；禁止仅靠 XHR / 点击后加载字幕或摘要作为唯一文本。
  • 字幕不作唯一替代 可提供字幕轨，但关键步骤仍须以可见正文 / 要点块交付；勿假设爬虫会解析媒体轨。
  • 装饰媒体勿入库 装饰性背景视频 / 氛围音标记跳过向量化；信息型媒体旁的要点块须参与切片。
