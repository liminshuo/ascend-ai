共用标尺 · AI亲和 Level

三条路径共用同一套判定：先过背书闸门，再定未就绪 / 基线亲和 / 深度亲和。四列实测（llms 收录、Sitemap 可发现、HTML 可读、Markdown 可读）用来取证。

背书闸门

G · 敢不敢背书

愿不愿意让 AI 把这页当官方事实原样引用？不愿意就停在基线亲和，业务价值再高也不升档。 一票否决：定价页价值高却因报价会变而故意不进目录。

未就绪

索引缺失或正文不可读

  • Sitemap / llms 都找不到，或 HTML 主信息缺失（正文靠 JS 才出现且无平行 MD）。

基线亲和

Sitemap 可发现 · HTML 可读

  • 进对应内容面 Sitemap，不执行 JS 也能读到完整主信息。服务 SEO / 人读，默认不进 llms、不强制 Markdown。

深度亲和

llms 收录 · Markdown 可读

  • 写入机器目录，并提供与 HTML 同源同步的平行 Markdown。只给官方愿背书的事实叶子页。

知识面目标

深度亲和

文档 / API / 教程 / 支持库。先保证 Sitemap + HTML 可读；再补 llms 与平行 MD。

非知识面默认

基线亲和封顶

营销、生态、博客、定价、活动等。Sitemap 可服务 SEO；不进 llms，不强制 MD。

可直接搬的决策

从友商对标沉淀的操作要点；展开论证见 友商对照。

三步决策

  1. 这页公开吗？是 → 保证 HTML 可读（主信息进 HTML，不靠 JS 才出现）。
  2. 用户会拿它问「怎么做 / 是什么」吗？会 → 进对应内容面 Sitemap，达到 基线亲和。
  3. 长期稳定、愿意背书吗？是 → 再补 llms 收录与平行 Markdown，升到 深度亲和。能搜到 ≠ 该被引用。

可搬走的结论

  1. 管道能力必须学——分区 sitemap、locale 权威 MD、枢纽 llms。
  2. 全面覆盖必须警惕——工程学 NVIDIA，收口学 Mintlify。
  3. 策展以场景为准——先问愿不愿意背书，再决定是否升到深度亲和。
  4. 叶子重于汇总——具体可引用页优先；根页最多做入口指针。
  5. 分流是为了场景边界——目标是分面管道 + 窄目录背书，而非全站镜像。

四种明确不做

  • 会频繁变且过期有害定价、活动日程、报价
  • 说服性而非事实性营销卖点、客户证言、博客观点
  • 与产品使用无关招聘、法务、公司新闻、登录账户
  • 壳页与弱背书转化入口、纯导航目录根、社区 / Wiki / UGC

运营域定档

按 AI亲和 Level 给七个运营域定档。知识域必改到深度亲和；其余多数停在基线或未就绪。

运营域 目标 AI亲和 Level定到哪一档 取证要点四列里盯什么 决策 改造动作
市场营销 基线亲和封顶，不升深度 Sitemap · HTML说服与导流，非说明书 不改 进 sitemap 即可；不进 llms，也不做平行 MD。
知识 深度亲和知识面目标 llms · Markdown操作说明书，答错=失败 必改 文档 / API / 教程 / 学习站做满四列；索引跟知识面走，按子域 / locale 验收。
内容运营 基线亲和封顶，不升深度 Sitemap · HTML时效强、口径偏传播 不改 进 sitemap；不进机器目录，避免稀释文档答题准确率。
生态 基线亲和封顶，不升深度 Sitemap · HTML招募与分群，非产品事实 不改 与营销相同；不追 MD、不进 llms。
商业转化 基线亲和封顶，不升深度 Sitemap · HTML报价会变，引旧价有风险 不改 允许 SEO；刻意不进 llms。
社区运营 未就绪可接受可不进 Sitemap HTML 可读即可时效 / UGC，不背书 不改 活动、Wiki / Forum 不必进知识目录；精华另做 FAQ 进知识域。
公司事务 未就绪与产品用法无关 HTML 可读即可组织事务，非知识源 绝对不改 关于、法务等。招聘可单独做到基线亲和做岗位曝光。

落地顺序

矩阵定「改到哪」，还要回答「先做谁」。三问不能颠倒。

  1. 过得了背书闸门吗？

    不愿意让 AI 当官方事实引用，就停在基线。一票否决，不参与打分。

    定价页高价值却因引旧价风险——故意不进目录。

  2. 目标定到哪一档？

    未就绪 / 基线亲和 / 深度亲和一次定档。索引缺口归站点配置，正文与 MD 缺口归前端与内容生产。

    没进 sitemap，和进了 sitemap 但正文全靠 JS，是两种问题。

  3. 先做谁？

    只在「必改」范围内排序：先补配置类（便宜、立刻见效），重写正文放后面。

    补一条 sitemap 几分钟；重写栏目正文要排几个季度。

打分只排序，不决定改不改。 「改不改」由背书闸门和运营域判定决定。价值与独特性加总会把定价页算成最该深度改造——结论正好反了。

robots.txt 不是档位。 「不做深度亲和」= 停在基线亲和，仍可进 sitemap；不等于屏蔽爬虫。

按季度复检。 Markdown 与 HTML 会漂移、新页会漏索引。亲和度会腐化，不是一次性项目。
