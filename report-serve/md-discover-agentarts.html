修改说明

  1. 先发布平行稿：把 agentarts.md 放到与 HTML 同路径，并对爬虫开放（现网 404）。
  2. 在人读页声明：加上 rel="alternate" type="text/markdown"，地址用绝对 URL。
  3. 正文从本页生成：用 HTML 转化成 Markdown 产出机器稿，与人读页同一套事实。
  4. 可复用文档站约定：文档站同类页 已声明且 .md 返回 200，营销页可照同一写法。
  5. 不要和 llms.txt 混用：llms 是站点索引入口；本页声明的是「这一页的平行正文」。
