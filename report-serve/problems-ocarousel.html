轮播帧语义噪声 部分可抓 · 不宜入库

轮播帧语义噪声指 OCarousel / Banner 多帧运营位上的标题、摘要与图意——对人读是发现入口，对 RAG 则常混入活动招募与营销口号，不宜当作产品规格知识。 以 昇腾社区首页 为例：静态 HTML 中多帧 banner-title 已可抓（好于只渲染当前帧），但内容偏活动/认证引流，图意与规格未转写为可引用正文。

根因分析

轮播帧语义噪声的核心原因：多帧文案虽已写进网页源码，但运营/活动/招募口号与产品规格混在同一层，缺策展隔离，易被 RAG 当事实入库。

1. 运营帧当规格入库

问题：昇腾首页 6 帧轮播（问卷调查、创新大赛、实习生招募、开发者认证、CANN 社区任务、智能助手）的 banner-title 与副文案均在静态 HTML，Agent 能复述标题；但这些是活动引流与认证入口，不是 CANN / 算子 API 规格。问「哪一帧和算子开发最相关、应去哪一页文档」时，易把认证口号答成产品能力，或给不出文档深链。

修改建议

轮播根节点默认加 data-llm-exclude="true"，不入 llms / 知识库白名单；规格事实落到可引用文档页，轮播只做人读发现。

2. CTA 用 button 无 href

问题：各帧 CTA（立即查看 / 了解更多 / 前往认证 / 操作指导等）源码多为 button，无稳定 href；跳转靠脚本。探针问「点进去应该去哪一页」时，只能复述按钮文案，无法跟链到官方文档或活动落地页。

修改建议

跳转型 CTA 改为 a[href] + 可见锚文本；或在轮播旁提供「本页推广入口」文本清单（标题 → URL），不依赖滑动与点击。

3. 图意未转写

问题：Banner 配图承载口号与视觉信息，源码无 alt / figcaption；多帧图意无法转写为可检索、可引用的文本 chunk，入库后只剩标题口号。

修改建议

信息型帧补有区分度的 alt 或帧下短说明；纯装饰背景图用 alt="" / aria-hidden，关键图意用正文复述。

4. 缺帧角色区分

问题：6 帧 indicator 与标题在 HTML 平铺，抓取管道无法区分「活动/招募帧」与「产品入口帧」；一律入库即噪声，且无法回答「这一帧是什么 / 不是什么」。

修改建议

信息帧须备一句话事实摘要（说明边界）；策展管道按帧类型分流——活动帧丢弃，仅白名单产品入口帧保留「标题 + 摘要 + href」三要素。
