图片热区 完全丢失

图片热区指通过 <img usemap> 与 <area href> 将跳转目标绑定在坐标上的导航方式——对人类是「点图跳转」，对默认 RAG 是藏在像素坐标里的链接。 以 什么是 Ascend C 为例：全页 28 个热区若不冗余为文本链接列表，跳转语义将无法进入知识库。

问题实测

1. 向模型提问

我在看 什么是 Ascend C（CANN 9.0.0），想入门算子开发的话，成长地图里的学习顺序是怎么安排的？环境准备和 HelloWorld 分别在什么阶段？

2. 大模型回答

查看大模型回答内容

3. 问题洞察

大模型的回答指向两点结论：

  • 热区链接未入库：成长地图 14 个热区、全页 28 个——map / area 完全不出现在 chunk 中。
  • 跳转目标不可检索：问「成长地图学习顺序」「环境准备在第几阶段」时，知识库无对应链接 chunk——热区对人类可点，对 RAG 不可见。

须与 图片图意 转写配合，链接冗余不能代替图里的阶段语义。

根因分析

图片热区丢失的核心原因是：热区无文本清单、area 缺标签、坐标链接不可检索。

1. 热区无文本清单

跳转目标只存在于图片坐标里，默认管道不产出链接 chunk。

修改建议

补充可见的文本链接清单，覆盖全部热区目标。

2. area 缺可读标签

多数热区仅有坐标与裸 href，裸文件名对向量检索几乎无意义。

修改建议

为每个 area 补充 alt / title 与描述性锚文本。

3. 锚文本不规范

链接文字不含阶段名 / 文档名，站外目标未标注来源。

修改建议

锚文本须描述跳转用途，外链附完整域名（见 链接语义）。

4. 与图意转写脱节

热区恢复链接但不转写图意，仍无法回答「分几阶段」类问题。

修改建议

同步落地 图片信息转文字 与热区文本清单。

    大模型

    成长地图一般会按阶段组织 Ascend C 学习路径，环境准备通常在靠前阶段，HelloWorld 在入门实践阶段。

    但这些信息如果只存在于图片热区坐标里、没有对应的文本链接清单，我读不到可检索的热区跳转目标，只能根据正文零散描述猜测顺序，难以准确回答「第几阶段、前后依赖是什么」。
