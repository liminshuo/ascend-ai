# 算子开发者认证（入门级）

> 本认证涵盖算子开发的多个场景，综合考察学员对昇腾AI处理器架构、自定义算子开发与测试调优、kernel编程、模型迁移的理解，以及算子模板库、性能分析工具的应用。

## 认证概要
- 适用对象：对算子开发感兴趣的伙伴、企业客户、高校师生和个人开发者
- 认证目标：综合考察昇腾 AI 处理器架构、自定义算子开发与调优、Kernel 编程、模型迁移及模板库与性能分析工具的应用能力
- 认证级别：入门级
- 考试形式：在线考试（仅电脑端）
- 考试时长：100 分钟
- 通过条件：考试总分达到 60 分及以上
- 考试条件：完成实名认证后参加考试
- 证书有效期：2 年
- 关联产品：CANN · Ascend C
- 认证价值：验证学员在昇腾算子开发、模型迁移与性能优化方面的综合知识和应用能力；定位为 CANN 开源开放推荐认证

## 认证内容

### 昇腾AI处理器架构（考试占比：14%）
1. 昇腾AI处理器组件功能
2. 分离耦合架构区别与优势
3. CANN五层体系功能
4. 控制单元与同步机制
5. HCCL定义与核心价值
6. 软硬件同步机制原理与实现

### 存储与计算单元功能（考试占比：10%）
1. 计算单元分工与协作机制
2. MTE数据流向与多级缓存
3. Queue同步与内存管理
4. 计算、存储与搬运单元的分工与协作
5. Tile层数据搬运与计算流水编排

### 并行计算与Kernel编程（考试占比：13%）
1. BlockDim取值与优化策略
2. SPMD并行原理与block_idx应用
3. 核函数定义与调用方法
4. 经典并行和通用调优策略应用

### 模板库基本概念（考试占比：13%）
1. 模板库基本概念与5层架构
2. CATLASS定位、价值与应用场景
3. 模板库支持的数据类型与分层Block复用

### 自定义算子开发（考试占比：10%）
1. Vector/Cube编程范式
2. 自定义算子开发与接入注册
3. MIX算子代码框架与实现
4. GEMV AIV/AIC实现差异与方案要点

### 性能分析工具使用与性能评估（考试占比：10%）
1. 仿真分析波形解读与缺陷识别
2. msprof性能分析工具使用
3. 可视化定性识别瓶颈与性能指标量化评估

### 模型迁移、适配与精度调试（考试占比：10%）
1. 模型迁移优势与挑战
2. 模型迁移分析可行性评估
3. 自动、工具、手工迁移的选择与应用
4. 模型迁移适配及环境部署

### GEMM类算子实现与优化（考试占比：10%）
1. GEMM通用分块计算方案
2. 双缓冲与Swizzle排布优化
3. 数据格式与Padding对齐优化

### 算子性能调优（考试占比：10%）
1. 自定义算子优化策略（数据搬运、内存、API）
2. Cube与Vector核架构
3. 4种映射策略的优化逻辑与访存影响

## 考试说明

### 考试规则
1. 考试仅支持电脑端操作
2. 考试期间严禁使用 AI 工具辅助作答

### 证书获取与查询
1. 考试及实名认证通过后 24 小时，可前往个人中心-我的证书-开发者认证证书查看或下载电子证书
2. 证书自颁布之日起 2 年内有效
3. 开发者认证证书支持在社区公开查询，可前往[人才认证-证书查询](https://www.hiascend.com/edu/certification/query)页面使用证书编号进行查询

元素拆解

对照上方完整示例按块填写。链接须为 https 绝对地址，并直达具体资源正文；无内容的块整节省略，勿保留空标题。名称以官网正式用语为准，全文保持一致。认证内容与考查要点必须写成文字，勿只依赖截图。

1. 文首 Frontmatter（必填）

  1. 说明：标识本认证，并与人读详情页对齐；区分内容更新与模板结构版本。
  2. 写法：置于文件最上方，以 --- 包裹；键名固定，勿增删。字符串值统一加双引号，便于 YAML 解析。
  3. title：认证名称，与正文一级标题完全一致。
  4. type：固定为 "developer-certification"。
  5. schema_version：模板结构版本，当前固定 "1.1"；模板字段升级时由规范更新，业务侧勿改。
  6. id：人读页 URL 末段 ID。
  7. url：人读详情页绝对地址。
  8. updated：内容最后更新日期 "YYYY-MM-DD"（非首次发布日）；暂无则上线时填写。

2. 标题与摘要（必填）

  1. 说明：认证正式名称，以及一两句介绍（考什么、覆盖哪些能力）。
  2. 写法：一级标题 # 认证名，须与 Frontmatter title 完全一致；下一行以 > 写摘要，对齐人读页简介。

3. 认证概要（必填）

  1. 说明：面向认证选择与备考问答的基础信息，对应人读页认证概要区域；勿写入「认证内容」。
  2. 写法：二级标题 ## 认证概要；下列 - 字段名：内容，一行一项。官方未公布的信息不填写，不得将未知信息推断为无要求或无限制。
  3. 适用对象：明确适合参加认证的人群及能力背景。
  4. 认证目标：描述本认证主要考查的综合知识与应用能力。
  5. 认证级别：与官方认证名称及人读页保持一致，如 入门级、中级、高级。
  6. 考试形式：如 在线考试（仅电脑端）；仅填写官方明确公布的信息。
  7. 考试时长：正式考试作答时长，勿与备考学习时长混淆。
  8. 通过条件：明确考试通过分数或其他官方通过要求（如 考试总分达到 60 分及以上），不得自行推断；考试通过与证书领取条件须区分开写。
  9. 考试条件：如实名认证等参加考试的前置条件；官方未公布则省略本行。
  10. 证书有效期：证书自颁布之日起的有效期限（概要供快速取数；操作细节见考试说明）。
  11. 关联产品：如 CANN · Ascend C。
  12. 认证价值：说明认证所验证的能力及应用价值；可附官方定位，避免无法验证的宣传性描述；勿写价格、领券 / 兑换等运营文案。

4. 认证内容（必填）

  1. 说明：明确考试覆盖的知识领域、考查要点及各领域占比，帮助 Agent 回答「考什么 / 重点考什么」；领域标题即主题索引，不必再单列「知识点」。须写成文字，勿只贴截图。
  2. 写法：二级标题 ## 认证内容；各领域用三级标题 ### 领域名称（考试占比：N%）；领域下用编号列表列出考查要点。
  3. 知识领域：按官方考试大纲领域名称填写，不自行合并、拆分或调整。
  4. 考查要点：依据官方考试大纲填写；不得自行推测、扩展或改写为超出官方范围的内容。官方未公布具体要点时，不得编造。
  5. 考试占比：与官方公布一致；所有领域占比之和必须为 100%。占比表示领域权重，不代表固定题目数量，不得据此推算题数。

5. 在线学习（条件必填）

  1. 说明：官方推荐的备考课程与案例，是回答「备什么 / 优先学什么」的主入口。勿另写短「预备知识」列表冒充门槛。
  2. 写法：二级标题 ## 在线学习；按类型用三级标题组织，如 ### 推荐课程、### 推荐案例。每项先写资源链接，下挂 资源说明；可选填写 关联考查领域。
  3. 资源名称：与人读页推荐资源卡片名称保持一致（可含「课程1：」等前缀）。
  4. 资源说明：一句介绍主要学习内容或实践目标。
  5. 关联考查领域：可选；须依据资源实际教学内容映射到「认证内容」中的领域名称，不得仅凭课程名称推断。无法核对时省略本行。
  6. 类型与链接：类型须与真实内容一致；使用 HTTPS 绝对地址，直达具体资源正文。仅收录官方推荐或明确认可的备考资源。
  7. 缺省：无对应资源的子标题省略；无任何推荐资源时整节省略。

6. 考试说明（必填）

  1. 说明：描述考试参与规则与证书获取 / 查询，帮助 Agent 分别回答「如何参加考试」与「如何获得证书」。
  2. 写法：二级标题 ## 考试说明；下设 ### 考试规则、### 证书获取与查询。
  3. 考试规则：设备限制、考试环境、作答要求、禁止事项及其他官方规则。
  4. 证书获取与查询：实名认证要求、证书发放时间、电子证书下载方式、有效期及公开查询方式。考试通过不等于证书已发放，先后关系须写清。「证书查询」等入口保留 HTTPS 绝对链接。
  5. 缺省：无对应说明时省略子标题；官方未公布的规则不得自行推断。勿写领券 / 兑换等运营话术与客套收尾。

发布前核验

  1. 考试内容：领域、要点与官方大纲一致；占比之和为 100%，勿自增考查范围。
  2. 通过与出证：通过条件、考试限制、证书有效期及领取条件与官方一致。
  3. 备考资源：类型真实；关联考查领域有教学内容依据。
  4. 链接：HTTPS 绝对地址，直达正文（HTTP 200 ≠ 正文有效）。
  5. 一致与时效：与人读页名称、级别、内容一致；变更时更新 updated。
