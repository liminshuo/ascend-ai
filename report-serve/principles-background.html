设计背景

AI 亲和的含义

AI 亲和（AI-Friendly）是指让产品界面、代码结构和文字内容更容易被 AI Agent 稳定发现、完整读取并正确理解的一套设计原则。它不是单纯面向机器优化，而是在保障用户体验的基础上，让内容同时适合人和 Agent 使用。

简单来说，就像无障碍设计帮助不同用户获取信息，AI 亲和设计则通过清晰的结构、明确的语义和可读取的内容，帮助 Agent 更准确地获取和理解信息。

设计对象的转变

过去，网页主要面向人类用户设计。用户通过视觉层级、页面导航、交互反馈和文案提示理解内容，并完成相应操作。

随着生成式 AI 和 Agent 的发展，用户开始将信息检索、内容比较和任务执行交给 AI 助手。网页内容不仅供人阅读，也成为 Agent 检索、理解、引用和调用的信息来源。

因此，设计对象从单一的人类用户，扩展为人和 Agent。网页不仅要让人看得懂、用得顺，还需要让 Agent 能够稳定发现内容、准确读取信息并正确理解其含义。

AI 亲和的价值

AI 亲和设计有助于降低 Agent 获取和处理信息的成本，提高内容被准确理解、引用和复用的可能性。

通过明确的内容结构、统一的语义表达和稳定的访问方式，既能帮助 Agent 更可靠地完成信息检索与任务处理，也能提升用户查找、阅读和使用内容的效率。

与相关概念的关系

与 GEO 的关系

GEO（Generative Engine Optimization，生成式引擎优化）关注内容如何被生成式搜索系统发现、理解、引用和推荐。AI 亲和设计通过改善内容的可发现性、可读性和语义清晰度，为 GEO 提供基础支持，但不直接保证内容被引用或推荐。

与 RAG 的关系

RAG（Retrieval-Augmented Generation，检索增强生成）通过检索外部知识，为模型生成答案提供依据，广泛应用于智能客服、企业知识问答等场景。AI 亲和设计通过提升内容的可获取性、结构清晰度和语义准确性，为知识检索和后续生成提供更可靠的内容基础。
