页面元数据完整一致

概述

页面标题和正文能够表达主要内容，但文档版本、更新时间、内容类型及适用范围等信息，往往需要通过元数据进一步明确。

页面元数据完整一致原则旨在确保文档的关键属性能够被 AI Agent 直接获取，并与页面正文保持一致，帮助 AI Agent 准确识别文档身份、理解内容范围并判断其适用性。

具体原则

  1. 核心元数据应完整提供。根据页面类型，明确提供标题、版本号、更新时间、内容类型及适用产品等必要信息，避免关键属性缺失。
  2. 元数据应采用统一、可读取的结构。通过 Frontmatter、HTML meta 或其他明确的结构化字段表达元数据，使用清晰、稳定的字段名称和值，避免仅以图片、隐藏提示或非结构化文本承载关键信息。
  3. 元数据与页面正文应保持一致。确保标题、版本、日期、摘要和适用范围等信息与正文实际内容相符；内容更新时，同步更新相关元数据，避免信息冲突或过时。
  4. 元数据应与具体文档明确关联。每个页面的元数据应准确描述当前文档，避免多个页面共用不准确的属性，或因字段缺失导致文档身份和适用范围难以判断。

预期效果

  1. 帮助 AI Agent 准确识别文档标题、版本、类型和适用范围，降低文档识别错误。
  2. 提高元数据的可读取性与一致性，减少因字段缺失或信息冲突造成的误判。
  3. 支持 AI Agent 更准确地检索、筛选和引用文档，减少不适用内容被错误使用的风险。

注意事项

  1. 元数据字段应根据页面类型合理设置，不要求所有页面使用完全相同的字段集合。
  2. 页面可见信息与机器可读元数据应保持一致，不能只更新其中一处。
  3. Frontmatter、HTML meta 等是实现方式，不是原则本身；应以字段清晰、信息完整、内容一致为判断标准。
  4. 元数据用于补充和明确文档属性，不能替代正文中的必要说明、操作步骤和技术细节。
