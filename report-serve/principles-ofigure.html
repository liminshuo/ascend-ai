图片/视频的 AI 亲和实践

指导图片与视频在图意转写、内容组织和前端实现方面提升 AI 对视觉信息的识别能力。

实践目标

信息图 / 视频须提供alt、图注或正文转写，使图意可入库；装饰媒体可剥离。组件实践口径对齐图片亲和原则，语气与幻灯片实践页一致。

适用场景

场景1·信息图 / 教学视频适用

架构图、流程图、参数对照图、上手视频等承载规格或步骤：须非空 alt / figcaption / 邻近正文转写。
对应页面：CANN 文档插图、社区教程

场景2·纯装饰媒体按需处理

背景纹理、氛围插画、无信息图标：alt="" / aria-hidden，或 data-llm-exclude。

设计实践

实践要点

  • 图注位预留：信息图稿面预留 figcaption / 短说明；关键结论勿只烧进像素。
  • 角色标注：信息图 vs 装饰图在稿面分区，给研发 alt / exclude 分流。

正反示例

示例1. CANN 部署拓扑：图意可引用

✗ 错误示范 · 无图注 · 结论在图里

拓扑图（像素内写「Master→Worker」）

看起来有字，但字在图里；源码抠不到部署关系。

✓ 推荐做法 · 图 + 图注转写

要点：图注是独立文案层；架构关系可被抓取引用。

Markdown 书写

实践要点

  • 图意写进正文：插图后紧跟转写段落或列表，勿只写「如图所示」。
  • 视频补摘要：教学视频旁附步骤摘要 + 文档深链。

正反示例

示例1. 架构图：MD 转写

✓ 推荐做法 · 图注 + 正文转写

前端实现

实践要点

信息媒体：非空 alt 或 figcaption / 邻近转写须进首包；装饰媒体空 alt 或 exclude。

具体要求：

  • figure 语义：信息图用 figure + figcaption 或非空 alt。
  • 视频可发现：标题 / 摘要 / 文档链进 HTML；勿只嵌 iframe 无文案。
  • 装饰分流：装饰图 alt=""；信息图禁空 alt。

正反示例

示例1. 文档插图：figure + figcaption

✗ 当前问题 · 空 alt · 无图注

<img src="topo.png" alt="">

图意不可入库。

✓ 推荐做法 · 语义 figure

<figure>
  <img src="topo.png" alt="CANN 分布式训练拓扑：Master 调度 Worker">
  <figcaption>Master 调度 Worker；各 Worker 挂载 Ascend NPU。</figcaption>
</figure>

alt 与 figcaption 互补；静态抓取可读图意。

检查项

  • 图意可引用：信息图有 alt / 图注 / 正文转写之一。
  • 视频有摘要：教学视频旁有可读步骤或文档链。
  • 装饰可剥离：装饰媒体空 alt 或 exclude。
  • 首包可得：转写不依赖客户端 OCR。
