Part2. 优化建议

建议稿以现网平行 Markdown 全文为底。绿色只标改过的地方：标题层级、图片说明、代码语言、说明前缀和验收。

建议模板（可部署的平行 Markdown）

修改说明

  1. 绿色只标改过的字：标题层级、图片说明、代码语言、说明前缀、验收；其余按现网原文。
  2. 给截图补一句说明：图标和效果图不要空说明。对照 图片内容可转写。
  3. 每条体验路径末尾加验收：例如能看到侧边栏图标、能打开指定页面、能插入代码。
  4. 标题改成连续层级：现网用四级标题，建议改成二级 / 三级，方便顺着读。
  5. 给代码标明语言：Java 示例和提示词分开写。对照 代码块语义可读。
  6. 提示框加上可见文字前缀：如「说明：」，不要只靠图标。
  7. 已具备、继续保持：本页已声明平行 Markdown 和产品 llms，且都能打开。
