主路径不被推荐打断

为了帮助 Agent 连贯跟完主任务，推荐、广告、相关阅读不得插进步骤中间；次要内容须后置并标识，避免被当成规格或步骤正文。

适用对象

名称 说明 常见落点
主路径穿插 相关文章、推荐阅读不得插进安装步骤或主路径中间。 安装文档、教程正文
推荐区标识 推荐应收至页末并标为推荐，不得被当成规格或步骤正文。 页末相关阅读

适用场景

优先级 页面类型 说明
必做 安装文档、教程 / 排障正文 主路径步骤最易被推荐打断，须保持连续。
建议做 官网能力说明、产品详情 规格与能力进引用池时，推荐勿混进正文段。
可不做完整改造 纯营销落地页、活动页 无连续任务步骤时，收录策略中划界即可。

设计UI调整

调整建议

  • 推荐不穿插主路径 相关文章、推荐阅读统一放在页面末尾，不插进安装步骤或主路径。
  • 推荐区须可识别 主路径连续成段；推荐区须能识别为推荐，不得被当成规格正文。

文档内容调整

调整建议

  • 主路径步骤完整可跟 安装 / 配置步骤写完整、可连续跟完；推荐链接触达自描述，勿写进步骤编号序列。
  • 相关阅读勿伪装下一步 相关阅读标题勿用「下一步」「继续安装」等操作口吻；明确标为推荐或相关阅读。

前端调整

调整建议

  • 主路径与推荐分区 main 内区分主路径与推荐区块；推荐可用 aside 或 data-role="related" 标记。
  • 切片优先主路径 入库切片优先主路径正文；推荐区降权或单独元数据，避免噪声污染步骤 chunk。

调整示例

推荐区用 aside 与主路径分离
