评分与社会证明 视情况

查看测试页面

评分与社会证明指评分数字若作社会证明可抓；「我要评分」等操作文案入库可剥离。 视情况：作社会证明的评分数字须进首包；「我要评分」等操作 CTA 入库剥离。用户评分 ≠ 官方质量认证，认证说明应写在正文。 以 学习路径 为例：学习路径课程卡可见 5.0 星等评分；首包无 o-rate / 完整卡文案。

友商测试

友商案例被测对象html 可抓取原因
昇腾社区学习路径课程卡评分社会证明抓不全浏览器可见「大模型开发全流程中级」等课程卡上的 5.0 星评分、时长与报名人数，但首包无 o-rate / 完整卡文案（无「大模型开发全流程中级」「5.0」），课程卡靠脚本注入，禁 JS 抓不到可引用评分数字。

根因分析

视情况：作社会证明的评分数字须进首包；「我要评分」等操作 CTA 入库剥离。用户评分 ≠ 官方质量认证，认证说明应写在正文。

评分与社会证明的核心原因：人在浏览器里能看见学习路径课程卡上的 5.0 星评分，但「查看网页源代码」里没有 o-rate、也抠不出「5.0」——整张课程卡要等 JavaScript 注入才出现，所以爬虫和 AI 默认引用不了社会证明数字；即便分数可读，也不等于官方质量认证。

1. 源码里没有可引用的评分数字

问题：打开学习路径页，用「查看网页源代码」核对：找不到 o-rate，也搜不到课程卡上的「5.0」。浏览器里「大模型开发全流程中级」卡清楚写着星级，但数字要等脚本把课程卡画出来才出现——探针问平均评分时，禁 JS 给不出可证伪的社会证明数字。

证据 · 评分本来应该长这样

期望写进网页的课程卡评分（示意）

<article class="course-card">
  <h3>大模型开发全流程中级</h3>
  <p>中级课程主要介绍基于 MindSpeed-LLM…</p>
  <p class="rating" data-score="5.0">评分 5.0</p>
  <a href="…/course/…">进入课程</a>
</article>

标题、摘要、评分、链接同在首包，才可供引用。

修改建议

若评分作社会证明，页面一出来就把数字写进 HTML（如可读文本或 aria/SSR 的 rate 值）；纯交互打分控件可不入库，但展示用均分须进首包。

2. 整张课程卡靠注入，形成半成品

问题：不只是星星：卡标题、标签（CANN / HCCL / 大模型开发）、简介、时长与报名人数也都不在首包。Agent 或许能复述「学习路径 / 大模型开发专区」壳层文案，却列不出具体课程卡，更谈不上引用其评分——发现层半成品。

证据 · 壳层有、课程卡无

首包可抓 vs 卡内缺失

<!-- ✓ 壳层 -->
主题路径推荐 / 大模型开发专区 …
<!-- ✗ 卡内 -->
大模型开发全流程中级 · 5.0 · 10小时 · 662
<!-- 上述卡文案首包均不在 -->

能介绍专区，不等于课程卡与评分可发现。

修改建议

课程列表 SSR：每张卡输出标题 + 短述 + 评分（若展示）+ 落地 a[href]；勿只留 o-card-content 空壳等客户端填充。

3. 也没有备用清单，且易与官方认证混淆

问题：评分读不全时，如果 llms.txt 或课程说明 MD 里也没有「课程名 + 均分」平行清单，AI 没有退路。即便日后分数进了首包，「我要评分」仍是操作 CTA；用户均分只是社会证明，不能当成官方质量认证唯一依据。

修改建议

在 llms.txt 或平行 MD 临时列出课程名与展示用均分（若对外承诺可引用）；页面 SSR 达标后以页面为准。认证/等级说明写进正文，并过滤「我要评分」等操作文案。
