全站亲和 Checklist 领队

Skill ID：/geo-checklist-audit

这个 Skill 做什么

这是站点根领队。给一个站点根地址，只敲 /geo-checklist-audit：先做全站亲和 Checklist，看基础建设是否对 Agent 友好（可达 / 可读 / 可理解），也看模型回答里是否会提品牌、引用官网。能测的写证据，缺材料的标「未测」。

测完会接着带出 robots、sitemap、llms 三份建议稿，不必再敲分项斜杠。核验表和三份配置稿分开交付。只想改其中一项，目录里的分项仍可单独下载。输入是一页文档时，会先问你查全站还是只改这一页。

下载 Skill 查看示例报告

它怎么带其它 Skill

把它当作站点根入口：对话里只敲 /geo-checklist-audit，后面接站点地址。它会先做总检，再把需要改的基础配置拆成三份建议稿。下载本包就能完成这条流程，不用先装 robots / sitemap / llms 三个分项。

输入怎么接力输出
站点根，如 https://www.example.com/ 先跑 Checklist，再按包内说明分别处理 robots、sitemap、llms 一份核验表 + 三份可下载建议稿：robots.txt、sitemap 基线、llms.txt。报告分开交付
某一页文档地址 先确认是查全站，还是只改这一页 只改一页时，改走页级探针；不会在这里批量生成页面 Markdown

本包已经内置这些分项说明，会在总检后按需接上：

  1. 配置 robots.txt 许可声明 /robots-txt-audit
  2. 提供可发现的 sitemap 路径清单 /sitemap-audit
  3. 部署 llms.txt 索引目录 /llms-txt-generate

分项仍保留单独下载入口：只想改 robots.txt、只想看 sitemap，或只想生成 llms.txt，可以直接用对应 Skill。

如何触发

  1. 下载本领队包，放到 Agent 可读取的 skills 目录（如 .cursor/skills/geo-checklist-audit/）。包内已含 robots / sitemap / llms 说明，不必再下三份分项。
  2. 在对话中用 /geo-checklist-audit 唤起；斜杠后写站点根 URL。不要再敲分项斜杠。默认两块一起测：生成 10 题，并由当前模型答一版。没有根地址时，Agent 会先追问。
字段必填说明
斜杠命令是用 /geo-checklist-audit 明确唤起这个 Skill
站点根 URL是如 https://www.example.com/。测 A 时拉 robots / Sitemap / llms；测 B 时默认把该根域名（含 www 与裸域）当作官网引用，不必另填白名单
页面清单 可选
  • 默认按 Sitemap + llms 清单对每条 URL 发请求，不必另授权
  • 要求更高再补全站抓取 CSV（URL、状态码、标题），用来对照 Sitemap 覆盖缺口
固定测试题 可选
  • 默认：按站点生成 10 题。报告附录列出，并附可下载文件
  • 用户上传题表则用用户的题，同样放进附录和附件
模型答卷 可选
  • 默认：本对话当前模型按 10 题答一版，写入答卷附件，标明模型名
  • 样本要更全面时：用户提供「模型回答记录表」（模型名、题号、回答正文、检索 URL、引用 URL）
主推版本规则可选如路径含 /900/ 视为社区主推版
