Sitemap 路径清单语义化

sitemap.xml 概述

sitemap.xml 是用于列出网站公开 URL 的 XML 文件，为搜索引擎提供 URL 发现入口，帮助其发现网站中的公开页面。

基于 Google Sitemaps 协议（2005 年），常见入口为 https://{域名}/sitemap.xml，也可以使用 Sitemap 索引文件组织多份 Sitemap。文件地址可通过 robots.txt 的 Sitemap: 指令声明，并使用绝对 URL。

具体原则

  1. 提供可访问的 sitemap.xml 或 Sitemap 索引文件，并可通过 robots.txt 中的 Sitemap: 指令声明其地址。
  2. 仅收录希望搜索引擎发现的公开 URL，避免纳入后台页面、重复参数 URL 及与网站内容无关的临时页面。
  3. 保持 URL 语义清晰，路径尽量体现产品、文档、版本等内容信息，避免使用会话 ID 和无意义参数。
  4. 页面新增、删除或迁移后及时更新 Sitemap，避免清单中保留失效或已不存在的 URL。

机器如何发现 sitemap.xml

方式一：约定路径

网站通常可在根目录提供 /sitemap.xml 作为常见入口，搜索引擎可尝试访问该路径。

方式二：读 robots.txt

搜索引擎会读取 robots.txt 中的 Sitemap: 指令，获取 Sitemap 或 Sitemap 索引地址。

预期效果

  1. 帮助搜索引擎更高效地发现网站公开 URL，减少新增或深层页面因缺少发现入口而被遗漏。
  2. 与 llms.txt 分工：Sitemap 提供公开 URL 发现入口，llms.txt 提供知识内容索引和理解入口。

注意事项

  1. Sitemap 用于提供公开 URL 的发现线索，不代表页面一定会被搜索引擎抓取或索引。
  2. 收录范围应与页面实际公开状态保持一致，避免列入后台、受限或不应公开的页面。
  3. lastmod 应反映 Sitemap 或页面的实际更新时间，避免填写不准确的时间信息。
