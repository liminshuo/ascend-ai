列表底部分页深页可爬

表格或卡片列表下方的分页若翻出公开知识深页，页码须为带 query 的真实 a[href]（如 ?page=2）；禁纯 button/onClick。后台表格分页见下方场景判断。

场景判断

场景1·公开列表底部分页要做亲和

挂在表格、卡片列表、文章列表等下方，用来切第 2、3… 页；深页承载公开可引用内容。
页码须为真实 a[href]（带稳定 query，如 ?page=2），静态抓取可跟到深页；可辅以 rel=next / sitemap 覆盖。
对应页面：官方技术文章

场景2·后台 / 登录后表格分页不做亲和 · 入库剥离

控制台、个人中心等登录后表格的翻页，指向非公开操作数据。入库管道宜标 data-llm-exclude 或直接剥离，别当可引用文档。

设计UI调整

无

文档内容调整 · 场景1

调整建议

  • sitemap / llms 收录深页：列表第 2、3… 页的稳定 URL 须进 sitemap 或 llms.txt，不单靠翻页控件才能发现深页内容。
  • 关键条目可平行清单：技术文章、案例卡等公开列表可在 Markdown / llms 平铺「标题 + 链接」；即使分页 HTML 未抓全，也能枚举条目。
  • 过渡补位：页码尚无真实 URL 前，用 llms / sitemap 临时补全量条目或深页地址；分页达标后以页面为准，去掉重复维护。

调整示例

示例1. 技术文章列表：深页平行轨

✗ 当前问题 · 只有第 1 页，深页未进清单

【HTML】技术文章列表可见第 1 页卡片 + 翻页控件
【缺失】sitemap / llms 无 ?page=2、?page=3 及深页文章链接

✓ 推荐做法 · sitemap 收录深页 URL

# sitemap（节选）
https://www.hiascend.com/developer/techArticles
https://www.hiascend.com/developer/techArticles?page=2
https://www.hiascend.com/developer/techArticles?page=3

✓ 推荐做法 · llms 临时补条目 / 深页

# llms.txt（过渡）
- [技术文章第 2 页](https://www.hiascend.com/developer/techArticles?page=2)
- [某篇文章标题](https://www.hiascend.com/developer/techArticles/…)
- [另一篇文章标题](https://www.hiascend.com/developer/techArticles/…)

分页控件输出真实 a[href] 且深页可跟后，llms 中重复深页项可移除。

前端调整 · 场景1

调整建议

公开列表底部分页的页码须在首包 HTML 输出为带稳定 query 的真实 a[href]；静态抓取（不执行 JS）仍能跟到第 2、3… 页（对标常见文档/博客列表分页）。

具体要求：

  • 页码为真实 a[href]：每一页码（及上一页 / 下一页）须为带地址的 a 标签；禁纯 button / onClick 翻页导致深页无官方 URL。
  • query 稳定可复用：深页地址宜用稳定参数（如 ?page=2），同一页多次打开结果一致，便于 sitemap 与引用。
  • 可用 rel=next 辅助：可在 link[rel=next] / rel=prev 标明相邻页，辅助机器发现；不能替代页码上的真实 a[href]。

调整示例

示例1. 技术文章列表底部分页

✗ 当前问题 · 页码是 button，无深页 URL

<div class="o-pagination">
  <button>1</button>
  <button>2</button>
  <button>3</button>
  <button>下一页</button>
</div>
<!-- 浏览器可翻页；静态 HTML 无 ?page=2 可跟链 -->

翻页只靠 button/脚本，静态抓取给不出第 2、3 页官方 URL，深页内容不可达。

✓ 推荐做法 · 页码 a[href] + 稳定 query

<nav class="o-pagination" aria-label="分页">
  <a href="/developer/techArticles?page=1" aria-current="page">1</a>
  <a href="/developer/techArticles?page=2">2</a>
  <a href="/developer/techArticles?page=3">3</a>
  <a href="/developer/techArticles?page=2" rel="next">下一页</a>
</nav>

页码均为真实 a[href]；静态抓取即可回答「第 2、3 页官方 URL 是什么」。
