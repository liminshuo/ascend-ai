Ascend 社区（html）分析 · 可引用性·内容（html）分析

本栏对着昇腾自己的页：大模型抓 HTML 时，正文在不在源码、缺到什么程度、站外空壳怎么处理。 下面先列当前问题，再给可执行建议。案例取自可达性表中市场营销 / 知识 / 生态的典型「部分」「缺失」行。

实施建议

  • 缺失页优先补 SSR：如 CCAE、HiDevLab 空壳，curl 几乎无产品说明。先把定位与要点写进 HTML，再谈入库。
  • 部分页区分「壳」与「规格」：首页、集群、下载中心常有导航/定位可抓，规格表或包列表仍偏动态——补表格 SSR，或链到可抓文档。
  • 知识壳 ≠ 知识正文：/developer 只有入口卡与短述；可引用内容在 FAQ 等叶子。壳做人读，叶子保可抓。
  • 站外单独策展：教育站、HiDevLab 不在 www 尺子里。社区侧留真链接 + 摘要，或明确「AI 不引用该壳」。
  • 改造优先级：知识叶子（FAQ）与缺失产品页（CCAE）优先于再堆营销首页口号。对照友商：NVIDIA 产品说明页常「完整 + 真链接」。
