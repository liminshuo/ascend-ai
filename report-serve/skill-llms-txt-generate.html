Skill ID：/llms-txt-generate

这个 Skill 做什么

这是一份用于检查与优化 llms.txt 的 Skill 说明。它适合在站点需要面向大模型 / Agent 提供精选知识入口时使用：先诊断现有入口与候选页面，再输出报告，并给出一份建议版 llms.txt。依据见部署 llms.txt 索引目录。

  1. 诊断：检查 /llms.txt 入口是否可发现，现有精选是否合理。
  2. 报告：生成独立 HTML 报告，说明当前入口、筛选依据与数据缺口；顶栏可导出 PDF，没有站点侧栏。
  3. 优化稿：在报告中附建议版 llms.txt，顶栏可单独下载。
下载 Skill 查看示例报告

如何触发

  1. 下载 Skill 包，放到 Agent 可读取的 skills 目录（如 .cursor/skills/llms-txt-generate/）。
  2. 在对话中用 /llms-txt-generate 唤起；斜杠后写站点根 URL。没有地址时，Agent 会先追问。Sitemap 由 Skill 从 robots 或 /sitemap.xml 发现，不必另交。
字段必填说明
斜杠命令是用 /llms-txt-generate 明确唤起这个 Skill
站点根 URL是如 https://www.huaweicloud.com/
抓取表 CSV可选有则精选更准。不交也能跑，改用 Sitemap 弱输入，报告会标明质量受限
