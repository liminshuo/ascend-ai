下拉子链首包缺失 子项须进源码

查看测试页面

下拉子链首包缺失指下拉菜单内导航项须在首包 HTML 可读；勿悬停/点击/JSON 注入才挂载子链，否则发现层断裂。 以 集群产品页 为例：标题旁「更多产品」下拉：浏览器可展开同品类机型，首包仅触发器、无 panel 内 a[href]。

问题实测

1. 向模型提问

我在看 集群产品页，标题旁「更多产品」下拉里各款集群/超节点（如 Atlas 900 A2 PoD 集群基础单元、Atlas 900 SuperCluster AI 集群等）对应的落地页 URL 分别是什么？

根因分析

下拉子链首包缺失的核心原因：人在浏览器里点开「更多产品」能看见同品类机型清单，但「查看网页源代码」里只有触发器文案，没有各子项 a[href]——要等点击或悬停才挂出来，所以爬虫和 AI 默认列不全落地 URL。

1. 下拉子链没有写进网页源码

问题：打开集群产品页，用「查看网页源代码」核对：标题旁只有「更多产品」触发器（more-production），看不到 Atlas 900 A2 PoD / SuperCluster AI 集群等子项的 a[href]。浏览器展开后能点，但要等脚本挂载——禁 JS 时答不出探针要的同品类落地 URL。友商 Mintlify Products mega menu、NVIDIA developer Resources 下拉也是触发器在、子项后挂，同类问题。

证据 · 下拉子链本来应该长这样

期望写进网页的「更多产品」面板（示意）

<div class="more-products-panel">
  <a href="/hardware/cluster?tag=900">Atlas 900 A2 PoD 集群基础单元</a>
  <a href="/hardware/cluster?tag=900ai">Atlas 900 SuperCluster AI 集群</a>
  …
</div>

子项可以默认隐藏，但链接必须还在首包里。

修改建议

SSR 输出完整下拉子项：每项可读机型名 + 真实 href；视觉可折叠，DOM 须保留 a 节点。

2. 触发器在、清单不在，形成半成品

问题：当前机型标题（如 Atlas 900 A3 SuperPoD）和「更多产品」文案已经写进首包，人知道这是产品切换入口；缺的是面板里的同品类 URL 清单。所以 Agent 可能答得出「这一页是某款超节点」，却答不出「更多产品里还有哪些机型、链到哪」——发现入口和可跟清单不同步。Mintlify 悬停才挂 panel、NVIDIA 从 header-secondary.json fetch 再挂，同属半成品发现层。

证据 · 半成品对照

实测：触发器 ✓ · 子项 ✗

<!-- ✓ --> <span class="more-production">更多产品</span>
<!-- ✗ --> <!-- 无 Atlas 900 A2 PoD / SuperCluster… 的 a[href] 列表 -->

有触发器不等于下拉可达；两边要一起进源码。

修改建议

触发器与子项同批 SSR；勿只输出「更多产品」文案，而把机型列表留给点击后注入。

3. 也没有备用的同品类产品清单

问题：页内下拉读不到时，如果 llms.txt 或产品目录页也没有按「集群 / 超节点」列出各机型官方 URL，AI 就只剩当前这一款标题，没有退路补齐同品类发现层。

修改建议

在 llms.txt 或产品索引页临时平铺同品类机型（名称 + URL）；页面下拉 SSR 达标后以页面为准。
