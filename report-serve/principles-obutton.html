跳转型按钮链接可发现

社区首页首屏 CTA（立即查看 / 了解更多等）须用可抓 a[href]；纯提交/关闭类 button 管道宜剥离（对标 Mintlify hero、NVIDIA en-sg 首屏 CTA）。

场景判断

场景1·跳转型 CTA要做亲和

点击后跳到另一页面或详情（如「立即查看 / 了解更多 / 前往认证」）。外观可仍是按钮，底层须为真实 a[href] + 可见文案，静态抓取能给出官方落地 URL。
对应页面：社区首页

场景2·纯操作按钮不做亲和 · 入库剥离

只在当前页做动作（提交 / 关闭 / 确认 / 我知道了），不承载站点入口。入库管道宜标 data-llm-exclude 或剥离，别把操作文案当可引用结论。

设计UI调整 · 场景1

调整建议

  • 跳转 CTA 文案宜自描述：尽量写清去向（如「查看大赛详情 / 前往认证」）；若须保留「了解更多」，稿面旁注落地页名，勿只交无目标的泛词按钮。
  • 外观可按钮、交付按链接：视觉可保留 o-btn 样式；稿面按可点链接标注目标 URL，勿做成「点了才知道去哪、实现常交成无 href 的 button」。

要点：文案尽量自描述；外观可按钮，交付按真实可点链接（实现上须首包 a[href]）。

文档内容调整 · 场景1

调整建议

  • 统一命名：CTA 文案、活动/认证落地页 title 与 llms 条目对齐；「了解更多」若保留，清单里须写成可区分的对象名 + URL。
  • CTA 落地平行清单：在 llms.txt 或活动文档 MD 中平铺首屏各跳转 CTA 的标题 + 官方 URL；规则摘要写在可引用正文，勿只出现在点 CTA 后的弹层。
  • 过渡补位：HTML 仍为 button 伪链时，用 llms / 活动页临时补落地 URL；SSR a[href] 达标后以页面为准，重复项可移除。

跳转 CTA 改为首包 a[href] 后，llms 中重复项可移除。

前端调整 · 场景1

调整建议

跳转型 CTA 须写入首包 HTML 为真实 a[href]；静态抓取（不执行 JS）仍能读出文案并跟到官方落地页（对标：Mintlify Get started、NVIDIA en-sg Read Blog）。纯操作按钮见场景2，管道剥离。

具体要求：

  • 跳转 CTA 须为真实链接：立即查看 / 了解更多 / 前往认证等须为 a[href] + 可见文案；勿用无 href 的 button.o-btn.banner-actions-item 冒充。
  • 样式可按钮、语义须链接：可保留 o-btn 外观，底层仍输出 href；勿只靠点击后 JS 跳转。
  • 规则勿只藏弹层：活动规则、认证须知等若 CTA 点开才出，须在旁侧正文 duplicate，或改为链到已 SSR 的详情页。
  • 纯操作 button 标注排除：提交 / 关闭 / 我知道了等加 data-llm-exclude，入库勿当正文 chunk。

调整示例

示例1. 社区首页 banner CTA

✗ 当前问题 · button 无 href

<p class="banner-title">HCCL通信库创新大赛</p>
<button type="button" class="o-btn o-btn-primary banner-actions-item">立即查看</button>
<button type="button" class="o-btn banner-actions-item">了解更多</button>

文案在，href 不在；静态抓取只能复述「立即查看 / 了解更多」，给不出官方落地 URL。

✓ 推荐做法 · SSR 跳转 CTA 链接化

<p class="banner-title">HCCL通信库创新大赛</p>
<a class="o-btn o-btn-primary banner-actions-item" href="/activity/hccl-contest">查看大赛详情</a>
<a class="o-btn banner-actions-item" href="/developer/cert">前往开发者认证</a>

外观仍可是按钮类名，底层写成 a[href]；静态抓取即可跟链。
