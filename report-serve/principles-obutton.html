跳转型按钮链接可发现

社区首页首屏 CTA（立即查看 / 了解更多等）须用可抓 a[href]；纯提交/关闭类 button 管道宜剥离（对标 Mintlify hero、NVIDIA build 列表 CTA）。 找的到 · 社区 UI · 以 社区首页 为例 · 对应 问题实测 · 按钮与链接角色混淆。

为什么按钮是「视情况」——先分清按钮的两种角色

跳转按钮（点击跳到另一个页面）要做亲和

如「立即查看 / 了解更多 / 前往认证」。它承诺「点了会去哪」，须做亲和：底层用可抓的 a[href]，样式仍可保留按钮外观，让 Agent 能给出官方落地 URL。

操作按钮（只在当前页做动作）不做亲和 · 入库剥离

如「提交 / 关闭 / 确认 / 我知道了」。它不是正文知识，入库管道宜标 data-llm-exclude 或剥离，避免文案被 Agent 误当成可引用结论。

设计UI调整

无

文档内容调整

调整建议

  • MD / llms 补 CTA 落地页：HTML 仍用 button 伪链时，llms.txt 或活动文档页须列出「立即查看 / 了解更多」等 CTA 对应官方 URL；达标后以 SSR a[href] 为准。
  • 活动规则勿只放弹层：认证须知、问卷规则等关键说明写在可引用正文或详情页 MD，勿只出现在点击 CTA 后的 dialog。

前端调整

调整建议

  • 跳转型 CTA 须 a[href]：社区首页 banner「立即查看 / 了解更多 / 立即填写 / 前往认证 / 立即参与」等须为 OLink 或 a[href] + 可见文案；禁 button.o-btn.banner-actions-item 无 href（友商 Mintlify Get started、NVIDIA More Models 首包可跟）。
  • 样式可按钮、语义须链接：保留 o-btn 外观时底层仍输出 href；或 button 旁并列隐藏/可见 a[href] 供爬虫跟链。
  • 纯操作 button 标注排除：提交 / 关闭 / 我知道了等无导航语义的 button 加 data-llm-exclude，入库管道勿当正文 chunk。
