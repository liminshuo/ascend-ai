Markdown 正文可发现

Skill ID：md-discoverability · 依据：Markdown 正文可直取 · 全量原则 #7 · 成对：html-to-md（生成 MD）

核心命题

核验人读页是否声明平行 Markdown（rel="alternate" type="text/markdown" 等），以及对应 .md 是否可达。与 html-to-md 成对：一个产 MD，一个验发现。不负责转换正文。

下载 Skill 查看示例报告

输入

字段必填说明
人读页 URL是（主）如 https://agentorchard.huaweicloud.com/agentarts.html
预期 .md URL可选缺则从 alternate 解析，或同路径改 .md 作候选
站点根可选拼相对 href

工作流

  1. 拉取人读页：解析 alternate / 等价 markdown 声明。
  2. 可达核验：声明 URL + 候选路径；记状态码与 Content-Type。
  3. 轻量正文信号（可选）：非空、含 # 标题。
  4. 输出报告：Part1 现状 + Part2 补声明建议；导出 PDF；双写。

边界

  1. 不把 HTML 转成 MD → 用 html-to-md。
  2. 不深审 robots / sitemap / llms 全文。
  3. 不编造不存在的 link 标签。

如何使用

  1. 下载 Skill 包，解压到 .cursor/skills/md-discoverability/（或个人 skills 目录）。
  2. 准备人读页 URL；可选给出预期 .md 地址。
  3. 在对话中调用，例如：按 md-discoverability 核验 https://agentorchard.huaweicloud.com/agentarts.html。
  4. 对照示例：智果 AgentArts · Markdown 可发现。
