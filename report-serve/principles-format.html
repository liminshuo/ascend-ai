双轨同源可消费

为了帮助 Agent 以最快路径读到可入库正文，人类页与机器源须同源双发：HTML 供人浏览，Markdown / 纯净正文供机器直读，并在页面提供可见的机器可读入口。归在「可达」：解决进站用哪条轨；同源约束会贯穿后续阶段。

适用对象

名称 说明
HTML 渲染页（人类浏览轨） 由同源内容渲染的文档页面（如 .html），供人类阅读。
Markdown / 纯净正文（机器读取轨） 由同一来源导出的结构化纯文本（如 /doc_center/source/），须保证可直接访问，且不被鉴权拦截。
机器可读入口 人类浏览页上明确指向对应 Markdown / 纯净正文的可见文字链接。严禁仅靠图标暗示或隐藏操作。

适用场景

优先级 页面类型 说明
必做 文档站正文页、手册 / 教程页 Agent 核心事实来源，须提供同源 Markdown 或纯净正文直连。
建议做 官网产品 / 规格详情页 视觉化元素多，须配平行 MD 或语义化结构的 HTML 表格源。
可不做完整改造 纯营销落地页、无实质正文活动页 须在收录策略（如 robots.txt）中明确划界；严禁强行挂载机器源误导 Agent。

设计UI调整

调整建议

  • 文档页级 Markdown 入口 文档页头必须提供可见的「打开 / 复制 Markdown」入口，文案须写清具体动作；严禁仅用仓库源码链替代。若整站 llms.txt 已收录稳定的本页 .md 直链，可免重复堆按钮。
  • 内容块平行 MD 架构图、规格表等强视觉块必须配备平行 Markdown；标题旁轻量 MD 徽标仅作快捷入口，严禁替代正文。若首包已包含完整可抓取的语义化 HTML 表，徽标可省略。
  • 入口默认可见 机器可读入口必须为可见文字或明确动作控件；严禁仅用无字图标暗示存在 Markdown 版本。

文档内容调整

调整建议

  • 同源同文 Markdown / 纯净正文与 HTML 渲染页必须由同一来源导出；严禁给人看一套、给机器看另一套，或按 UA 动态换皮。

前端调整

调整建议

  • Markdown 源对外可访问 机器源路径（如 /doc_center/source/）必须可直接访问与下载，严禁鉴权拦截；并同步放行 robots.txt 与收录进 llms.txt。
  • 两轨一致性校验 构建流程必须对比 Markdown 与生成 HTML 的事实正文，发现渲染层单独改写导致的不一致，须阻断发布。frontmatter（版本、日期、状态）与 HTML <head> / JSON-LD 必须由管道同步，严禁人工双向维护。
  • 入口须为可跟链 页内机器可读入口必须为带真实地址的 <a href> 或可复制的稳定 .md URL；首包即须输出，严禁仅靠客户端注入。
