多语言与本地化锚点

多语言站须用 hreflang / canonical 标明语言与默认版，使 Agent 进入任务对应的语言与地区页面，术语跨语言一致。 可达 · 对应全量表 相关条目。

设计 UI 调整

  • 语言切换入口文案写清语言名（中文 / English），当前位置可识别。
  • 单语言站可在页脚或元信息标明语言，避免误导为多语言枢纽。

文档内容调整

  • 同一概念在中英文版用语对齐；建立多语言术语表。
  • 翻译页保留与源页对等的章节结构，便于跨语言锚点。

前端调整

  • 输出 link rel="alternate" hreflang 与 x-default；canonical 各自指向本页。
  • URL 或路径稳定区分 locale；禁止所有语言 canonical 拧到单一中文页。
