检索阶段

检索阶段指三模型联网问答中为回答当前问题而访问的 URL 池（非知识库 chunk 召回）。 本页统计该池中昇腾社区（hiascend.com）官方 URL 占比。

问题实测

1. 向模型提问

我想基于官方资料了解一下 Ascend C 算子开发，能介绍一下吗？

2. 大模型回答

Claude AI · DeepSeek · 千问

4. 问题洞察

  • 社区官方占比偏低：Claude 21%、DeepSeek 33% 均未过半；千问界面未显示检索链接。
  • 非社区信源占主导：Claude 第三方 79%；DeepSeek 华为系其他渠道 56%——与「基于官方资料」约束错位。

根因分析

官方占比低的核心原因是：机器入口不清、第三方排序占优、官方渠道分散、版本信号缺失。

1. 机器入口不清

无 llms.txt，/doc_center/ 被 robots 屏蔽，sitemap 只引导渲染页（详见 机器发现层缺失）。

修改建议

部署 llms.txt，放行并优先声明 /doc_center/source/，让 Agent 默认抓社区机器源。

2. 第三方排序占优

Claude 检索池中第三方教程占 79%；Prompt 的「官方资料」约束无法直接过滤检索 URL。

修改建议

双轨交付官方 Markdown / 源 HTML，提高官方内容的可索引性与排序权重（详见 格式交付）。

3. 官方渠道分散

DeepSeek 拉取华为开发者 30%、华为云博客 26%；Agent 容易把「华为官方」泛化为社区官方。

修改建议

将 hiascend.com 声明为 canonical 入口，并用 source_channel 区分社区官方与华为系其他渠道。

4. 版本信号缺失

检索结果多为 8.x、8.5 alpha、9.1 beta，未见 CANN 9.0 社区版（详见 版本滞后）。

修改建议

在 sitemap / llms.txt 中声明主推版本 900，并用页级 version 字段做默认过滤。
