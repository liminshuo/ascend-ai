## Ascend C 是什么

- CANN 算子开发编程语言，原生支持 C/C++
- 五层 API：语言扩展层 → 基础 API → 高阶 API → 算子模板库 → PyAsc
- 支持 Atlas A2/A3、Atlas 350 等

## 学习路径（IA）

```
概念原理 → 编程模型 → SIMD/SIMT
API 参考 → 基础/高阶 API
算子实践 → 矢量/矩阵/融合算子
```
