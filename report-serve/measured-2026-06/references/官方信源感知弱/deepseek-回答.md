## 对话正文

**Ascend C 是华为昇腾 AI 处理器上用于自定义算子开发的 C/C++ 编程语言，核心优势是通过多层接口抽象、SPMD 并行模型和流水式编程范式，在发挥极致硬件性能的同时，保持开发效率。**  
标注：[华为云博客](https://bbs.huaweicloud.com/blogs/467955)

### 1. 概述与定位

- **本质**：Ascend C 是 CANN 中专为算子开发设计的语言，原生支持 C/C++ 标准，旨在兼顾开发效率与执行性能。  
  标注：[华为云博客](https://bbs.huaweicloud.com/blogs/467955)
- **核心能力**：提供丰富的类库 API，允许开发者直接操控 **AI Core** 的计算、存储和搬运单元。  
  标注：[CANN 8.1.RC1 算子开发指南 PDF](https://www.hiascend.com/doc_center/source/zh/canncommercial/81RC1/developmentguide/opdevg/Ascendcopdevg/CANN%E5%95%86%E7%94%A8%E7%89%88%208.1.RC1%20Ascend%20C%E7%AE%97%E5%AD%90%E5%BC%80%E5%8F%91%E6%8C%87%E5%8D%97%2001.pdf) · [CANN 8.0.0 自定义算子开发指南 PDF](https://www.hiascend.com/doc_center/source/zh/canncommercial/800/developmentguide/opdevg/Ascendcopdevg/CANN%E5%95%86%E7%94%A8%E7%89%88%208.0.0%20Ascend%20C%E8%87%AA%E5%AE%9A%E4%B9%89%E7%AE%97%E5%AD%90%E5%BC%80%E5%8F%91%E6%8C%87%E5%8D%97%2001.pdf)

### 2. 核心特性

- **SPMD 编程模型**：单程序多数据，所有 AI Core 运行同一份代码，处理不同数据分片。  
  标注：[华为云博客](https://bbs.huaweicloud.com/blogs/467955)
- **流水式编程范式**：算子逻辑细分为多个流水任务，使用 `TPipe` 管理资源，数据以 `LocalTensor` 为载体通过 `TQueue` 传递。  
  标注：[CANN Kit 基础 API](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/cannkit-programmingapi-basic-apis-0000002300239860)
- **分层 API 设计**：
  - **基础 API**：如 `DataCopy`、`Add`，精细控制底层硬件。  
    标注：[CANN Kit 基础 API](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/cannkit-programmingapi-basic-apis-0000002300239860) · [API 参考 PDF](https://www.hiascend.com/doc_center/source/zh/canncommercial/800/apiref/ascendcopapi/CANN%E5%95%86%E7%94%A8%E7%89%88%208.0.0%20%20Ascend%20C%E7%AE%97%E5%AD%90%E5%BC%80%E5%8F%91%E6%8E%A5%E5%8F%A3%E5%8F%82%E8%80%83%2001.pdf)
  - **高阶 API**：如 `Matmul`，封装常用复杂算法。  
    标注：[API 参考 PDF](https://www.hiascend.com/doc_center/source/zh/canncommercial/800/apiref/ascendcopapi/CANN%E5%95%86%E7%94%A8%E7%89%88%208.0.0%20%20Ascend%20C%E7%AE%97%E5%AD%90%E5%BC%80%E5%8F%91%E6%8E%A5%E5%8F%A3%E5%8F%82%E8%80%83%2001.pdf) · [Matmul 说明](https://developer.huawei.com/consumer/cn/doc/hiai-References/cannkit-matmul-usage-description-0000002158477037)

### 3. 开发流程（工程化路径）

- **步骤一：环境准备**：安装 CANN 软件包并配置环境变量。  
  标注：[环境准备](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/cannkit-environment-preparation-0000002157601593) · [华为云博客](https://bbs.huaweicloud.com/blogs/469418)
- **步骤二：创建算子工程**：使用 **msOpGen** 工程生成工具。  
  标注：[msOpGen 工具链](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/81RC1alpha001/devaids/opdev/optool/atlasopdev_16_0027.html)
- **步骤三：实现算子**：
  - **Host 侧**：编写 `Tiling` 函数。  
    标注：[华为云博客](https://bbs.huaweicloud.com/blogs/469418)
  - **Kernel 侧**：数据搬入 → 执行计算 → 数据搬出（`DataCopy` + 计算 API）。  
    标注：[矢量编程](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/cannkit-vector-programming-0000002157683241)
  - **核函数定义**：定义算子入口函数 `add_custom`。  
    标注：[矢量编程](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/cannkit-vector-programming-0000002157683241) · [8.2.RC1 算子开发指南 PDF](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1alpha002/opdevg/Ascendcopdevg/CANN%E7%A4%BE%E5%8C%BA%E7%89%88%208.2.RC1.alpha002%20Ascend%20C%E7%AE%97%E5%AD%90%E5%BC%80%E5%8F%91%E6%8C%87%E5%8D%97%2001.pdf)
- **步骤四：编译与部署**：执行 `./build.sh` 编译，运行 `.run` 安装包部署。  
  标注：[工程编译](https://developer.huawei.com/consumer/cn/doc/hiai-guides/cannkit-operator-project-compilation-0000002122321636) · [msOpGen](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/81RC1alpha001/devaids/opdev/optool/atlasopdev_16_0027.html)

### 4. 核心知识点

- **编程模型关键要素**：围绕「流水」「张量」「队列」构建；`TPipe` / `TQueue` / `LocalTensor`。  
  标注：[华为云博客](https://bbs.huaweicloud.com/blogs/467955) · [CANN Kit 基础 API](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/cannkit-programmingapi-basic-apis-0000002300239860)
- **Tiling 机制**：Host 侧将大张量切分为 Tile，Kernel 循环逐块搬运计算。  
  标注：[昇腾论坛](https://developer.huawei.com/home/forum/ascend/thread-02162212495117620099-1-1.html)

### 5. API 参考

下表总结 Ascend C 主要 API 分类与功能。  
标注：[API 参考 PDF](https://www.hiascend.com/doc_center/source/zh/canncommercial/800/apiref/ascendcopapi/CANN%E5%95%86%E7%94%A8%E7%89%88%208.0.0%20%20Ascend%20C%E7%AE%97%E5%AD%90%E5%BC%80%E5%8F%91%E6%8E%A5%E5%8F%A3%E5%8F%82%E8%80%83%2001.pdf)

| API 分类 | 主要功能 |
| :--- | :--- |
| **Kernel API** | 在 AI Core 上执行的核心接口 |
| ├─ **基础数据结构** | `GlobalTensor`、`LocalTensor` |
| ├─ **基础 API** | `DataCopy`、`Add/Mul`、`TPipe/TQueue` |
| ├─ **高阶 API** | `Matmul`、`Softmax`、数学库等 |
| **Host API** | Host CPU 辅助接口 |
| ├─ **Tiling API** | 计算并下发 Tiling 参数 |
| ├─ **算子注册 API** | 向 CANN 注册自定义算子 |
| └─ **平台信息 API** | 获取硬件核数、缓存大小等 |
| **算子调测 API** | 孪生调试、Profiling 等 |

### 6. 最佳实践与调优

- **多核并行**：Host 侧 `Tiling` 计算各核数据范围，实现负载均衡。  
  标注：[8.2.RC1 算子开发指南 PDF](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/82RC1alpha002/opdevg/Ascendcopdevg/CANN%E7%A4%BE%E5%8C%BA%E7%89%88%208.2.RC1.alpha002%20Ascend%20C%E7%AE%97%E5%AD%90%E5%BC%80%E5%8F%91%E6%8C%87%E5%8D%97%2001.pdf)
- **双缓冲**：`TQueue` 管理双缓冲区，计算与预取并行。  
  标注：[华为云博客](https://bbs.huaweicloud.com/blogs/469234)
- **核函数融合**：将 Matmul + Add + ReLU 等融合进一个算子，减少内存读写。（无段末 URL 标注）
- **调测工具**：
  - **CPU 调测**：孪生调试验证 Kernel 逻辑。  
    标注：[华为云博客](https://bbs.huaweicloud.com/blogs/467955)
  - **NPU 调测**：`printf` 或 AscendCL API 进行性能分析。（无段末 URL 标注）
