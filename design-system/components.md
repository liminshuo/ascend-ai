## 1. OMenu 菜单

![OMenu](./assets/o-menu.png)

**用途：** 侧栏 / 层级菜单，支持一、二级展开。

**结构**
- 一级：左宫格图标 + 标题 + 右展开箭头
- 二级：缩进、无左图标 + 标题 + 右箭头

**状态**
| 状态 | 表现 |
|------|------|
| 默认 | 深灰字 / 灰图标，透明底，箭头向下 |
| 选中 / 展开 | 浅蓝圆角底，蓝字 / 蓝图标，箭头向上 |

**备注：** 选中条为整行圆角高亮；层级靠缩进区分。

---

## 2. OTab 标签页

![OTab](./assets/o-tab.png)

**用途：** 内容分区切换；稿中含 5 种形态。

| 变体 | 说明 |
|------|------|
| 通栏下划线 | 图标 + 文案横排；选中通栏蓝底边 |
| 文字下划线 | 同上，下划线宽度贴近文案 |
| 上图下文 | 图标在上、文案在下；选中短蓝下划线 |
| 大分段控件 | 浅灰圆角容器 + 多选项；选中白底浮起 + 蓝字 |
| 小分段控件 | 同结构，更紧凑 |

**状态：** 默认深灰；选中品牌蓝（字 / 图标 / 指示条）。

---

## 3. OBreadcrumb 面包屑

![OBreadcrumb](./assets/o-breadcrumb.png)

**用途：** 展示当前页在站点层级中的路径。

**结构：** `首页 > 一级页面 > … > 当前页面`  
分隔符为 `>`。

**状态**
| 项 | 表现 |
|----|------|
| 祖先页 | 中灰字，可点击 |
| 当前页 | 深蓝加粗，不可点（或非链） |

---

## 4. OAnchor 锚点

![OAnchor](./assets/o-anchor.png)

**用途：** 长文 / 侧栏目录跳转；支持一、二级。

**竖向变体**
- 竖线 + 空心圆节点
- 嵌套二级缩进
- 选中：蓝字；可选实心蓝点 / 左侧蓝竖条指示

**横向变体**
- 纯文字并排；选中蓝字
- 白底条内容纳多锚点（类顶部分区）

---

## 5. OPagination 分页

![OPagination](./assets/o-pagination.png)

**用途：** 列表翻页。

**完整版**
- 左侧：总数文案（如「共 120 条数据」）+ 每页条数下拉
- 中部：上一页 / 页码（当前页深蓝底白字）/ 省略号 / 末页 / 下一页
- 右侧：「前往」+ 页码输入框

**简洁版**
- 上一页 + `当前页输入 / 总页数` + 下一页

**样式：** 白底、浅灰描边、小圆角；禁用箭头更浅。

## 6. OStep 步骤条

![OStep](./assets/o-step.png)

**用途：** 流程进度（横 / 竖）。

| 状态 | 圆点 | 文案 | 连接线 |
|------|------|------|--------|
| 已完成 | 绿底白号 | 深灰 | 深蓝实线（通向下一步） |
| 进行中 | 深蓝底白号 | 深蓝加粗 | 之后为浅灰线 |
| 未开始 | 浅灰蓝底白号 | 浅灰 | — |

横版标签在圆点下方居中；竖版圆点左对齐，标签在圆点下方。

## 7. ONavigation 导航

![ONavigation](./assets/o-navigation.png)

**用途：** 站点顶栏（稿面样本为 openEuler）。

**桌面**
- 左：Logo
- 中：主导航文案链（下载 / 开发 / 文档 / 学习 / 支持 / 社区 / 动态）
- 右：搜索框、「源码」下拉、语言、主题、用户

**移动**
- 左：汉堡菜单
- 中：Logo
- 右：搜索、头像

**样式：** 白底顶栏；主导航深色字；搜索浅灰圆角输入。

## 8. 底部导航

![底部导航](./assets/o-footer-nav.png)

**用途：** 站点页脚导航与品牌区（稿面样本为 openEuler）。

**结构（自上而下）**
1. 基金会归属说明 + OpenAtom 标识
2. 六栏链接：关于 / 新闻与资讯 / 获取与下载 / 支持与服务 / 互动与交流 / 贡献与成长
3. 友情链接横排
4. 底栏：Logo + 邮箱 | 品牌 / 隐私 / 法律与版权 | 微信与社交入口

**样式：** 深色背景；栏目标题偏亮，链接偏灰；底部分隔线弱对比。

# 操作类

## 9. OButton 按钮

![OButton](./assets/o-button.png)

**用途：** 主操作触发；含左图标 / 文案 / 右外链图标。

**变体 × 尺寸 × 状态**

| 变体 | 正常 | 禁用 |
|------|------|------|
| 强调按钮 | 深蓝实心胶囊，白字白图标 | 浅蓝灰实心，白字 |
| 普通按钮 | 白底 + 蓝描边，蓝字蓝图标 | 白底 + 浅描边，浅灰蓝字 |
| 文字按钮 | 无底无边，深灰字；右为 `>` | 浅灰字 |

尺寸：大 / 中 / 小三档（胶囊圆角）。文字按钮小档稿面文案可为「普通按钮」。

## 24. OUpload 上传

三张截图覆盖图片卡、拖拽区、按钮+文件列表。

### 24.1 图片上传卡

![OUpload 图片](./assets/o-upload-image.png)

| 状态 | 表现 |
|------|------|
| 空态 | 方框 +「+」+「上传图片」；旁注格式/大小限制 |
| 成功 | 方框内预览图 |
| 上传中 | 蓝环形进度 |
| 错误 | 红描边；可有红字「请至少上传一张图片」 |
| 小尺寸 | 更小方卡（空态 / 预览） |

旁注文案示意：仅 jpg/png，最大 1M。

### 24.2 拖拽上传区

![OUpload 拖拽](./assets/o-upload-dragger.png)

- 大区：中央「+」+「点击或拖拽文件到此处上传」+ 格式/大小副文案
- 下方文件行：链接图标 + 文件名 + 右侧蓝进度环
- 另有偏灰的次态 / 禁用示意，及无副文案的紧凑拖拽区

### 24.3 按钮 + 文件列表

![OUpload 按钮](./assets/o-upload-button.png)

- 触发：蓝描边胶囊「上传文件」（左 + / 右外链图标）
